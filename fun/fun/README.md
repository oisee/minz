# LFSR-16 AND-cascade XOR renderer

GPU-found seeds → ZX Spectrum image / animation.  
Same algorithm drives [the web player](../../z80-optimizer/docs/renderer.html).

---

## Algorithm

### 1. LFSR-16 (Galois, polynomial 0xB400)

```
state = (state >> 1) ^ (0xB400 if state & 1 else 0)
```

16-bit maximal-length LFSR: period 65535, never visits 0.

### 2. makeBuf(seed, warmup, and_n) → 768 bytes

Canvas = 128×96 pixels = 32×24 block grid = **768 blocks**.

```
s = seed
repeat warmup: s = lfsr16(s)          # skip transient

for i in 0..767:
    acc = 1
    repeat and_n: s = lfsr16(s); acc &= s & 1
    buf[i] = acc                       # 0 or 1
```

`and_n` controls density:
- AND-1: ~50% blocks active  
- AND-3: ~12.5%  
- AND-5: ~3.1%  
- AND-7: ~0.8%

### 3. applyBuf(buf, ox, oy, blk) → XOR onto 128×96 canvas

```
for by in 0..23:
    for bx in 0..31:
        if buf[by*32 + bx] == 0: continue
        for dy in 0..blk-1:
            for dx in 0..blk-1:
                x = ox + bx*blk + dx
                y = oy + by*blk + dy
                if 0 <= x < 128 and 0 <= y < 96:
                    canvas[y*128 + x] ^= 1
```

`blk` = block size in pixels (1, 2, 4, or 8).  
XOR is **reversible**: applying same seed twice restores original.

### 4. Full render

```
canvas = zeros(128, 96)
for each seed entry (seed, ox, oy, blk, and_n, warmup):
    buf = makeBuf(seed, warmup, and_n)
    applyBuf(buf, ox, oy, blk)
```

## Data format (seeds JSON)

```json
{
  "lfsr16_poly": "0xB400",
  "canvas_w": 128, "canvas_h": 96,
  "seeds": [
    {"seed": 450, "ox": 0, "oy": 0, "blk": 4, "and_n": 3, "warmup": 0},
    {"seed": 9449, "ox": 32, "oy": 48, "blk": 2, "and_n": 3, "warmup": 1},
    ...
  ]
}
```

Animation adds `"type": "animation_flat"` + `"frame_starts": [...]`:
frame N uses seeds `frame_starts[N] .. frame_starts[N+1]-1`.  
`"kf"` frame = clear canvas first; `"dt"` frame = XOR delta onto previous.  
Compact keys: `s/b/n/w/f` = `seed/blk/and_n/warmup/frame`.

## Binary seeds format (for Z80 replay)

Generated by `gen_seeds_bin.py` from JSON. 2-byte header + 7 bytes/entry:

```
[n_seeds u16 LE] [seed u16 LE][ox u8][oy u8][blk u8][and_n u8][warmup u8] ...
```

## Files

| File | Purpose |
|------|---------|
| `render_seeds.py` | Python: JSON → PNG / GIF |
| `gen_seeds_bin.py` | Convert JSON → binary for Z80 |
| `replay.nanz` | Nanz: binary seeds → ZX screen (via VIR) |
| `replay.asm` | Z80 ASM: same, hand-optimized |
| `seeds.bin` | 192-byte Che demo data (different LFSR, see below) |

**Note:** `seeds.bin` / `che_intro.nanz` use a *different* LFSR (Fibonacci, init=0x1337).  
The AND-cascade data lives in `~/dev/z80-optimizer/data/*.json`.

## Pipeline summary

```
GPU brute-force (z80-optimizer CUDA)
    ↓  prng_segmented_search.cu / prng_budget_search.cu
seeds JSON  (z80-optimizer/data/*.json)
    ├─→ web player  (z80-optimizer/docs/renderer.html)
    ├─→ PNG / GIF   (render_seeds.py)
    └─→ Z80 binary  (gen_seeds_bin.py → replay.asm / replay.nanz)
```

## Quick start

```bash
# view static image as PNG
python3 render_seeds.py ~/dev/z80-optimizer/data/foveal_cascade_seeds.json

# view animation as GIF
python3 render_seeds.py ~/dev/z80-optimizer/data/che_anim_flat.json --gif

# compile Z80 replay
python3 gen_seeds_bin.py ~/dev/z80-optimizer/data/foveal_cascade_seeds.json seeds_lfsr.bin
mz --vir replay.nanz -o build/replay.a80
mza build/replay.a80 -o build/replay.bin
mze --target spectrum build/replay.bin

# or pure asm
python3 gen_seeds_bin.py ... seeds_lfsr.bin
mza replay.asm -o build/replay.bin
mze --target spectrum build/replay.bin
```

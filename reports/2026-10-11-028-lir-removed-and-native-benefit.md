# LIR удалён; получена конкретная native польза

В `47127a27` удалён весь живой pkg/lir и его последние тестовые потребители. Shared rewrite engines, VIR, canonical z80spec, native expected-value оракулы и шесть composition fixtures сохранены. Архив 53 исходных research-файлов повторно открыт, SHA256 каждого содержимого совпал; полный пакет сохранён на шаре. Архив не входит в Go build.

Свежая проверка объединённой ветки: полный HIR PASS29.620s, MIR2 PASS6.864s, shared ISLE PASS0.003s, z80spec PASS0.010s. Все cmd/pkg/internal/tests проходят compile-only без LIR. Общий ./... по-прежнему имеет зафиксированные проблемы standalone scripts; этот gate не объявляется зелёным.

Исправлен signed Sub/Cmp fusion (`15c257bc`): abs_diff20,-10 снова30, крайние -128/127 дают255. 810 независимых rawMIR/optimizedVM/assembledZ80 случаев проходят; unsigned fast path сохранён. Showcase после интеграции проходит с пятью оставшимися точными исключениями; это сборочный gate, не исполнение всех программ.

Native word multiply10/12 (`0580ee7d`, артефакты `22bdfd90`) заменяет software multiply на shift/add. Runtime parameter, результатHL: 1079→96T, 32→9B. Проверены 192 физических случая до/после и40 source→VM/Z80 случаев с Graceoff/on. Интегрированные focused проверки также PASS. Это измерение конкретной операции, не общий выигрыш программы и не завершённая Graceheldout проверка.

В `2a6db0d7` допуск VIR таблиц отвергает совместно живые значения с физическим перекрытием и разрушительное определение поверх используемого позже источника. Три ранее принимавшихся случая воспроизведены. Scratch/repair выбранных patterns и CFG/островные границы ещё требуют проверки.

Общая цель активна: устранить оставшиеся сбои корпуса, доказать допустимость и измерить пользу PFCCO/PBQP/table назначений с пересылками/сохранениями, подтвердить Grace на разных программах и заранее отложенных нагрузках. PureSpeed и Size остаются раздельными целями.

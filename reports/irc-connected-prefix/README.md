# IRC: рабочий участок исходного main

Заранее заданный обмен включает pre-connected состояние, регистрацию, `PING :abc`, PRIVMSG от bob с текстом hi и JOIN от bob. Между сообщениями сеть возвращает 0, клавиатура — 0. Ожидаемые 313 host-событий, ответы сети и 512 байт srv_buf построены из исходника до исполнения, включая хвост предыдущего сообщения.

Неизменённый main прошёл raw/final VM и собранный Z80 во всех трёх режимах. Совместный повтор с тремя путями отказа: **PASS 3,500 с**. Проверены все globals; native проверяет все 64 КиБ RAM кроме точных spill-ячееек и использованного стека. Host callbacks сохраняют регистры кроме объявленного результата. TUI callback читает CString только из известных объектов.

| Режим | BIN, байты | Такты участка |
|---|---:|---:|
| Ordinary | 4496 | 68 602 |
| Grace Size | 4471 | 65 401 |
| Grace Speed | 4471 | 65 401 |

Выигрыш на этой нагрузке: **−25 байт и −4,7% тактов**. Host callbacks не включены в такты. Это сравнение режимов на одном заранее заданном обмене; нагрузка не является новым heldout для selector.

Исходный рабочий цикл бесконечен. Стенд останавливает наблюдение перед следующим net_read после трёх итераций, не добавляя return и не меняя исходник. Native PC указывает на net_read, SP находится внутри допустимого стека; сохранённый адрес продолжения проверен по настоящему CALL net_read. Возврат main и восстановление SP здесь не заявляются. На VM тестовый sentinel завершает наблюдение в том же host-вызове.

Произвольный серверный поток, ввод команд пользователем, физическая сеть и CP/M не покрыты. Пути DNS error/refused/timeout имеют отдельную проверку настоящего возврата: [отказы подключения](../irc-connection-failure/README.md). [Совместный лог](root.txt) · [Freeze](frozen/freeze.json).

# Zork II: позднее сохранение после wand

13 октября 2026 года. Работа в `feat/zmachine-spectrum128`.

Полный игровой маршрут Zork II уже подтверждён на банковом Z80:
400/400 очков. Это отдельный следующий допуск: SAVE после получения wand,
потеря предмета, RESTORE и продолжение до финала.

## Что уже измерено

В `mzv -H` тот же Nanz-интерпретатор проходит маршрут с SAVE/RESTORE:
400/400 на 650 ходах. Полный инвентарь с wand совпадает перед SAVE и после
RESTORE. Запись состояния этого момента после перекодирования в MZ3R занимает
1932 байта: заголовок 32, RLE состояния 308, RLE разницы динамической памяти
1592. Проверено обратное декодирование. Это замер записи из host VM, а не
утверждение о размере записи нативной реализации.

Слот SAVE сжатой истории в обычном Spectrum 128K — 700 байт. Данное состояние
туда не помещается; обрезать запись нельзя. Переполнение не доказывает ошибку
исполнения самой игры. RAM SAVE имеет ограниченную ёмкость; неудачная
перезапись инвалидирует предыдущую запись, гарантия её сохранности отсутствует.

## Дисковая проверка

Новый тест `TestZMachineBankedZorkIIScorpionLateDiskSaveNative` использует
раскладку памяти Scorpion: история в банках 0/1/3/4/6/7, архив RESTART
в банке 10, запись временно собирается в банке 8, сектор — в банке 9.
SAVE публикуется в выделенный файл TRD. Перед RESTORE тест очищает временные
банки 8/9 и заново открывает TRD с диска. Затем требует полный инвентарь,
побайтовое совпадение всего вывода с mzv, финальные 400/400 на 650 ходах,
неизменность статической истории и архива RESTART, правильные PC/SP/paging.

Используется API TR-DOS эмулятора. Это не проверка физического контроллера
диска и не заявка на поддержку всей аппаратуры Scorpion. Очистка буфера и
повторное открытие файла проверяют источник восстановления; новая машина
для поздней записи пока не проверена. Тест раннего SAVE отдельно проверяет
RESTORE после запуска новой машины.

Попытка объединить сжатую историю и расширенный дисковый SAVE дала resident
до $C255, за границей стека $BE00. Этот вариант отклонён проверкой размера.
Текущий тест использует уже работающую несжатую банковую раскладку Scorpion;
256-байтный стек не уменьшен.

**Статус:** нативный поздний дисковый тест запущен; PASS пока не заявляется.
Проверка переполнения RAM SAVE обычного 128K ещё предстоит.

Маршрут: `examples/zmachine/zork-west-demo/routes/zork2-late-save-vm.txt`.

# Проверка цели: Z-machine V3 на Spectrum 128K

13 октября 2026 года. Цель: Z-machine V3 на Spectrum 128K с историей
в банковой памяти; сначала Zork I, другие V3-истории подтверждаются отдельно.

| Требование | Прямое подтверждение | Границы |
|---|---|---|
| Интерпретатор V3 исполняется как Z80 | Nanz → HIR → MIR2 → Z80 → assembler → Spectrum emulator; независимая Inform-история и CZECH | `mzv -H` — дополнительный путь, не замена Z80 |
| Обычный Spectrum 128K | Zork I: 86 928 байт в банках 0/1/3/4/6/7; SNA roundtrip всех восьми банков и PC/SP/paging | Физическая машина не проверена |
| Игровое поведение Zork I | Полный финал 350/350, 399 ходов; 36 967 байт вывода совпали с mzv; Frotz отдельно подтвердил финал | Один детерминированный маршрут |
| SAVE/RESTORE и RESTART I | Поздний RAM SAVE 1660/2204 байта, затем 350/350; ранние повторные RESTORE/RESTART | Текущий поздний повтор выполняется; переполнение отвергается, неудачная перезапись инвалидирует RAM слот |
| Реальный пользовательский ввод и экран | Матрица клавиатуры, ROM font, окна V3, статус, курсор/история/delete; CLI открывает новый SNA до prompt | IRQ отключены; 79 символов ввода, 32 колонки |
| Другая V3-история отдельно | Zork II полный финал 400/400 на обычном 128K со сжатой историей; 59 497 байт совпали с mzv, Frotz отдельно подтвердил финал | Не обобщается на все V3-игры |
| Дисковый SAVE II | 1916-байтный нативный SAVE, 400/400; тот же TRD восстановлен в новой машине и снова 400/400 | Раскладка Scorpion; TR-DOS API эмулятора, не физический контроллер |
| Независимый корпус V3 | CZECH v0.8, 349 assertions, 19 print cases, 0 failed; окна, byte-exact mzv, PC/SP/paging | Сам по себе не подтверждает всё файловое/экранное I/O |
| Воспроизводимый комплект | Builder, исходники, ASM/BIN/SNA, play.sh, метаданные и SHA256 на шаре | Исследовательская ветка, не весь код уже в main |

## Проверенные артефакты

* `/mnt/safe/minz/grace/2026-10-13/zork1-full-play/`: прежний полный допуск I,
  21 запись манифеста, SHA256 повторно совпали.
* `/mnt/safe/minz/grace/2026-10-13/zork2-full/`: полный допуск II на 128K,
  88 записей манифеста, SHA256 повторно совпали.
* `/mnt/safe/minz/grace/2026-10-13/zork2-late-save/`: поздний дисковый SAVE II
  и новая машина, 71 запись манифеста, SHA256 повторно совпали.
* `/mnt/safe/minz/grace/2026-10-13/zork1-current-128/`: новый SNA I,
  resident 23 604 байта, старт и prompt проверены; текущий поздний повтор ожидается.

Неподтверждённые расширения: все V3-истории, физический Spectrum/TR-DOS,
произвольная история больше 98 304 байт, Unicode и host-файловые потоки.
Они не должны подразумеваться словом «работает». Текущая проверка цели остаётся
открытой до результата повторного позднего маршрута I и сохранения его артефактов.

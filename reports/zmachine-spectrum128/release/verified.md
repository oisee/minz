# MinZ 0.25.0: встроенные Z80-демо

Порт Z-machine/Spectrum интегрирован в main через PR #92 (`675216c6`).
Каталог MZX поставляет Zork I/II, Spectrum Tetris, ротозумер 32×48 и два
SMC-спрайтовых демо. Linux и Windows запускаются одним файлом; отдельные
SNA/TRD-образы поставляются с лицензиями и исходниками примеров.

Проверены именно файлы пакетов 0.25.0, сборка `fedfa83d`: SHA256, каждый файл
в ZIP, запуск всех шести демо на Linux/X11 и Windows/Wine 9, повторное чтение
сессии Zork I, SAVE Zork II и RESTORE новым процессом. Ответы игры `Ok.`
проверены на скриншотах. Восстановление не меняет SHA256 диска.
Также новый пакет восстановил SAVE старого кандидата; отдельный Linux
SNA/TRD launcher сохранил прежние данные. Меню проверено через Enter/Escape.

Это проверка Windows-бинарника под Wine, не утверждение о запуске на физическом
Windows-компьютере. Zork II использует раскладку Scorpion memory и эмуляторные
TR-DOS API traps, не полную модель устройств Scorpion. Проверки полноценных
игровых финалов и независимые VM/Z80 оракулы описаны в current-status.md.

Сохранения находятся в `~/.config/minz/mzx` или `%AppData%\minz\mzx`;
`--data-dir PATH` меняет каталог. Обновление ZIP не заменяет SAVE.
Zork I сохраняет `session.sna` при нормальном выходе, Zork II — `save.trd`
по команде SAVE. Встроенные ресурсы неизменяемы.

Истории скомпилированы из лицензированных historicalsource исходников;
MIT notices Microsoft 2025 включены в каждый пакет и архив образов.

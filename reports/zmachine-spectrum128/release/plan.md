# Релиз с демо: условия готовности

Цель: интеграция Z-machine/Spectrum в main, Linux и Windows, встроенные демо
и отдельные образы, сохранения между обновлениями, проверка релизных файлов,
README и полный архив SHA256 на `/mnt/safe/minz/`.

## Состав

Zork I (обычный 128K), Zork II (Scorpion memory с TRD SAVE), Tetris,
32×48 ротозумер, compiled/PUSH SMC-спрайты. Встроенное меню эмулятора
запускает те же образы, которые публикуются отдельно; не отдельные версии игр.
Tetris для CP/M требует CP/M runtime: его нельзя выдавать за Spectrum snapshot.
Нужно подтвердить игровой Spectrum Tetris либо явно предложить запуск CP/M.

## Сохранения

Встроенные ресурсы immutable. TRD SAVE создаётся в каталоге пользовательских
данных только при отсутствии файла. Обновление/выбор демо не заменяет SAVE.
Для обычного 128K RAM SAVE volatile; UI сообщает это и предлагает snapshot
либо дисковую конфигурацию. Образы и диски пользователя сохраняются отдельно.

## Проверки

Интегрированный main: пакеты компилятора, эмулятора, Z-machine и точная
классификация pipeline CI. Короткие регрессии на PR; глубокие домены
на release/nightly/manual. Релиз: проверить конечные Linux/Windows бинарники,
меню, запуск всех демо, клавиатуру и SAVE после перезапуска/обновления.
Кросс-компиляция Windows сама по себе не является проверкой исполнения.
Публиковать тег и пакет после этих проверок; хранить логи, исходники,
образы, лицензии и SHA256. Сейчас интеграционные проверки выполняются.

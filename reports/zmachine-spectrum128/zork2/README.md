# Zork II: отдельная полная V3-история на Spectrum 128K

13 октября 2026 года. Исследовательская ветка `feat/zmachine-spectrum128`.

Zork II проходит короткий маршрут на нативном Z80 с историей в шести банках
Spectrum 128K. Это проверка второй полной игры, независимо от Zork I;
полное прохождение игры не проверено.

## Воспроизводимый исходник

История собрана из MIT-исходников
[historicalsource/zork2, 3da9661098809788a99cef00f00c865c6c204f96](https://github.com/historicalsource/zork2/tree/3da9661098809788a99cef00f00c865c6c204f96).
Использован исходный ZIL, а не готовая коммерческая история из архива.

ZILF 1.9 отказывается компилировать исходную `DREARY-ROOM-FCN`: последний
случай `COND` оказывается вне формы. Приложенный [diff](cond-bracket.patch)
переносит закрывающую скобку после последней ветки; других изменений нет.
Это локальная поправка исторического исходника, не исправление MinZ.

ZILF/ZAPF 1.9.0 Linux x64:
`https://github.com/taradinoc/zilf/releases/download/1.9/zilf-1.9.0-linux-x64.tar.gz`,
SHA256 `06ff0e59eff6e6896fd9ce71d16c100365abbc537cf030f2bd31beb9384d0155`.
Все девять `INSERT-FILE` разрешаются в локальные файлы Zork II.
Библиотека ZILF не подключена; compiler/assembler — отдельные build tools.

В двух свежих каталогах скопированы `*.zil` и `*.xzap`, применён diff, выполнены:

```sh
zilf zork2.zil
zapf zork2.zap zork2-repro.z3 -r 1 -s 000001
```

Оба результата побайтно одинаковы: V3, **92412 байт**, dynamic **11761 байт**,
SHA256 `4cd8ac586b93881afe6fad00e72a33e93541c9573b15a1977ac67acf36ddc6b1`.

## Что проверено

Маршрут: `look`, `inventory`, `take lamp`, `turn on lamp`, `north`, `look`,
`south`, `quit`, `y`. Он проверяет описание комнаты, инвентарь, изменение
объекта, включение фонаря, отказ перехода и успешный переход в Narrow Tunnel.

- VM и Frotz: совпадение всех слов и пунктуации после удаления статусных строк,
  пустых строк, промптов и различий переносов. Нормализация не удаляет игровой текст.
- Native Z80 и VM: **побайтное** совпадение игрового текста, 1649 байт.
- Реальные порты клавиатуры эмулятора: 62 нажатия.
- Z80: 465519490 T; максимальный расход стека 66 байт.
- Завершение: PC=$5000, SP=$BF02, paging=$10, IRQ отключены.
- Собранный SNA: resident 23137 байт; обратная загрузка проверяет все восемь
  физических банков, PC/SP и paging.

Повторить (из `minzc`, story-файл поставляется отдельно):

```sh
MINZ_Z3_ZORK2_STORY=/path/to/zork2-repro.z3 \
MINZ_Z3_VM=/path/to/mzv \
MINZ_Z3_FROTZ=/path/to/dfrotz \
go test ./pkg/pipeline -run '^TestZMachineBankedZorkIIGameplayNative$' -count=1 -v

go run ../scripts/zmachine/build_spectrum128.go /path/to/zork2-repro.z3 /path/to/output
```

## Ограничение памяти

После истории остаётся 5892 байта из 98304. Исходный dynamic-prefix сжимается
нынешним RLE до 9589 байт. Поэтому builder явно отключает RESTART и
SAVE/RESTORE для этой сборки. Нельзя переносить вывод о сохранениях Zork I
на Zork II. Следующий практический шаг — более компактный restart-архив или
иной источник исходной динамической памяти. Полная совместимость V3,
прохождение всей игры и запуск этого SNA на физическом Spectrum не доказаны.

## Сжатая версия с SAVE, RESTORE и RESTART вместе

13 октября: новый runnable checkpoint хранит static story и исходную dynamic
память в независимых LZ-блоках, используя общий кэш 2048 байт. SAVE хранит
RLE-разность относительно исходной памяти и состояние интерпретатора.

Совместный маршрут `take lamp`, `take sword`, `turn on lamp`, `south`, `save`,
`drop sword`, `inventory`, `restore`, `inventory`, `restart`, `y`, `look`,
`inventory`, `quit`, `y` прошёл нативный Z80: **116 клавиш, 2214 байт текста**
побайтно совпадают с VM. Отдельные ожидания проверяют потерю/возвращение меча,
сохранение горящего фонаря и пустой инвентарь после RESTART. Проверены PC/SP,
пейджинг, неизменность архива вне dynamic и выделенного SAVE. Это маршрут
VM/Z80; сравнение с Frotz для SAVE не заявляется. Отдельный RESTART ранее
прошёл VM/Frotz.

Resident **25193 байта**, запас **151 байт** до `$BE00`; стек маршрута 60 байт.
Сохранение **628 из 700 байт**, 1124 cache misses, **1343968580 T** на весь
маршрут. SAVE остаётся volatile; более поздняя игра может не вместиться, тогда
SAVE возвращает ошибку, а не портит историю. Неудачная перезапись отменяет
предыдущее сохранение. Полное прохождение не доказано.

Builder теперь принимает необязательный `--compressed`:

```sh
cd minzc
go run ../scripts/zmachine/build_spectrum128.go STORY.z3 OUTDIR --compressed
```

Без флага сохраняется raw-путь; контрольная пересборка Zork I прошла.
SNA перечитан с побайтным сравнением всех восьми RAM-банков и PC/SP/paging.
Готовый SNA также запущен Linux headless-эмулятором: экран содержит заголовок
Zork II, Inside the Barrow и промпт. Startup включает VERIFY и может занять
заметное время на скорости настоящего Spectrum.

Версии на шаре: `/mnt/safe/minz/grace/2026-10-13/zork2-play/`:
`linux-x86_64.tar.gz`, `windows-x86_64.zip`. Распаковать и запустить `play.sh`
или `play.bat`. Внутри MIT-лицензия истории и поправка исходника. Backspace,
стрелки редактирования и история четырёх команд включены. Windows executable
собран cross-compile, запуск под Windows здесь не проверен.
Исходники, layout, журналы и скриншот: соседний `zork2-save-restart/`.

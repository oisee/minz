# SQLite test: исходный main через портовые ASM-тела

Неизменённый `examples/nanz/sqlite_test.nanz` прошёл native Z80 в Ordinary, Grace Size и Grace Speed. Каждый режим проверен с сохраняющим и затирающим регистры BDOS: **6 запусков, PASS 0,223 с**. Исходные SQL/TUI ASM-тела исполняются; SQL порты подключены к уже существующему тестовому адаптеру с настоящей SQLite.

Независимо заморожены 92 байта stdout, порядок 21 команды и девять значений column_text. Все записи принимаемых строк в 256-байтовый буфер проверяются по адресу и значению, включая NUL и оставшиеся хвосты. Native проверяет весь RAM кроме точных spill и фактически использованного стека. PC=7003/SP=F000 восстановлены, query/database закрыты. BDOS допускается только из настоящего CALL5 в исходном tui_puts. Командные строки и события портов сохраняются для ревью; оракул отдельно проверяет порядок типов команд и содержимое результата, не каждый байт всей последовательности портов.

| Режим | BIN, байты | Такты |
|---|---:|---:|
| Ordinary | 1973 | 26 137 |
| Grace Size | 1977 | 26 145 |
| Grace Speed | 1977 | 26 145 |

Grace здесь увеличивает размер на 4 байта и время на 8 тактов. Это наблюдение режимов, не измеренный выбор selector; baseline предпочтительнее по обоим показателям. Время SQLite/BDOS callbacks не включено.

Это native проверка исходных ASM и тестового SQLite/BDOS runtime. Raw/final VM ASM не эмулируется; физический CP/M и production provider отдельно не проверяются. Каталог пока не обновлён. [Лог](root.txt) · [Freeze](frozen/freeze.json).

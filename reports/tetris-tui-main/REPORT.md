# Полный original TUI Tetris main

Точный исправленный исходник `examples/nanz/tetris_tui.nanz` SHA `019ddfef02d2afe7e9c911bdf50e8f4ec95a341ef638bbd1b73b34130efb97e8` проходит конечный сценарий `z,q,a`: два кадра, поворот, выход, финальное подтверждение. Все original bodies, main, глобальные данные и literals сохранены; этот пакет не меняет исходник. Независимая модель заморожена commit b29b9fa7 до исполнения: 1 955 ordered terminal events и ровно 8 669 байт UTF‑8. Она построена на исходном алгоритме вывода, геометрии горизонтальной/вертикальной I на пустой доске и документированном terminal API, без чтения HIR/emitted tables/results.

Во всех режимах ordinary/Grace Size/Grace Speed проверены raw VM, final VM и actual assembled Z80: весь main до реального возврата, точные события и вывод, все globals/200 board bytes, guards и полная RAM. Итог: cur_rot=1, x=3, y=0, RNG=28984, timer=tick=2, score=lines=0, game_over=1; доска пустая. Native loader CALL main затем DI/HALT в 0x0107, SP=0xeff0. Записи ограничены mutable globals, board, compiler spill slots и bounded real stack; остальные RAM/image bytes сохраняются. Native image с loader/linker: ordinary 4085 B, Grace 4090 B. Финальный gate PASS 1.238 s.

Runtime соответствует фактическому `minzc/cmd/mzv/tui_host.go`: decimal cursor y+1/x+1, ANSI colors/reset/clear, Unicode box 1..6, NUL string scan максимум 4096, неблокирующий read_key из заранее заполненной очереди. Это отличается от imported CP/M TUI ASM; его leading-zero coordinates/ASCII box здесь не используются. Нормализованы только pointer arguments `tui_puts` в строки для сравнения по смыслу: физические VM/native адреса различаются и отдельно сохранены. Каждое чтение string handler допускается только внутри настоящих pooled literal objects, включая terminator; ordered read addresses сохранены.

Native unlinked ASM имеет empty extern labels на одном адресе с rng_next. Первый refusal сохранён в before.txt. Явный test-owned terminal linker добавляет только один RET-byte к каждому declared unique extern label, не меняет ни одного игрового body. Нативный host вызывается только по этим entry PC; читает фактические allocation homes formal args, возвращает объявленный byte через A и извлекает реальный return address из стека (включая tailcall последнего read_key). Неизвестные PC/returns/лишний ввод отвергаются. `abi-bindings.json`, unlinked/linked ASM, COM и отдельные SHA сохраняют точную границу. Это proof whole original main под явно связанным terminal runtime, а не успех неподключённого публичного BIN или public mze/CPM runtime. RuntimeCPM admission не менялся.

Model/source/spec/host SHA сохранены в freeze.json. LINKER.md объясняет initial refusal и mechanism, закоммиченный до строгого repeat. VM host implementations эквивалентны реальному API для этого сценария, не вызывают main/helpers вместо source execution; native executes оригинальные machine bodies. Общий корпус/CLI здесь не повторялся, результаты coordinator отдельно. Manifest включает все исходники, workload/model, actual outputs, raw/final MIR, native COM/ASM и ABI mapping; payloads tracked и SHA проверены.

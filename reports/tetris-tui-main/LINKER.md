The unlinked original-module ASM contains nine declared extern labels with no bytes between them. Their symbol values alias the following rng_next entry. They cannot select nine native runtime operations without linking.

The test-owned terminal linker inserts exactly one RET byte at each uniquely named, declared extern label, without changing any original function body. Each native operation uses its real allocation-derived formal parameter homes and declared u8 return A. The hook consumes the real return address from the call stack, advances SP by two and rejects a return outside the image; source tail-call to final tui_read_key uses the main caller return. Only these unique linker entry PCs are handled. Runtime implementations match documented mzv ANSI/UTF8/NUL/input semantics. The original source/model freeze preceded execution. The initial unlinked refusal and first linked success are preserved, followed by this frozen mechanism and a stricter repeat checking pooled string object bounds and actual return-stack bounds. This is a native test runtime adapter, not a claim that unlinked public ASM is executable.

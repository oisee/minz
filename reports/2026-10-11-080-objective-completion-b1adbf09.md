## Конкретные исполнения, которые нельзя считать закрытыми

Из официальных первых девяти showcase у каждого есть bounded independent proof, включая direct/indirect09, но runtime main автоматически не покрыт. Полный original SelfLanz/tokenizer main уже имеет явный native/COM+BDOS-hook proof; это настоящие инструкции Z80 и CP/M ABI, не физическая CP/M OS. У SORT **PRINTARRAY/main/BDOS не исполнялись**; canonical dead-runtime admission даёт право только на SORT. Original13/10 generated tag/payload helpers могут быть pruning/inlining: source callable tests сохраняются, pruned helper отдельно raw-only, это не забытая native функция.

Действительно недоказанные original semantic programs: **widemath.nanz** (26 callable entries/overloads), **examples/pascal/recursive_test.pas** (FACT/SUMTO и остальные9 entries), **examples/lizp/functional.lizp** (apply/funcall/lambda/transform), **examples/nanz/tuple_assert_gate.nanz** (divmod), **examples/tests/pipe_fold_mul_combos.nanz** (ordered callbacks+multiply), **examples/zx/tetris_mir2_test.nanz** (board/piece state). Полный список86 pending сохранён машинно, включая исторические исходники, а не скрыт за этими примерами. Наличие source assert/test reference само по себе не independent execution.

Projection gap: `promoted_arithmetic.nanz` остаётся pending в132, хотя `hir/TestFix1FrontendAsserts` исполняет9 фиксированных original native случаев, включая signed pressure. Это **bounded факт**, не all-input/3mode proof; каталог стоит дополнить точной ссылкой. `tiny` имеет checked triple+caller доказательство, но не полное add/double/triple module proof. Не путать отсутствие curated registry с отсутствием любого теста.

Явные отказы не miscompile PASS: ZVM131072-byte story невозможно разместить в16-bit ordinary Z80; Agon/MOS и ZX/BDOS apps требуют определённого runtime/device oracle; arbitrary inlineASM игнорируется HIR VM и не может стать равным no-op оракулу. CY error ABI сейчас поддерживает direct checked u8/void, явно отклоняет fallible word/tuple/extern/nested и value-only profiles. Такие границы допустимы как результат, но если программа ранее обещана к исполнению, сам отказ не снимает обещание поддержки.

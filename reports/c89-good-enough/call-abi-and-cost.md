# C89: широкие CALL и цена декомпозиции структур

16 октября 2026 года. `feat/c89-call-abi`, до интеграции в main.

`testdata/call_abi/wide.c` передаёт два unsigned long через CALL, получает
32-битный результат и сохраняет живые исходные операнды для следующих
операций. Есть простая цепочка, caller-live цепочка и вложенное forwarding.
Глобальные входы не должны изменяться. Пятнадцать граничных значений для
каждого аргумента, три семейства и три режима дают 2025 native Z80 и 2700
raw/final MIR VM наблюдений. Они прошли; final MIR отдельно сохраняет два
32-битных parameter slots и 32-битный result slot. Native harness проверяет
результат по модулю 2^32, входные globals и PC/SP.

Декомпозиция небольшого `Pair` измерена отдельно. Обе сборки используют один
исходник и одинаковые настройки pipeline. У memory baseline выключена только
C-specific scalar eligibility: полноценный caller-owned buffer возврата и
копирование by-value параметра сохранены. Это корректная реализация C, а не
старый указатель в освобождённый кадр.

| Исходник | Входов | Memory ABI, байты / T | Scalar ABI, байты / T |
|---|---:|---:|---:|
| `scalar_cost.c` | 49 | 193 / 56301 | 90 / 23569 |
| `scalar_heldout.c` | 73 | 255 / 100012 | 141 / 46138 |

Первый caller использует x и y после `make_pair`/`consume`. Второй исходник
добавляет ветвление в factory и другие вычисления полей, а входы берутся из
отдельной детерминированной последовательности. Он не участвовал в выборе
трансформации. Это проверка обобщения на другой форме, не полноценный PGO
эксперимент и не доказательство выигрыша на произвольном C.

Таблица измеряет весь вызов `execute`, включая загрузку входов, CALL, сохранения,
передачи и запись результата. T — сумма по указанному набору входов, байты —
полный собранный модуль без CP/M startup. В default/Grace/Size получились те же
значения: дополнительного эффекта Grace на этих двух программах нет.
Тест требует реальный scalar ABI (два аргумента/результата), корректный memory
baseline и сохранение измеренного выигрыша по размеру и времени.

Отдельные передачи всё ещё есть. Например, caller scalar-сборки:

```asm
    PUSH AF
    PUSH IX
    LD A, B
    CALL make_pair
    LD C, B
    LD B, A
    POP IX
    POP AF
    ; затем подготовка и CALL consume
```

Поэтому «tuple slots» не означает zero-cost CALL. Польза здесь — исчезновение
объектных копий и более дешёвая передача значений; сохранение живого x/y уже
включено в стоимость.

Два ABI × три режима × (49+73) входов = 732 native и 1464 raw/final VM
наблюдения. Raw MIR строится до Grace/pipeline оптимизаций, после выбора
исследуемого ABI. Strict host C89 (`cc -std=c89 -pedantic-errors`) независимо
подтвердил обе серии результатов. Опциональный `MINZ_C89_CALL_ARTIFACT_DIR`
сохраняет исходники, raw/final MIR, ASM/BIN и каждый замер; обычный тест
не пишет эти артефакты в репозиторий.

Эти проверки закрывают distinct wide CALL и измеренный scalar transfer slice.
Глобальные pointer relocations и строгая интеграция оставшихся PR ещё впереди.

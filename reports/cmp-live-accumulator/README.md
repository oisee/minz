# Сравнение сохраняет уже живой A

Когда правый операнд byte comparison уже находится в A, CP lhs не меняет A. Backend теперь распознаёт этот случай до materializePendingAcc, устанавливает reversed predicate и сохраняет нужную форму условного перехода. Это устраняет ненужные scratch save/reload/restore. Допуск исключает константы, bit-pattern, signed ordering, пары и wide operands; остальной путь сохраняется.

В точном forEach модуле Grace BIN61→58B; ordinary57B. Остаточная разница1B не объявлена исправленной. Полный исходный forEach со всеми independent VM/native входами и порядок стадий range прошли38,334с. Первый вариант без guards дал TestPopcountZ80 FAIL; сохранённый лог объясняет причину, окончательный вариант исключает этот паттерн. Полный MIR2 окончательного варианта PASS66,668с.

after сохраняет восемь ASM/BIN/MIR снимков начального положительного случая; на этом исходнике окончательные guards не меняют матч. Исходные57/61 продукты сохранены отдельно в foreach-size-audit. Матрица измеряет байты; такты здесь не измерены. Полный pipeline350149ad работает на прежнем immutable executable и не включает эту backend правку.

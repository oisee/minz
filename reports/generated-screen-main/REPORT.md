# Original generated customer/declarative whole-main screens

Неизменённые screen_customer.nanz и screen_declarative.nanz исполняются целиком после настоящего @screen generation: init, PBO render, PAI, пользовательский main postprocessing. Independent DSL/default/layout/field-state model заморожена b58a71d4 до исполнения. Сценарии: Customer F8 defaults; Customer Enter/NOVA/F8; Declarative TAB/F8; Declarative Esc cancel. 4×3режима×rawVM/finalVM/native=36 whole-main runs PASS3.297s. VM stdout558/1045/844/424 байт. Полная RAM, title pointer relocation, focus/field values и buffers проверяются; после короткого NOVA прежние bytes 'Corp' за NUL сохраняются согласно реальному bounded line-write.

Native исполняет настоящий generated _scr_puts_padded ASM с BDOS2 — не host substitution. API entry нормализуется в logical string+width event, а реальные emitted char bytes сравниваются с independently padded output. Customer terminal externs явно связаны test-owned unique RET linker slots; настоящий ABI argument homes, return stack и source HALT используются. Declarative imported render ASM выполняется тоже реально: native coordinates минимум2digits, VM terminal host protocol decimal без leadingzero. Эти два expected outputs заморожены раздельно ffd1c11f до завершения native import execution. Для cancel logical VM27 соответствует fixed native bytes27,97: CP/M ESC decoder потребляет следующий byte и возвращает27. Native queue/ledger отдельный freeze fa1696ec, лишние BDOS reads отказываются.

Runtime boundaries явные. VM моделирует source-defined paddedASM contract и реальные imported terminal API, остальные unbound ASM calls получают отказ. Native BDOS1/2 handlers обслуживают только реальные imported API/padding execution, остальные неизвестные calls/fetch/writes отвергаются. Все generated helper bodies/main сохраняются; unlinked/linked ASM, actual COM, HIR, raw/final MIR, events/stdout и BDOS ledger retained. Native images: customer ordinary2193B/Grace2201B; declarative ordinary2836B/Grace2844B. Mutable writes ограничены declared globals/buffers/spill/real bounded stack; image/other64KiB сохраняются.

Compiler/source bug здесь не найден. Initial customer-edit RAM diagnostic выявил обязанность oracle сохранять default suffix за новым NUL, модель финального видимого field NOVA не менялась. Initial title repeated-events diagnostic оказался observer entry alias с ASM loop label: native execution внутри одного API теперь отмечается только один раз до realreturn. Frozen source/expected bytes не подгонялись под compiler output; scope runtime distinctions взяты из actual contracts. Plain strings не переписывались; RuntimeCPM/stdlibTUI не менялись. ALV/SQLite report остаются следующим отдельным whole-main scope.

Manifest фиксирует source/model/spec/import identities, все expected и actual artifacts, test harness. Каждый payload tracked с SHA256; share сохраняет complete packet. Full pipeline/CLI не повторялся, coordinator владеет общими gates.

## 1. PL/M-80 → HIR → MIR2 → Z80

### 1a. Source

```plm
SUM: PROCEDURE (N) BYTE;
  DECLARE N BYTE;
  DECLARE (S, I) BYTE;
  S = 0; I = 0;
  DO WHILE I < N;
    S = S + I;
    I = I + 1;
  END;
  RETURN S;
END SUM;

CLASSIFY: PROCEDURE (X) BYTE;
  DECLARE X BYTE;
  IF X < 10 THEN RETURN 0;
  IF X < 100 THEN RETURN 1;
  RETURN 2;
END CLASSIFY;
```

### 1e. Gap analysis: PL/M constructs

| Construct | Status | Note |
|-----------|--------|------|
| BYTE variables | ✓ | Full support |
| DO WHILE / IF THEN / RETURN | ✓ | Verified |
| EXTERNAL PROCEDURE | ✓ | Maps to @extern |

**30 instructions.**  Hand-written reference: **10 instructions** (+200% overhead).

```z80
; ── hand-written reference ──────────────────
process:           ; HL=buf, C=n
    LD B, C
.loop:
    LD A, (HL)     ; x
    ADD A, A       ; x*2
    CP 6           ; x*2 >= 6 → x*2 > 5
    JR C, .skip
    CALL emit
.skip:
    INC HL
    DJNZ .loop
    RET
```

**Loop body trace** (chain fusion):
- `(HL)→C=x`, `ADD A,A→A=x*2`, `LD C,A→C=x*2`
- `LD A,5; CP C`: C flag if `5 < x*2` (i.e. `x*2 > 5`) → jump to emit ✓
- Dead stores at function entry (zero-offset ptr+0) removed by Phase 4 DSE

## 3. Nanz Features NOT YET in HIR/MIR2

| Feature | Status | Blocker |
|---------|--------|---------|
| struct field assign (`p.x = v`) | ✗ panic | `lowerStmt` missing `FieldExpr` target |
| struct field read (`p.x`) | ✗ panic | same |
| global variables | ✗ panic | HIR lowerer doesn't resolve global scope |
| switch statement | ✗ panic | sealed-block bug in mir2 join creation |
| enum values | ✗ | Not in HIR AST yet |
| string literals | ✗ | Not in HIR path |
| @print / @define | ✗ | MinZ-only (parked) |
| SMC / RST optimization | ✗ | MIR1-only (parked) |

**Fix effort:**
- Global variables: ~1h (add `globals map` to lowerer, resolve in `lowerExpr`)
- struct fields: ~2h (add `OpField` emit in `lowerAssignStmt` + `lowerExpr`)
- switch: ~1h (trace sealed-block sequencing in `lowerSwitch`)

## 4. Code Quality Gap vs Hand-Written Z80

| Benchmark | Nanz-compiled | Hand-written | Overhead |
|-----------|--------------|-------------|----------|
| sum (u8 loop) | 18 instr | 9 instr | +100% |
| forEach (call) | 17 instr | 6 instr | +183% |
| chain (map+filter+forEach) | 30 instr | 10 instr | +200% |

**Root cause of all overhead:** Register allocator spills ClassGeneral virtuals
and u16 pairs through `$F0xx` memory-backed pseudo-registers instead of keeping
them in B/C/D/E/H/L. This adds 2× `LD r,(addr)` + `LD (addr),r` per live variable
per loop iteration — accounting for 70–80% of all excess T-states.

**Fix:** Phase 4 — copy-coalescing + register-first allocation for ClassGeneral.
Estimated improvement: 3–5× T-state reduction on loop-heavy code.

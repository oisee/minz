# Ручной FAT12: измеренный ориентир для lowering

Это ручной Z80, а не output MinZ или sccz80. Native-стенд использует только sccz80 binary/map importer для загрузки вручную собранного образа. Ожидания и 64 входа взяты из неизменного C benchmark; проверяются результат, объявленные области памяти и PC/SP. VM-выполнение ручного ASM не заявляется.

- same-caller: прежний ABI MinZ HL/IY → HL и прежний compiler-generated execute(); 135 B / 19 776 T.
- hand-caller: HL/DE → HL и ручной execute(); 121 B / 13 696 T.
- текущий MinZ C/Nanz: 167 B / 32 000 T.

Полный модуль включает те же 67 байт данных. Оба native прогона PASS. Это не доказательство глобальной оптимальности и не полный домен всех 16-битных cluster values.

Человек сохраняет исходный cluster в BC, сдвигает DE для cluster/2, складывает оба слагаемых прямо с базой HL, читает low/high в E/D через INC HL и меняет DE/HL местами. В C остаётся parity. Затем нечётная ветка делает четыре SRL H / RR L; чётная маскирует только H. Компилятору это подсказывает последовательное word-read, нормализацию адресов, byte-pack fusion и выбор ABI с учётом caller. Исходный алгоритм не изменён.

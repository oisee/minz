# NC: оригинальный FAT12 browser на VM и Z80

Неизменённые main и FAT12 module с замороженным образом диска прошли raw/final VM и собранный Z80 в трёх режимах. Навигация Down/Up/Esc даёт **1453 ожидаемых события**. Все глобальные данные и все 64 КиБ native RAM проверяются независимой моделью, с точными исключениями для spill и фактически использованного стека. [Результаты, замеры и ограничения](../../docs/grace-integration-310/README.md).

Нагрузка содержит два файла и одну директорию, читает секторы 0 и 2. Просмотр и удаление файлов не проверяются. Модель хвостов буферов форматирования выведена из исходника отдельно от исполнения VM.

Исходник, диск и события заморожены в `493d250f`, модель памяти — в `cc01d4bf`, проверки — в `12a07168`. Неудачные пробы компилятора и стенда сохранены в checkpoints и пакетах 303–309. Физический CP/M ещё не проверен.

# NC whole main: подготовка независимой нагрузки

До исполнения заморожены точные исходники, FAT12 image (8 секторов), три directory entries и клавиши Down/Up/Esc. Ожидаются три кадра с выбором 0/1/0, count3 и panel height4. Образ читается только по фактическому disk API в исходном main. Полный terminal oracle, raw/final VM и native proof ещё не выполнены; эта запись не меняет статус корпуса.

# SALV native grid — CP/M implementation and evidence

Base5fa997de8 contains reviewed frontend-services v3. The unchanged frozen final
report examples/abap/zfleet_csv_alv.abap SHA50a48e0726154b3d37115bfdcd09d4f6222c7c2e3380293128cb489c75fb7979
opens the F4 picker, reads real FLEET.CSV, constructs the typed fleet table and
opens a native80x24 grid. Factory emits no display/copy/I/O: it binds table base
and its live count. Display operates on the current table value.

The declared compiler-known reference subset accepts exact named FACTORY and
parameterless receiver DISPLAY. Handles have no general object runtime. Factory
inside control flow, procedure/event escape, unknown receiver/method/parameters,
elementary/deep line types and oversized layouts are refused. Straight-line
rebinding is static; display reads the binding at that source point. Admission and lifecycle tests cover unknown/duplicate/wrong-section arguments,
reference alias/escape, procedure/conditional binding, live APPEND/CLEAR and
repeated display with two independent handles.

Column offsets/storage lengths derive from checked structure metadata. c cells
use min(max(storage length,heading length),20) display columns, left aligned,
with deterministic clipping; storage is untouched. Signed i32 cells reserve11
columns and are right aligned. Every data byte outside ASCII32..126 renders as
'.', including NUL/ESC/CR/LF/high bytes. Headings are uppercase, left aligned and
clipped to cell width. At most16 columns and total1+sum(width+1)<=80 are admitted.

Layout: title row1, border2, headings3, border4, eighteen row slots5..22, border23,
help24. Unused slots are blank. Up/Down move1, Page keys18, Home0, End=max(0,count-18).
Movement clamps to that range. CSI and SS3 arrows/Home/End are supported.
Enter is ignored; q/Q/backspace/ESC/F3 exits.
Escape continuation uses a finite4096-poll budget. Return resets cursor/style.

Layout/cell formatting/number conversion/scrolling run in shared compiled Nanz.
Only CP/M platform adapters emit VT100; common code calls screen_begin,
goto(x,y),screen_end plus byte output and nonblocking key poll. Agon VDP requires
separate real VDU adapters; raw ANSI portability is not claimed.

Milestone proof: raw MIR2 VM, optimized MIR2 VM and native Z80 match the independent
FLEET screen and actual table storage/count. Native BDOS traps deliberately clobber
primary registers; only record/key/byte I/O is supplied by the provider. The native
application uses incoming SP0080, returns PCF100/SP0082, preserves its return word
and resident canaryA5, and closes the input file/restores DMA80. COM40,257 bytes,
image end9E41, resident stack9A41..9E41, measured minimum SP9DE5 (92bytes used).
CLI and native-harness COM bytes are identical. Actual MZE runs the same program
with F4 Down Enter Enter then Back and returns to the OS. Coordinator captured a
real continuous X11/MZE grid video. The final reviewed v3 retains the same
40,257-byte program; its only change from v2 is a refusal-test diagnostic assertion.

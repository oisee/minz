# Постоянный сдвиг с живым аргументом вокруг CALL

Проверяется настоящий внешний Z80-caller: PUSH исходного аргумента,
CALL shifted, POP BC, ADD HL,BC, RET. ABI входа берётся из текущего
распределения регистров. Оракул x*((1<<N)+1) modulo65536 сохраняет
зависимость от исходного значения после вызова (Nanz Book v7, глава 3).

| Сдвиг | Caller T до / после | Модуль, байты до / после |
|---|---|---|
| 1 | 88 / 84 | 9 / 8 |
| 4 | 121 / 117 | 15 / 14 |

PFCCO greedy/PBQP × Grace off/on × два сдвига: восемь вариантов,
каждый baseline/selected проверен на всех 65536 входах, включая PC/SP.
Пересылки ABI, сохранение x и реальные CALL/RET входят в такты.
Модульные размеры относятся к Nanz-программе с двумя функциями;
внешний caller одинаков в обеих сборках и сохранён отдельно.

Исходный Nanz `return shifted(x)+x` встроен компилятором, поэтому
его собственные такты остались 40/73; уменьшается отдельная shifted.
Эти данные не смешиваются с внешним CALL. Победа PFCCO поверх таблицы
не заявляется: матрица подтверждает совместимость четырёх режимов.
Проверка использует небольшие функции, не полный FAT12 runtime.

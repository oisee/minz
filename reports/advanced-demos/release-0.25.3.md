## Что войдёт

Tetris использует единое описание целого Nanz-спрайта. Специализированные
процедуры стирания и вывода запекаются при компиляции, адреса размещаются до
HALT, изображение пишется прямо на экран. Типизированный ByteWave добавляет
покачивание на один пиксель внутри клетки; игровая геометрия остаётся прежней.

На старте доступны три режима:

| Клавиша | Гравитация |
|---|---|
| 1 | Один пиксель за два кадра |
| 2 | Один пиксель за кадр |
| 3 | Плавно меняющаяся случайная скорость, отдельный воспроизводимый RNG |

Контроллер режима 3 суммирует движение за каждый прошедший кадр до ввода.
Каждый пиксельный шаг проверяет контакт; hold/hard-drop не замораживают кривую
скорости, а оставшийся бюджет не переносится на новую фигуру после lock.
Генератор фигур не зависит от генератора скорости.

Цветные строки и целые формы описаны декларативно на Nanz. Общие immutable
row-kernels уменьшают дублирование; Tetris запекает только нужные X-фазы
0/1/7. Публичный восьмифазный API сохраняется. [Код и подробные проверки](tetris/variable-speed/README.md).

## Уже проверено на кандидате

- 18 игровых Z80/ULA-сессий: фиксированные уровни, переменная скорость,
  hold/lock и очистка 1/2/4 линий. Сверяются независимое состояние игры,
  реально показанные кадры поля, RNG, INT и PC/SP.
- 1630 физических сценариев в трёх режимах: 4890 native Z80 и 9780 raw/final
  VM-вызовов; проверены форма, поворот, пиксельная фаза, границы, контакт,
  порядок строк и вся память вне разрешённых spill/стековых записей.
- Новый product BIN совпадает с проверенным candidate BIN: ordinary 31820
  байт, конец 0xFC4C, 20 байт перед прежней границей стека. Grace добавляет
  12 байт. Исправленный source-пакет также даёт тот же BIN без stdlib из
  рабочего checkout.
- 78 декодированных GIF-кадров совпадают с последовательными native PNG и
  имеют длительность 20 мс. MP4 сохраняет полную проверенную сессию, включая
  повторы кадров, без интерполяции.
- Шесть native rc2-пакетов: 66 исполняемых сценариев и шесть проверок
  сохранности SAVE. Образы и экраны совпадают, файловые SHA256 и ZIP CRC
  проверены. Платформенный Tetris-сценарий — menu smoke; полная игровая
  проверка выполнена отдельно выше.

Тяжёлый ввод и lock могут занимать два кадра, очистка линий — три. Это не
обещание 50 FPS для каждого события. Layout-запас мал и проверяется при
сборке. Публичный compiler backend этим релизом не объявляется безошибочным.

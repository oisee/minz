# Ограниченный pointer-walk поиска приземления

Кандидат от 15 октября 2026, поверх attribute-walk checkpoint 36ec46cc.
Не включён в main или опубликованные пакеты 0.25.1.

Ghost query проверяет, на сколько может опуститься каждая из четырёх клеток;
ответ — минимум этих расстояний. Для следующих клеток не нужно сканировать
дальше уже найденного минимума. Board — принадлежащая игре обычная RAM:
сокращение чтений не меняет внешних событий. Независимый оракул по маскам
форм по-прежнему проверяет приземление повторными целыми позами.

Короткий Nanz helper один раз вычисляет адрес первой нижней клетки и идёт
по колонке шагом 10 байт, ограничиваясь полом и текущим минимумом.
Счётчик убывает до нуля; результат — доступный лимит минус остаток.
Caller допускает x<10 и y<20; при нулевом лимите память не читается.

```nanz
fun column_gap(x:u8,y:u8,limit:u8)->u8 {
    let row:u8=y+1
    var count:u8=BOARD_H-row
    if limit<count {count=limit}
    var source:^u8=ptr(u16(&board)+u16(row)*10+u16(x))
    var remaining:u8=count
    while remaining!=0 {
        if source^!=0 {break}
        source=source+10 remaining=remaining-1
    }
    return count-remaining
}
```

# Дешевле готовить изменённые строки Tetris

Кандидат от 15 октября 2026, ветка `feat/tetris-span-pointerwalk`.
База — `0571a4f4`. Это следующее ускорение после шестиплатформенного
кандидата: уже выложенные ZIP на `0571a4f4` его ещё не содержат.

Разметка диапазонов атрибутов держала два указателя, счётчик, фазу и
координаты живыми внутри большого цикла. Z80-код много сохранял и загружал
временные значения. Разделение на короткую клеточную функцию уменьшает
давление на регистры; стоимость CALL и сохранений учтена в полном модуле.

```nanz
fun pixel_mark_cells(xs: ^u8, ys: ^u8, phase: u8) {
    var xp: ^u8 = xs
    var yp: ^u8 = ys
    var count: u8 = 4
    while count != 0 {
        let x: u8 = xp^
        let y: u8 = yp^
        pixel_mark_cell(x, y)
        if phase > 1 { pixel_mark_cell(x, y + 1) }
        xp = xp + 1
        yp = yp + 1
        count = count - 1
    }
}
```

`pixel_mark_cell` уже существует: проверяет границы и расширяет левую/правую
границу изменённой строки. Дробная фаза добавляет нижнюю строку. Этот код
готовит metadata до HALT; запечённые пары draw/erase не менялись.

| Полный модуль с launcher | До, байт | После, байт |
|---|---:|---:|
| Обычный | 24 868 | 24 563 |
| Grace Speed | 24 885 | 24 580 |
| Grace Size | 24 866 | 24 561 |

Обычная сборка заканчивается на 0xDFF3, стек зарезервирован в FC60..FCE0.
Два простых варианта pointer walk без helper были отвергнуты: они добавляли
9/8 байт и 120/90 тактов на два прохода разметки в наблюдаемых шагах.
Одной замены индексирования на указатель недостаточно для пользы.

Полная выбранная проверка прошла за 123,429 секунды:

- `TestTetrisPixelPhysicsNativeVM`: независимая физика на native Z80 и raw/final VM;
- `TestTetrisDirectTemporalMachine`: полные фактически показанные ULA-сцены,
  RAM/PC/SP/INT и отрицательный контроль tearing;
- `TestTetrisDirectMainMachine`: оба уровня × три режима через настоящий main,
  клавиатуру и IM2 до game-over, с независимым состоянием игры;
- `TestTetrisDirectLineClearMachine`: девять seeded-сессий с очисткой 1/2/4 линий.

В этих main-сценариях все три soft-drop действия занимают один принятый INT
во всех шести вариантах. Left/right также занимают один INT, кроме второго
уровня Grace Speed. Повороты и hold остаются в диапазоне 1–2 INT;
обычный lock — 1–2, seeded line clear — до 3. Это ограниченный сценарий,
не гарантия бюджета для любого ввода. Спокойное падение сохраняет выбранную
скорость и проверенные последовательные полные кадры.

Изменение времени подготовки меняет фазу на некоторых поздних шагах
реальной игры. Поэтому отдельные замеры разных build нельзя считать
сравнением одинаковой позы; независимый game model проверяет каждую
получившуюся траекторию. Профиль по ближайшей метке также не равен
инклюзивной стоимости функции. Итоги выше используют полный размер и
границы шагов main.

CLI BIN побайтово совпадает с BIN полного native main. Встроенный SNA
обновляется из этой сборки; его SHA и исходник фиксирует
`minzc/cmd/mzx/demos/tetris.provenance.json`.

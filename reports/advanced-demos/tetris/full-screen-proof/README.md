# Tetris: проверка всего показанного экрана

15 октября 2026. Отдельный кандидат `experiment/tetris-full-screen-proof`,
поверх точного product-коммита `c3574329`. Проверка пока не интегрирована
в main; она не меняет игру, компилятор или зафиксированные native-пакеты 0.25.3.

Прежний наблюдатель сравнивал каждый фактически показанный кадр поля 80×160.
Ожидаемые previews и меню проверялись после завершения вывода по памяти.
Теперь direct-наблюдатель сравнивает все 256×192 пикселя активного экрана:
меню, стенки стакана, next/hold, уложенные клетки и падающую фигуру.
Это позволяет обнаружить ошибку интерфейса или смешанный кадр вне поля.

Ожидаемая сцена строится независимо. Положение и содержимое поля поступают
из host-модели физики; previews — из независимых форм фигур. Стенки,
координаты и подписи заданы спецификацией интерфейса. Глифы берутся из
исходного Spectrum ROM, общего входного ресурса, а не из полученного экрана.
Generated renderer, его таблицы и экранная память игры не используются
как ожидаемое изображение. Сравнивается именно ULA framebuffer после
реальных fetch, а не screenshot конечной RAM.

| Проверка | Результат |
|---|---:|
| Native-сессии: три уровня и очистка 1/2/4 линий в уровне 3; три режима компилятора | 18 PASS |
| Полные показанные активные экраны | 4008 |
| Всего выполнено аппаратных кадров | 4710 |
| Шаги main, сверенные с независимой физикой | 1461 |
| Время матрицы | 157,901 с |

Ordinary, Grace Speed и Grace Size сохраняют прежние проверки состояния,
порядка публикации, INT, PC/SP и измеренного бюджета lock/line-clear.
Все шесть ordinary-сессий исполняют один и тот же BIN; он побайтно равен
результату настоящего `scripts/build_zx_tetris_demo.sh` для релизного кандидата:
31820 байт. [Числа, SHA и receipts каждой сессии](checkpoint.json).

Два исследовательских мутанта намеренно испортили только интерфейс:
нижняя стенка получила неверный цвет, а next-preview — отсутствующий bitmap.
Оба отвергнуты сравнением полного fetched-экрана. Это ожидаемые отказы
контрольного эксперимента, не падения основной игры. Временный тест мутантов
сохранён локально и не включён в обычный тестовый набор.

Сравнение начинается после первой завершённой публикации и продолжается
до возврата main после game-over. Переходы первоначальной очистки/меню
и внешний бордер здесь не сравниваются с пиксельным оракулом. Исторические
shadow-fixtures сохраняют прежний контракт проверки только поля. Сравнение
всех видимых пикселей не заменяет независимые проверки памяти: невидимые
bitmap-биты под чёрными атрибутами могут не влиять на изображение.

```sh
cd minzc
MINZ_TETRIS_MAIN_EXPORT=/path/to/local/evidence \
  go test ./pkg/pipeline \
  -run '^(TestTetrisVariableSpeedMainMachine|TestTetrisVariableSpeedFixedLevelRegression|TestTetrisVariableSpeedLineClearMachine)$' \
  -count=1 -v
```

Исходники, ASM/BIN, полные логи и контрольные мутанты сохранены локально
в `grace-reports/2026-10-15/tetris-full-screen-proof/`; на шару CI-файлы
не копируются. Плавная скорость и игровой релиз описаны
[в отдельном отчёте](../variable-speed/README.md).

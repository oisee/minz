# Tetris: border timing diagnostic

Диагностическая сборка текущего direct-screen renderer, 14 октября 2026.
Это предварительная сборка: режимы сложности 1/2 и стабильное движение
по пикселю каждый кадр ещё не завершены. Обычная release-сборка не содержит
этих цветных меток.

Запуск в существующем Windows-пакете MinZ:

```powershell
.\mzx.exe --model 48k --snapshot "PATH\tetris-border.sna"
```

Linux/macOS:

```sh
./mzx --model 48k --snapshot /mnt/safe/minz/releases/diagnostics/tetris-border/tetris-border.sna
```

Клавиши: стрелки — движение, Z — поворот, X — сброс, C — hold.

Цвета бордера:

- Синий: размещение, проверки и подготовка адресов.
- Пурпурный: подготовка атрибутов и диапазонов.
- Голубой: ожидание INT через HALT.
- Красный: точное стирание предыдущей фигуры.
- Жёлтый: обновление неподвижного поля.
- Зелёный: вывод запечённой фигуры.
- Белый: commit/атрибуты поля и previews.
- Чёрный: commit завершён.

Положение полосы показывает положение луча во время этапа. Для оценки
срока записи сравнивайте его с Y изменяемой строки, а не с верхом всего
экрана. OUT и вызовы диагностики добавляют время; итоговый бюджет проверяется
на сборке без меток. Бордер даёт наглядный сигнал, независимая проверка
ULA подтверждает отсутствие смешанных кадров.

MP4: 250 последовательных аппаратных кадров, 50 кадров/с, без интерполяции
и пропуска кадров. Это запись текущей диагностики, а не заявление о
постоянном 50-Гц движении фигуры. PNG — кадр 249 с полосами этапов.
Захват использует фактически отрисованный ULA framebuffer, включая бордер,
а не картинку, восстановленную из памяти после кадра.

## Проверки текущего renderer

Обычный вывод движущейся фигуры после HALT: 6 806–6 848 T-states в текущей
матрице. Полное обновление поля: до 58 168 T-states. Из 58 проверенных
отображённых кадров два остаются смешанными при полной смене поля; все три
положительные политики пока FAIL. Отрицательный контроль корректно
обнаруживает смешивание. Подготовка адресов до HALT остаётся дорогой:
около 40 000 тактов для новой фигуры и 24 500 для старого стирания.
Следовательно, выпуск как завершённого плавного renderer пока преждевременен.

Запись headless была исправлена: раньше она восстанавливала 256×192 из
итоговой VRAM и игнорировала бордер. Теперь берётся исполненный ULA frame;
`--no-border` только обрезает его. Регрессионная проверка сохраняет отличающийся
от VRAM пиксель, цвет бордера и обе геометрии изображения.

Создание отдельного исходника:

```sh
python3 scripts/zx_tetris_border.py examples/zx/tetris_playable.nanz build/tetris-border.nanz
```

Сам генератор не изменяет исходник игры. Метки удаляются из финального
дистрибутива выбором обычного исходника; отдельный runtime-переключатель
и вызовы OUT в release не требуются.

# Tetris: лишний пересчёт атрибутов перед HALT

15 октября 2026. Исследовательский кандидат; в релиз 0.25.2 не включён.

Тяжёлый шаг Tetris состоит из физики, подготовки и публикации. Профиль
четырёх очищаемых линий показал 199 073 T вне функции ожидания HALT.
Из них 47 410 T относятся к `pixel_restore_span`: Nanz пересчитывает
атрибуты по таблице цвета. Это измерение одного сценария, а не всех игр.

При обновлении поля сначала восстанавливались полосы старой и новой
фигуры, затем весь изменённый диапазон. Если второй диапазон полностью
покрывает первый, первая операция избыточна. Проверенное условие:

```nanz
if direct_refresh!=0 {
    if (pixel_first_row<direct_board_first)|(pixel_row_limit>direct_board_limit) {
        pixel_restore_attributes()
    }
    pixel_prepare_board_attributes(direct_board_first,direct_board_limit)
} else {pixel_restore_attributes()}
```

Проверка использует охватывающий диапазон всех отмеченных полос. Если хотя
бы одна полоса выходит за обновляемые строки, прежнее восстановление
сохраняется целиком. Атрибуты новой фигуры накладываются после восстановления
поля, как прежде. Публикация и экранные маски не меняются.

На ordinary-сборке полного main:

| Сценарий | До, T без HALT | После, T без HALT | Разница |
|---|---:|---:|---:|
| Четыре очищаемые линии, шаг 5 | 199 073 | 195 065 | −4 008 |
| Обычный lock, шаг 101 | 114 232 | 114 424 | +192 |
| Обычный lock, шаг 115 | 100 745 | 100 935 | +190 |

Полный BIN вырос с 24 269 до 24 323 байт: +54. Гистограммы аппаратных
кадров не изменились: тяжёлые lock-действия по-прежнему занимают два,
данная очистка — три кадра. Эти цифры не доказывают устранение задержек.
Атрибуция профиля — ближайшая предшествующая метка функции; ожидание HALT
исключено из приведённых сумм.

Шесть native-вариантов — main на уровне 2 и fixture четырёх линий,
каждый ordinary/Grace Speed/Grace Size — PASS за 35,582 с. Проверены
независимая игровая модель, память поля, фактические ULA-кадры и порядок
row-kernels, возврат со стеком и INT. Это ограниченное покрытие кандидата;
уровень 1 и остальные line-clear fixtures этим прогоном не заявлены.

Первый, более сложный вариант отбрасывал отдельные покрытые строки.
Он вырос на 169 байт и добавил 2 232 T обычному lock шагу 101. Сохранили
его локальные протоколы, но не выбираем этот вариант.

Вывод для продолжения: общий табличный проход и подготовка диапазонов
остаются более крупными источниками затрат. Этот кандидат даёт небольшой
обмен скорости на размер, а не законченный 50-Гц бюджет всех действий.
Релизный коммит `867281fc` и его проверенные образы остаются неизменными.

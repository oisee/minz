# Пиксельное покачивание Tetris: эксперимент размещения

15 октября 2026. Исследовательская ветка; в main и релиз не включено.

Четыре запечённых блока получают один ByteWave-сдвиг −1/0/+1 пиксель.
У блока остаётся прозрачный край в один пиксель: непрозрачные пиксели
геометрически остаются внутри исходной восьмипиксельной клетки. Это
основание для будущего игрового оракула, а не проверка сохранности поля.
Физика остаётся в клетках и дробной вертикальной фазе; renderer готовит
адреса и фазу до HALT и использует прежнюю пару draw/erase.

Общий восьмифазный генератор оказался слишком большим. Прототип
`pixel_phases 0 1 7` запекает только нужные фазы и отвергает остальные
перед патчем. Перестали автоматически добавлять per-row effects при
whole-sprite pixel shifts; для них требуется явное `row_shifts` или `effect`.
Эта смена API пока экспериментальна, существующие row-effect fixtures
потребуют явной опции. Публичное допущение фаз и изображения ещё не
проверены независимыми VM/native тестами.

Измерения используют настоящий zx_tetris_entry.a80 с ORG 0x8000.
Стек зарезервирован с 0xfc60; oversized-кандидаты не запускались.

| Вариант | Полный BIN | Конец, exclusive | Влезает до стека |
|---|---:|---:|---|
| Исходный прямой renderer | 24269 | 0xdecd | Да |
| Все 8 фаз и per-row методы | 50755 | 0x14643 | Нет |
| Все 8 фаз, сдвиг блока целиком | 34811 | 0x107fb | Нет |
| 3 фазы, boolean guard | 33722 | 0x103ba | Нет |
| 3 фазы, short-circuit guard | 32362 | 0xfe6a | Нет |
| То же, Grace Size | 32374 | 0xfe76 | Нет |

Последний вариант заходит в резерв стека на 522 байта. Сборка не является
игровым checkpoint. Grace Size добавил 12 байт вместо сокращения. Следом анализируется вклад
повторяемых kernels/обвязки. Затем обязательны независимые admission,
RAM/PC/SP/IFF, игровая семантика и все фактически показанные ULA-кадры.

Полные source/ASM/BIN и журналы находятся локально в grace-reports/2026-10-15.
Промежуточный 34811-byte ASM/BIN был перезаписан последующим probe; его
измерение сохранено в журнале. Последующие probe используют отдельные каталоги.

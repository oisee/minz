# Пиксельное покачивание Tetris: запечённый Nanz, проверенный Z80

15 октября 2026. Проверенный checkpoint в исследовательской ветке.
В main и релиз пока не включён; общий восьмифазный API интегрируется отдельно.

![78 настоящих ULA-кадров на 50 Гц](tetris-wobble-50hz.gif)

Это 78 последовательных кадров настоящего Z80/ULA, по 20 мс. Все пиксели
декодированного GIF совпадают с исходными PNG; интерполяции и ускорения нет.
Вся записанная сессия проходит независимые проверки игры и поля.
[Протокол, отпечатки и 15 native receipts](checkpoint.json).

## Один тип формы, четыре независимо подготовленных блока

```nanz
import zx.sprite
import zx.sprite_effect

@zx_sprite_instances("FallingBlock") {
    size 8 8
    instances 4
    erase
    pixel_phases 0 1 7
    pixels "........"
    pixels ".######."
    pixels ".######."
    pixels ".######."
    pixels ".######."
    pixels ".######."
    pixels ".######."
    pixels "........"
}
```

Каждый экземпляр имеет отдельные подготовленные адреса/фазы и отдельный
кэш старого стирания. Пиксели и маски остаются данными в инструкциях.
Типизированный `ByteWave` задаёт сдвиг всего блока −1/0/+1 пиксель; физика
работает с прежними координатами клеток и дробной вертикальной фазой.
Непрозрачные шесть пикселей при этих сдвигах остаются внутри исходной
восьмипиксельной клетки. Независимый оракул вычисляет маску 0xfc/0x7e/0x3f
из своего счётчика времени, проверяя поле вместе с уложенными клетками.

`pixel_phases` — экспериментальная специализация: запекаются только
указанные фазы 0..7; остальные отвергаются до патча. Для отдельных
смещений строк теперь нужно явно задать `row_shifts` или `effect`.
Действующий байтовый API сохраняет прежние единицы.

## Почему первый вариант не помещался

Настоящий загрузчик начинается с 0x8000; стек зарезервирован с 0xfc60.
Oversized-кандидаты не запускались.

| Вариант | Полный BIN | Влезает до стека |
|---|---:|---|
| Исходный прямой renderer | 24269 | Да |
| Все 8 фаз и per-row методы | 50755 | Нет |
| Все 8 фаз, сдвиг блока целиком | 34811 | Нет |
| 3 фазы, boolean guard | 33722 | Нет |
| 3 фазы, short-circuit guard | 32362 | Нет |
| То же, Grace Size | 32374 | Нет |
| Общий target для кэша и патча строки | 31534 | Да |
| Текущий вариант с полным board fast path | 31561 | Да |

Явное вычисление target один раз убрало 828 байт: stage_on прежде повторял
`address-0x4000+base` для кэша и setter. Текущий ordinary BIN заканчивается
на 0xfb49: 279 байт до резервированного стека. Native минимальный SP
измеряется в каждом receipt, отдельно от размера программы.

## Проверка нашла и закрыла пересечение с лучом

Нормальная игра сначала прошла оба уровня во всех трёх режимах, но
seeded очистка 1/2/4 линий обнаружила промежуточное поле. Полная
публикация всё ещё проверяла диапазон на каждой строке; последняя строка
заканчивалась примерно на 54771-м такте, позже прохода луча.

Для диапазона 0..20 теперь вызывается уже существующий полный board
renderer с тем же порядком строк и callback вставки фигуры. Частичные
диапазоны сохраняют прежний путь. Границы допущены до HALT. После
исправления все девять line-clear вариантов прошли ULA-оракул; негативные
кадры, диагностика и прежние артефакты сохранены локально.

## Границы подтверждения

- Два уровня × ordinary/Grace Speed/Grace Size: шесть main-сессий с
  независимой физикой, полем, фактически показанными кадрами, INT и PC/SP.
- Очистка 1/2/4 линий × три режима: девять main-сессий. Проверены входы
  и порядок row-kernels, вставка фигуры, стек и все fetched field frames.
- 168 native и 336 raw/final VM вызовов finite-phase draw/cached erase:
  все фазы, границы, полная RAM с точным staging/SMC и ограниченным стеком.
  После сохранения erase отвергается новая фаза 2; publish запрещён,
  старые адреса/фазы стирания остаются верны.
- Малформированные дескрипторы отвергаются для формы и instances.
  Отрицательный literal отвергает сам синтаксический разбор meta block.
- Общие регрессии: 729 native/1458 VM signed-row bounds, полная pixel-wave
  сцена и arbitrary-buffer tile/sprite публикация прошли.

Некоторые lock/input действия остаются двухкадровыми; line-clear может
занимать три кадра. Этот checkpoint не объявляет всю игру 50 FPS и не
доказывает произвольные эффекты. Следом — интеграционная проверка всех
вызовов библиотеки, main и обновлённые игровые пакеты шести платформ.

Полные source/ASM/BIN, исходные PNG, MP4, журналы и отрицательные кадры
сохранены локально в grace-reports/2026-10-15. Промежуточный 34811-byte
ASM/BIN был перезаписан прежним probe; его измерение осталось в журнале.

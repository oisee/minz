# Проверка интеграции measured specialization

CI [38717350316](https://github.com/oisee/minz/actions/runs/38717350316)
проверял PR #153 на исходнике `178a8bba4ea9c9f37c6c87022dc8a6aa6a5dc112`.
Default output sweep сравнил 838 исходников и 326 выходных файлов.
Единственное различие — `examples/zx/tetris_playable.nanz`.

Baseline-компилятор разбирал текущую библиотеку `zx.sprite`, в которой теперь
используется compile-time host `meta_variant`, и падал при lowering метафункции
с `value type void incompatible with u8`. Candidate-компилятор знает этот host
и успешно выдаёт ASM. Это ожидаемая несовместимость новой библиотеки со старым
компилятором. Sweep не проверяет поведение игры; независимое игровое и ULA
покрытие описано в [общем checkpoint](../objective.md).
Проверка остаётся включённой и сохраняет различие в своих артефактах.

Advisory lint нашёл пять замечаний: необработанные ошибки очистки временного
каталога и выбора assembler target, две строки ошибок с заглавной буквы и
сигнатуру `WriteByte`, похожую по имени на `io.ByteWriter`. Ошибки теперь
обрабатываются, сообщения приведены к обычному стилю. Сигнатура сохранена:
она реализует интерфейс памяти Z80; локальное исключение govet объясняет
именно это обязательное имя и аргументы.

Эти изменения не меняют данные спрайта или выбранный BIN/SNA. Для нового
исходника результаты main CI и финального релизного прогона ещё предстоит
получить; шестиплатформенный прогон frozen candidate `f6b5123b` остаётся
проверкой той конкретной версии.

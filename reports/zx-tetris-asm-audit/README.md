# ZX Tetris: аудит встроенных примитивов

Оба исходника допускаются как executed-native-asm-bounded. Это native исполнение на плоской Z80 памяти с явными границами; оно не заменяет VM/runtime контракт для inline ASM и не обещает произвольную игру или настоящее ZX оборудование.

| Примитив | Доказательство |
| --- | --- |
| LD (HL), A в текущем zx_poke | Инициализация, все игровые экраны и full RAM после каждого кадра; исторический исходник использует обычную запись по указателю |
| IN A, (FE) | Девять keyboard сценариев, точные адреса пяти строк и число чтений |
| OUT (FE), A | Начальный чёрный бордюр и все 40 смен цвета при game over; полный 16-битный port учитывает A в старшем байте |
| HALT | Контролируемое продолжение игровых кадров и 120 flash HALT, фактическая CALL/return authority и возврат main |
| LD A, (HL) в неиспользуемом zx_peek | Отдельно 4 адреса (0,6000,7FFF,FFFF) × 256 значений × 3 режима = 3072 native чтения; фактический HL/A ABI, PC/SP и full RAM без записей |

Последний тест — PASS (2,060 с). Main game-over replay и его 72 сохранённых артефакта относятся к коммиту aba293de; новый тест не изменяет production/source. [Полный lifecycle](../zx-tetris-game-over/README.md). Все девять main сценариев подтверждены отдельно.

Каталог: independent/bounded VM/Z80 153, отдельно native ASM 21, CP/M 10, SMC 2. Inline ASM audit 0. Agon MOS 5, pending oracle 2 и иной memory model 1 остаются. Итого 194 пути. Это изменение допуска двух конкретных исходников по проверенным workloads. Multi-line, T-spin, wall kicks, произвольная игра, ROM, contention, interrupt и hardware остаются за пределами доказательства.

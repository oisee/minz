# Профиль видит циклы, созданные структурным emit

У сгенерированных `hir_while` отсутствовала привязка к исходнику. Они попадали
в `UnmappedLoops`, поэтому наблюдения не содержали их счётчиков, а строгая
загрузка профиля отказывала. Это пробел между DSL и профильным поиском,
воспроизведённый после исправления привязки имён: [до](before.json).

Теперь структурные statements получают происхождение от настоящего вызова
`@build()`/`@fill()` в исходнике. В `SourceLocation` явно записаны имя
метафункции и SHA256 её эффективного Nanz-определения. Это адрес вызова,
а не выдуманная строка `while` в пользовательском исходнике.
[Карта после исправления](after.json).

Два снимка одного генератора различаются ordinal; два вызова — byte offset.
Повторный разбор даёт ту же карту. Изменение импортированного определения
меняет его отпечаток даже при неизменном caller. Источник и контекст профиля
проверяются прежним строгим механизмом; смена отпечатка отклоняет сохранённый
профиль. Некорректные метаданные определения также отклоняются.

Новые проверки используют четыре сгенерированных цикла: каждый имеет один
вход и три итерации; профиль успешно загружается обратно. На настоящем
`hw.fill` профиль фиксирует 1 вход / 256 итераций, вся 64-КБ память совпадает
с независимым оракулом. Input-HIR карта сохраняется при включённом Grace.
Прежние структурные ASM baseline остаются побайтно теми же.
[Направленные проверки](regressions.txt): Nanz, HIR и pipeline — PASS;
pipeline 2,931 с. Полные [HIR 42,119 с и Nanz 30,693 с](full.txt) — PASS.
[Воспроизводящий probe](probe.go) запускается через `go run` из модуля minzc.

Вложенный структурный вывод из текстового `emit` с временным lexer по-прежнему
остаётся unmapped: позиция временного текста не выдаётся за адрес в исходном
файле. Синтетические замены HIR без явного происхождения также не получают
автоматической привязки. Метаданные дают атрибуцию, а не доказательство
безопасности оптимизации. Нового выигрыша тактов здесь не заявляем.

Все доступные исходники, карты, профиль и логи сохраняются на шаре:
`/mnt/safe/minz/grace/2026-10-14/structured-emit-provenance/manifest.json`.

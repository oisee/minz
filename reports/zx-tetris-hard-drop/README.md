# ZX Tetris: hard drop, фиксация и очередь

Оба неизменённых main исполняются на Z80 в ordinary, Grace Size и Grace Speed. SPACE на кадрах 1/2 и 4 проверяет отдельное нажатие, удержание без повторного сброса и повторное нажатие. Первая I кладётся на строку 19, вторая — на строку 18. Поле получает восемь клеток в колонках 3–6; счёт равен 74 (38 + 36). После двух spawn текущая фигура — Z (4), следующая — J (6), RNG=7246. На кадре 31 y=0, timer=28.

Шесть запусков, 186 кадров, 930 чтений клавиатуры — PASS (6,753 с). Независимая модель задаёт клетки фигур и цвета литералами, проверяет столкновение, призрак, очередь PRNG, счёт, таймер и всю RAM после каждого кадра. Пустое поле в прежних сценариях заменено моделью состояния поля. Модель явно отвергает сценарий с полной строкой или gravity-lock: для них потребуется собственный оракул, они не принимаются как отсутствие эффекта.

Старые idle/movement/rotation/soft-drop сценарии перепроверены отдельно. Исходники сохранены в zx-tetris-initial-main/frozen. ASM/BIN, MIR, allocation и снимки RAM находятся на шаре в compiler-reports/zx-tetris-hard-drop/executed.

Проверка ограничена 31 кадром. Line clear, gravity-lock, hold, game over, wall kicks и произвольная игра ещё не доказаны. HALT wake задаётся тестом, Hooks отсутствуют; ROM, реальные прерывания, contention и hardware не моделируются. Категория inline ASM audit сохранена.

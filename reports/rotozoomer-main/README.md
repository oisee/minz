# Rotozoomer: полный main на VM и Z80

Полный исходный main рисует и сохраняет 32 кадра 256×192. Ожидаемые пиксели получены отдельной моделью signed16 с явным модульным переполнением и делением к нулю; оси и палитра заморожены до запуска. Проверка исполняет raw/final VM и собранный Z80 в трёх режимах.

Для каждого запуска проверяются все 1 572 864 pixel calls, координаты и цвета, порядок init/шести palette calls/save и 32 точных пути файлов. Внешние callbacks имеют тестовый контракт сохранения регистров кроме u16 результата; физическое устройство и файловая запись PNG здесь не заявляются. Native проверяет full RAM с исключениями только для точных spill и использованного стека; PC/SP должны вернуться к загрузчику.

**PASS 91,570 с**: все 32 кадра прошли raw/final VM и native во всех трёх режимах. Ordinary, Grace Size и Grace Speed дают одинаковые 2656 байт и 5 523 758 850 тактов на полную анимацию; время callbacks не включено. Проверки памяти и PC/SP прошли. Выигрыша Grace здесь нет. Каталог пока не обновлён. Тест находится в `minzc/pkg/pipeline/original_rotozoomer_main_test.go`; артефакты выводятся через `MINZ_ROTO_MAIN_EXPORT`.

# Десятичная печать: native gate включён по умолчанию

`TestDecimalPrintSourceNative` теперь использует `t.TempDir()`, когда постоянный экспорт не задан. Раньше обычный полный pipeline пропускал исполнение этой проверки; экспорт остаётся доступен через `MINZ_DECIMAL_PRINT_ARTIFACTS`. Production-компилятор не изменён.

На checkpoint 5d90b7aa экспортная проверка прошла для CompileHIRSteps и CompileHIRWithOptions. Оба собранных варианта вывели `099`, вернули 273, восстановили SP=0xf000 и остановились на ожидаемом PC; полный harness занял 853 T. Ожидание `099` и 273 зафиксировано в тесте до исполнения и также сверяется с raw VM. Это один небольшой Nanz-исходник, не полный домен форматтера и не CP/M-приложение. Более широкое CP/M decimal покрытие хранится отдельно в `pascal-closure-pfcco-speed`.

После изменения оба теста Compile/Native прошли без export-переменной. Команда: `go test ./pkg/pipeline -run '^TestDecimalPrintSource(Compile|Native)$' -count=1 -timeout=5m -v`. Лог сохранён в `default-check.txt`; export-пакет содержит точные ASM/BIN, источник, выход, ожидаемый выход и регистры. Уже работающий полный бинарник 5d90b7aa этой правки теста не содержит и продолжает работать без перезапуска.

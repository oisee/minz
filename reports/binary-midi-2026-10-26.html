MIDI по байтам.
На Nanz. До Z80.

Идея из мира Erlang — явно описывать двоичные поля и состояние потока — превратилась в работающие библиотеки. Проверили их на четырёх настоящих MIDI из Autosiril.

От идеи до машинного кода

Nanz source→Meta VM + frontend→HIR→MIR2→Z80

Для битовых схем meta-функция генерирует обычные структуры, сдвиги и маски. Автоматы потока написаны обычным Nanz: поля состояния, ветвления и вызовы. Новых инструкций HIR для этого не понадобилось.

import stream.bit_fields
@bit_fields("Header") {
    bits "kind" 3
    bits "flags" 5
}
// Header { kind:u8, flags:u8 }
// kind = (raw >> 5) & 7; flags = raw & 31

Сейчас схема содержит до восьми полей по 1–8 бит, всего 8 или 16 бит. Это небольшой работающий DSL; общий синтаксис Erlang и декларативный язык автоматов ещё не реализованы.

Что умеет SMF-декодер

Музыкальные события

SMF 0/1, PPQN, running status, одно- и двухбайтовые channel messages, meta events и сегменты F0/F7 SysEx.

Настоящий поток

Подача по байту или chunks. Выдача одного события, пауза до ack(), точное число принятых байтов, отдельный EOF.

Границы и ошибки

Длины треков, VLQ до четырёх байт, вместимость payload, EOT, обрыв потока и переполнение 32-битного времени.

События приходят в порядке треков файла. Это декодер: объединение дорожек по времени, синтез звука и проигрывание — следующие отдельные слои. SMF 2, SMPTE, RMID и live MIDI wire protocol пока не поддерживаются.

Остановиться — тоже часть протокола

Миниатюрная иллюстрация: delta=0, NoteOn, C4, velocity=100. После последнего байта автомат удерживает готовое событие. Следующий байт ждёт подтверждения потребителя.

132 байта: состояние автомата + событие + дескриптор + 64-байтный payload примера. Счётчики потребителя, стек и compiler spills считаются отдельно. Тестовый harness использует payload на 512 байт; вместе с кодом, статическими данными и вспомогательными функциями он занимает 10 005 байт.

Payload копируется в память вызывающего кода и доступен до ack(). Слишком длинное событие получает ошибку до записи payload. Время проверено вплоть до 4 294 967 295; дальнейшее переполнение отвергается.

Что досталось всему компилятору

Нагрузочный пример выявил и помог исправить потерю метаданных локального ^Struct, потерю элементов импортированных простых enum и пропущенную зависимость &local при разбиении функций в HIR. Для scalar cells и массивов разбиение теперь отказывается от интерфейса, который не может сохранить идентичность адреса.

Общие ByteView, ByteBuffer и ByteRing получили применение в декодерах. Пакетный автомат проверен на всех 128 разбиениях потока и всех восьми позициях головы кольца. Это пригодится другим frontend после подключения их адаптеров; Crystal bridge пока не предоставляет этот MIDI API.

Возможный следующий шаг — удобный DSL для переходов автомата и потребитель MIDI, который объединяет дорожки по времени. Из OTP здесь интересны явные состояния, ограниченные очереди и правила отказа. Полноценный OTP runtime не добавлялся.

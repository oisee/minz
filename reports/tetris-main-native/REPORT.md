# Полный исходный Tetris CP/M: исправление строк и конечный сценарий

Сценарий `z,q,a` теперь проходит на assembled Z80 во всех трёх режимах: ordinary, Grace Size и Grace Speed. Выполняется весь `main` исправленного оригинального модуля вместе с настоящими импортированными ASM-функциями `stdlib/tui/render.nanz`. Независимая модель требует два кадра, поворот, выход и финальное подтверждение: ровно 326 байт ANSI/текста, пустую доску, rotation=1, game_over=1, timer=tick=2, RNG=28984, score=0. Все значения глобального состояния и вся RAM проверяются; исключены только фактический используемый стек и явно выделенные compiler spill slots. Код и остальные байты должны сохраниться.

До исправления plain SString (Book v7 §18.1: length+data) передавалась в `tui_puts`, читающую до NUL. Оригинальный запуск выводил length byte, соседние литералы и poison RAM, не завершал сценарий. Это сохранённый отрицательный опыт, а не исправленная семантика языка. В отдельном source commit исправлены только 3 CP/M и 7 TUI literal arguments этого NUL API: добавлен `c`. Алгоритм игры и импортированная библиотека не менялись. `literal-correction.json` фиксирует каждый контракт, а old/new snapshots и `freeze-corrected.json` явно разделяют идентичности. Исправленный CP/M SHA: `91b2a3cc7be3a309b17b6655ed7e1757b70b89ac67985cad0bcc3a5e2f55c23d`.

Исторический negative checkpoint использовал JP main; он обнаруживал string overrun до возврата и потому не доказывал корректность loader termination. Этот старый payload/NEGATIVE.md/манифест сохранён без переписывания. Недостижимый success tail в новом negative test удалён.

Обычный emitter завершает `main` инструкцией RET. Проверочный loader поэтому использует CALL main, затем DI/HALT в 0x0107; SP должен восстановиться до 0xeff0. Только переход в CP/M BDOS по адресу 5 обслуживается тестом: функция 1 возвращает очередной замороженный символ, функция 2 записывает E в вывод. Неизвестные BDOS, лишний ввод, чужой instruction fetch и другой HALT отвергаются. Это явная граница runtime, не замена игрового main вызовами helpers. BIN целого модуля с loader: ordinary 4608 байт; размеры других режимов сохранены в summaries.

Публичный RuntimeCPM по-прежнему отказывает этому полному ASM-модулю; ошибка проверяется и сохранена. Raw/final VM не исполняет ASM этой библиотеки, поэтому whole-main VM успех не заявляется. Полный TUI main с внешним terminal runtime здесь не исполнен; семь исправленных аргументов подтверждены контрактом `mzv/tui_host.go`, но runtime claim остаётся отдельной работой.

Исторические family/sequence эксперименты продолжают использовать прежние замороженные исходники. Их SHA/freeze/старые отчёты не переписаны. Exact прежний family test сохранён в `historical-family-test.go.txt`; проверка Go AST сравнивает все model types/functions и model controls с текущими декларациями, исключая только сам execution harness. Sequence проверяет свой прежний model dependency SHA по этому immutable artifact. Изменена только загрузка historical source snapshots. Текущий исправленный исходник не выдаётся за прежний unchanged-source proof.

Проверки: historical sequence 27 552 native + 55 104 raw/final VM вызовов, все шесть source/mode комбинаций PASS, общий scoped gate 36.216 s. После дополнительной точной проверки HALT и artifact metadata: whole-main + negative reproduction + independent model identity/controls PASS 3.064 s; после удаления недостижимого negative success tail terminal gate PASS 3.623 s. Повторный большой family run не запускался: модель проверена на идентичность и historical sequences повторены. Полный pipeline/CLI остаётся ответственностью coordinator.

`manifest-negative.json` остаётся неизменным историческим манифестом. Новый `manifest-proof.json` включает corrected payloads, текущие тесты и архив модели; все перечисленные файлы tracked, включая ASM/COM/MIR.

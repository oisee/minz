# Полный размер модуля sum_array после исправления +1

12 октября 2026 года, compiler checkpoint `194b739c`. Единственное оставшееся падение `TestProfileGuidedSumVMZ80` было несовпадением закреплённого размера: 203 байта вместо 201 при неизменных 69 тактах для n=0.

Исходный HIR, raw MIR и финальный MIR обеих реализаций совпадают побайтно с предыдущим retained reference. ASM diff изменяет только цикл печати в **main**, который не вызывается при замере sum_array. Исправление unit RHS (`2dbe4355`, research `59f88d33`) заменяет ADD HL,DE на копирование DE в HL и INC HL. Отсюда +2 байта в обеих полных программах; тело sum_array неизменно.

| Вариант | Ранее, байт | Сейчас, байт | Такты |
|---|---:|---:|---|
| Original | 201 | 203 | 69 + 191n |
| Pointer walk | 251 | 253 | 241 + 37n; n=0: 232 |

Равенство на границе добавляет 7 тактов, fallback/wrap: 258 + 191n. **Все коэффициенты прежние.** `TestMeasureLoopCostModel` повторно подтвердил 1022 сценария всего u8-домена длин, быстрый путь, равенство, fallback и wrap. Проверки используют независимую сумму, VM и собранный Z80, точный возврат PC/SP, фактические ветви и отслеживание обращений к памяти: лишние чтения, записи и zero-trip reads отклоняются. PASS 22,427 с; evidence связывает все строки с binary SHA.

После обновления только размеров и EvidenceID исходный профильный тест проходит, включая raw VM/native результат, сохранность входа, lineage, применение решения, обе стороны порога полезности, Size и отрицательные случаи устаревших source/model/options. Выбор не изменился: основной профиль берёт pointer walk, короткий и Size сохраняют original.

В `before/` и `after/` сохранены ASM/BIN/HIR/MIR, отдельные diff. `loop-cost-evidence.json` содержит полный новый замер, `loop-cost-model.json` — его параметры; измерения и решения — из focused regression. Лог первого отказа сохранён. Полный pipeline/CI не перезапускался; этот PASS относится к двум указанным проверкам.

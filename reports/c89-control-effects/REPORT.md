# Sequenced C89 control-statement effects

Eight valid, include-free C89 functions are frozen in `source.c`/`freeze.json` before production edits. They use unsigned-byte arithmetic, bounded limits 0..32, and complete selector byte domains. No expression has unsequenced conflicting effects. ISO C90 6.6.4 (selection), 6.6.5 (iteration and continue), 6.3.2.4 (postfix), and the full-expression sequence points determine the expected order. GCC `-std=c89 -pedantic-errors -Wall -Wextra` independently evaluates all 710 frozen workloads in `gcc-results.txt`; native tests also cross-check their separately implemented arithmetic model against that file. This is a regression packet, not a new original showcase corpus row.

Before: all eight controls fail raw MIR (`before.txt`). While/for postfix conditions evaluate once and then loop forever; do tests mutate locals before the first body; false if executes a postfix return effect; if/else executes both arm effects; for/do continue skips its required step/test. This comes from the shared pending-statement queue being drained by parent/child statements without ownership.

After: each lowered statement owns its pending effects. If/else conditions execute before the branch, and each selected body owns its effects. Side-effectful while/for tests are inside a `while(true)` test-before-body block, including the final failed test. Do tests remain after each body. For initialization effects execute once. Continue re-lowers its nearest enclosing for-step or do-test effects into that selected arm before an ordinary Continue, using fresh temporary names; nested while clears that prelude. Break/return bypass post/test. This avoids introducing synthetic goto joins into the existing SSA machinery.

Evidence: 710 actual source calls per ordinary/Grace Size/Grace Speed mode, 2130 native calls total and 4260 raw/final VM calls. Independent return/state models, exactly one expected public global write (or zero when not selected), every RAM byte except actual private stack/spill writes, code integrity, return PC and restored SP all pass. No output or external runtime is used. Full source, raw/final MIR, actual ASM/BIN and all observations are retained in `execution/`. Nested-loop nearest-continue ownership, break bypass, and an effectful if selector also pass independent native assertions and raw/final models in three modes (`nested-tests.txt`).

All C89 tests pass, including full FatFS HIR→MIR verification. The full slow pipeline/CLI suites were not duplicated. The earlier switch-arm fix remains tested through the full C89 package.

Remaining adjacent gap: logical &&/|| and ternary expression lowering still collects RHS/arm pending effects unconditionally (lowerExpr branches in lower.go). This packet fixes statement-owned simple-condition effects; it does not claim all conditional-expression semantics. A separate focused fix should place RHS/ternary effects in their chosen expression arm rather than broadening this donor silently. C switch fall-through limitations are also unchanged.

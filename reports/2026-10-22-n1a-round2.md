# N1a round 2: critic corrections

This revision addresses F1–F4 independently of the P36 backend fix. It uses no
function/benchmark-name admission rules.

## Changes

- F1: the typed aggregate pass rejects a bool in tuple slots 3 or 4. Return
  promotion, parameter splitting and local scalarization share this restriction.
  Two-bool and ordinary byte structs remain eligible. The comment identifies P36
  as the condition for lifting this temporary guard; C legacy gates are unchanged.
- F2: parameters with nonzero `RegClass` or `SMC` retain their ABI. Generated
  typed scalar parameters use `__scalar_`, removing the C prefix from Nanz ABI
  comments without changing C compatibility temporaries.
- F3: README, ADR and the historical report scope the earlier byte-identical C
  result to the measured corpus. Single-bit equality canonicalization can change
  C assembly. New execution coverage includes signed char bit 7 (positive and
  negative masks) and short bit 15 using `-32768`, including inverted polarity.
- F4: missing tuple measurements print `n/a`; successful C-only comparisons say
  `PASS (C only; tuple n/a)`, supplying no tuple-pass evidence. A Python test
  covers the missing-row case.

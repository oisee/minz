# C89 short-circuit and conditional expression effects

Frozen exact include-free source117fc1ba and compressed GCC output precede this fix. ISO C90 6.3.13/14/15 requires a sequence point after the first logical/conditional operand and evaluation of only the selected RHS/arm. Unsigned-byte updates wrap modulo256; no expression contains unsequenced conflicting effects. GCC C89/pedantic evaluates all frozen inputs; the test independently implements byte recurrences and cross-checks all recorded GCC rows.

Before: unselected RHS/ternary increments are hoisted into a shared pending queue. Raw MIR failures are retained in before.txt. After: lowerControlExpr isolates each RHS/arm effects; lowerConditionalValue emits them inside its selected If block, sharing only a result slot. Effect-free arms retain CondExpr. Logical comparisons explicitly have Bool type and return canonical0/1 (not raw nonzero bytes). First operand effects precede branch selection. Nested expressions and effectful loop conditions compose with statement-scope isolation.

# Nanz-ротозумер для галереи — 2026-10-01

В [rotozoomer.nanz](../examples/nanz/rotozoomer.nanz) каждый экранный пиксель берёт цвет из повторяющейся текстуры 16×16. Координаты вычисляются фиксированной матрицей `[a b; -b a] / 256` относительно центра экрана. 32 пары `a` и `b` проходят полный оборот с плавным изменением масштаба и возвращаются к исходной фазе. Внутренний цикл продвигает `u` и `v` сложениями, без умножения на каждом пикселе. Графика выводится через canvas-host MIR2 VM.

`main` строит 32 кадра 256×192 через `mzv`, а [сборщик GIF](../scripts/build_rotozoomer_gif.py) сохраняет их в исходном порядке с задержкой 160 мс на кадр и бесконечным повтором. Обратного хода и дублированного первого кадра нет: переход 31→0 продолжает вращение тем же угловым шагом 11,25°. Сборщик требует Pillow. Из корня репозитория:

```sh
make -C minzc mzv
python3 scripts/build_rotozoomer_gif.py --output build/rotozoomer.gif
(cd minzc && go test ./pkg/nanz -run '^TestRotozoomerGallery$' -count=1)
```

Тест запускает тот же Nanz-файл через MIR2 VM и сравнивает пиксели выбранных кадров с [GIF](../media/rotozoomer.gif); дополнительно проверяет число кадров и повтор фазы 0 на шаге 32. Это доказательство текущего HIR→MIR2→VM пути. Z80 backend и скорость на настоящем Spectrum этим тестом не подтверждаются.

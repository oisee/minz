# Original terminal/ABAP whole-main screens and register-renumbering fix

Полные неизменённые tui_screen.nanz и abap_screen.nanz проверены по independent model, замороженной adbbe7b7 до выполнения. Четыре конечных сценария: tui layout→a→exit; ABAP TAB→F8 (focus1), Enter→line MAT-42→F8 (buffer mutation), Esc→cancel. Wholemain вывод, каждый ordered terminal call и полная память моделируются независимо; исходные алгоритмы, buffers и методы сохранены. 3 режима ×4 сценария ×rawVM/finalVM/native=36 запусков. Output bytes420/842/879/423. Сценарии отдельно фиксируют пустую Plant, Count10, title pointer relocation и точные untouched buffer tails. Все real source hashes сохранены в freeze.json.

Найден actual Grace miscompile: TAB/F8 в rawVM и ordinary печатает Count10, final Grace печатает byte148 вместо49 ('1'). До RenumberRegs opt.mir сохраняет правильные incoming n/started; после renumber shared CFG argument slices обработаны дважды и подменены const48/add values. Grace join redirects допускают alias аргументов двух рёбер. Minimal shared/overlapping slices test тоже падает на неизменённом backend (got2 want1). Исправление отдельным commit1ab5e8e9 отделяет owned argument arrays и ASM input/output arrays перед перенумерацией; overlapping/cross-function shared slices теперь имеют независимые mappings. Source/oracle не менялись. before-renumber.mir, after-renumber-broken.mir и negative logs сохранены.

После исправления все36 wholemain executions PASS1.038s; финальный repeat PASS1.031s. Полный MIR2 package PASS90.801s. Нативный terminal runtime явно связан test-owned linker: один RET slot на каждый original extern label, actual allocated argument homes, u8/u16 return conventions, real stack return. Tui source tailcallsreturns: CALLmainloader→HALT0x107. ABAP emittedmain ends DI/HALT, поэтому loader JPmain и проверка именно original main HALT/SPeff0; предыдущая ошибочная CALLloader assumption отдельно записана в before diagnostic. Native mutation tracker отказывает всемwrites вне globals/buffers/explicitspills/boundedstack; image/full64KiB проверяется. VM uses exact mzv-equivalent ANSI80x24, prequeued key returns, interactive read_line cursor-show/hide plus NUL-truncated write. Foreign CString object reads/line write addresses/extra input/return PCs запрещены. Это full source runtime adapter proof, не claim незалинкованного публичного BIN или RuntimeCPM.

Plain strings не исправлялись: original callsites уже CString. SQLite/generated @screen/report/ALV сюда не включены; это следующая семейная задача. Parent catalog сохраняет остальной корпус. Freeze paths нескольких model artifacts первоначально абсолютны; test переводит только exact первоначальный prefix в repo-relative lookup, сохраняя прежние hash/bytes.

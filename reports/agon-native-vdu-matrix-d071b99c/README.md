# Full-device native VDU matrix

Three unchanged graphics examples × ordinary / HIR Grace Size / HIR Grace Speed. Public CLI MOS ADL executables run with real eZ80 CPU, MOS and full VDP firmware. A transparent research proxy records and forwards unchanged VDU bytes. An independent source-level text/layout/navigation model supplies every expected application byte; a single MOS boot and following echo/prompt are required. Four negative controls reject mutated text, prefix insertion, missing return and repeated boot.

Hello and Demo receive SDL A. NC receives nine Down, Enter, Up, Enter, Escape through the normal SDL→PS2→MOS path. Key timing and capture C sources, tools/hashes, compiler build provenance, source/library, ASM/BIN, wire streams, expected bytes, output logs, commands and observer exits are retained. Observer timeout124 means MOS remains running; it is not an application error. Exact return evidence comes from the following MOS echo/prompt.

Research tool: scripts/agon_native_vdu_replay.py. Required paths are compiler, Fab emulator, MOS, original VDP library, local SDL installation and a new output directory. summary.json lists completed cases and scope; manifest.json covers retained files. This establishes bounded command/text agreement in all three modes, not independent framebuffer/RAM/SP or hardware execution. No speed comparison is claimed.

# Полный домен sum-array и выбор arena: актуальные ожидания

Полный pipeline `350149ad` выявил два устаревших ожидания; производственный код в этом изменении не меняется.

Для sum-array повторно измерены 1022 сочетания длины u8 и адресов: обычный адрес, последний быстрый адрес, guard fallback и wrap. На каждой точке исходный и преобразованный HIR проверены независимой суммой по модулю 256, неизменностью входной памяти, VM и собранным Z80. Модель совпадает с существующим `sum-array-z80-coalesced-edges-v5` в profile_guided_sum_test.go: original `69 + 191n`, fast `241 + 37n`, zero `232`, equal-boundary +7, fallback `258 + 191n`. Старый тест всё ещё содержал прежние entry/iteration costs; формулы обновлены, строгая проверка полного домена PASS.

Для frozen arena training (`test_split`) варианты off/greedy/PBQP дают 1121/1130/1122 байта и 3818/3906/3766 тактов. Size выбирает off, Speed выбирает PBQP; прежнее утверждение о ничьей неверно. Frozen heldout не участвует в выборе и даёт 7133 такта для обоих выбранных вариантов; дополнительного heldout-выигрыша здесь нет. Независимое ожидание возвращаемых результатов 0 сохранено.

# ZX Tetris: game over, мигания и возврат main

Оба неизменённых исходника исполняются целиком на Z80 в ordinary, Grace Size и Grace Speed. На нечётных кадрах нажимается SPACE, на чётных — отпускается. Двенадцать фигур сбрасываются в x=3. На кадре 23 очередь пытается создать J на занятом поле: game_over=1. Счёт 234, строк не очищено; следующая фигура S, RNG=5515. Поле, текущая фигура поверх него, экран и все globals независимо проверены после каждого игрового кадра.

После выхода из игрового цикла проверены все 20 циклов мигания: красный бордюр, три HALT, чёрный бордюр, три HALT. Итого 120 flash HALT и 40 смен цвета, плюс исходный OUT(0). Для каждого HALT проверена фактическая CALL/return authority. Каждая инструкция продолжения проверяется на отсутствие изменений RAM вне точных spill и использованного стека. Main возвращается на исходный PC=7003, SP=F000; дополнительного чтения клавиатуры нет. Всего 115 keyboard reads в одном запуске.

Шесть запусков — PASS (5,383 с). Это подтверждённый полный жизненный цикл на одной конечной нагрузке, а не доказательство произвольной игры. Прежние восемь сценариев перепроверены отдельно. ASM/BIN, MIR, allocation, экран, RAM каждого контрольного кадра и возвращённые registers/RAM сохранены на шаре в compiler-reports/zx-tetris-game-over/executed. Исходники заморожены в zx-tetris-initial-main/frozen.

Multi-line clear, изменение скорости после 8 строк, T-spin и wall kicks ещё не доказаны через main. HALT wake задаёт тест; реальные прерывания, ROM, contention и hardware не моделируются. Hooks отсутствуют. Категория inline ASM audit пока сохраняется с явно расширенным объёмом доказательств.

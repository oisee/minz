# EX для умирающей пары перед постоянным сдвигом

Обычный Z80 backend теперь может перед постоянным word-сдвигом заменить
две byte-пересылки DE↔HL на EX DE,HL. Допуск проверяет фактические живые
vreg после инструкции, включая половинки обеих пар. Живой исходный
аргумент или соседний байт запрещает обмен; остаётся прежняя копия.
Метаданные физических копий обеих пар инвалидируются после EX.
Общие emitMov и parallel-copy правила не изменяются.

Восемь native-вариантов: два направления × отсутствие живого источника,
живое слово, старший байт, младший байт. Каждый проверен на всех 65536
входах, включая независимый результат word-сдвига, сохранение источника
в памяти и PC/SP. Существующие shift-проверки прошли. Полный MIR2 пакет прошёл за 127,673 с; все 355 fast pipeline тестов
прошли в четырёх процессах. Интеграция и общий выигрыш пока не заявляются.

Это перенос полезного выбора из checked-кандидата в обычный backend,
чтобы простой случай не требовал opt-in таблицы.

Исходная `fat_byte_ofs` из неизменённого `stdlib/fs/fat12.nanz`
проверена для FAT12/FAT16 на всех 65536 аргументах в ordinary и Grace.
Оракул отдельно вычисляет x+x/2 либо 2*x modulo65536; проверяются PC/SP
и неизменность памяти вне стековой области. До/после относятся к
main #103 и этому emitter изменению. FAT16: 69→65 T; FAT12: 80→80 T.
Весь модуль ordinary: 9720→9716 B; Grace: 9908→9904 B.
Это проверка функции смещения на реальном CFG, не всего FAT runtime.

## Changes and regression evidence

`minzc/pkg/hir/lower.go:3089` (`lowerCond`) previously widened every literal and zero-extended narrow variables. `lowerExprForRet` at line 799 and direct call lowering also bypassed variable widening; memory and conditional boundaries had the same omission. The shared `lowerExprAs` conversion at line 2458 already supplies the needed `sext`.

Non-negative comparison literals retain their narrow unsigned type. Only negative literals need the wider comparison context. Unsigned variables also retain their existing comparison representation: physical zero extension already preserves their value. Creating explicit word registers for them changes allocation and can introduce extra moves, spills, and register-number churn.

Implicit signed widening is explicit HIR `sext` at returns (including multiple returns), signed call arguments (including typed indirect calls), local and memory assignments, addressable initializers, runtime array-element initializers, struct-field initializers, and conditional joins. Existing arithmetic uses `lowerExprAs`, which already sign-extends. Mixed signed comparisons use the wider operand width, with each narrow signed variable sign-extended first. MIR2 and the physical Z80 move helpers retain their existing instruction semantics; HIR supplies the conversion.

`TestSignedLiteralContexts` checks raw MIR2, production optimized MIR2, and assembled Z80. New cases cover implicit return, binding, reassignment, global and field storage, conditional values, function arguments and signed helper returns, mixed equality and arithmetic, and all six comparisons in both operand orders at signed boundaries. The previous test that expected `0 < i8(-2)` to be true now expects false. The existing pipeline mixed-width test sign-extends each source value independently in its oracle, including 24/32-bit cases. No new pipeline test function was added, so the profile registry needs no additions.

Red evidence (all exit 1):

- `.local/review1-size-red.log`: non-negative comparison constants become word constants.
- `.local/review1-widen-red.log`: returns, arguments, global assignments, equality and ordering lose the narrow sign.
- `.local/review1-storage-red.log`: conditional joins and field initializers lose the narrow sign.
- `.local/review1-unsigned-width-red.log`: the preceding local commit creates an unnecessary word register for an unsigned comparison variable.
- `.local/review1-return-conditional-red.log`: widening a return conditional before lowering its arms truncates -129 to 127. Return arms now convert independently to the declared result type.
- `.local/review1-fuzz-red.log`: the old signed oracle cannot evaluate a signed helper call.

Focused tests pass: `.local/review1-size-followup.log`, `.local/review1-pipeline-mixed.log`, and `.local/review1-return-conditional-green.log` (exit 0). The complete pipeline gate caught the conditional-return regression; it was repaired with a new raw/optimized/Z80 regression before final validation.

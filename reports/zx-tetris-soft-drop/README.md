# ZX Tetris: удерживаемая A и таймер гравитации

Оба неизменённых исходника запускаются целиком на эмуляторе Z80 в ordinary, Grace Size и Grace Speed. На кадрах 1–3 удерживается A: горизонтальная I опускается каждый кадр. На кадре 4 Q поворачивает её; на кадрах 20–22 A снова удерживается и опускает вертикальную I. Кадр 31 заканчивается на y=6, timer=9. Независимый расчёт следует порядку действий main: held-A устанавливает timer=30, затем тот же кадр увеличивает его и выполняет gravity. Отпускание A сохраняет обычный отсчёт.

Шесть запусков, 186 кадров, 930 реальных чтений keyboard ports — PASS (6,414 с). После каждого кадра проверены вся RAM, экран, ghost, previews, board, globals и таймер. Для стека исключён только реально использованный диапазон; для spills — точные области listing. Исполняется исходный ASM, Hooks отсутствуют. Предыдущие idle/movement/rotation сценарии повторяются отдельно.

Проверка ограничена первыми 31 кадрами и I на пустом поле. Lock, hard drop, hold, line clear, game over, другие фигуры и wall kicks ещё не доказаны. HALT wake задаёт тест; реальные прерывания, ROM, contention и hardware не моделируются. Категория inline ASM audit сохранена. ASM/BIN, MIR, allocation и RAM сохранены на шаре в compiler-reports/zx-tetris-soft-drop/executed.

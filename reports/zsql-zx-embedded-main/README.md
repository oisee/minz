# ZSQL со встроенным шрифтом: полный main на Z80

Исходный main после двух явных исправлений программы проходит CREATE/INSERT/SELECT и все 16 console prompts. Проверены 257 байт текста, реальные SQLite-команды и строки, оба значения колонок и каждый receive store. Native исполняет исходные ASM ввода и рисования; они не заменены host-вызовами. Независимая модель рисует ожидаемый экран из frozen текста и исходных DB glyph bytes. Сравнивается вся RAM, включая код и шрифт, кроме конкретных spill slots и наблюдаемого стека. Завершение — исходный DI/HALT с SP EFFE и loader return word 7003.

| Режим | Байты BIN | Такты до HALT |
| --- | ---: | ---: |
| Ordinary | 2137 | 318 613 |
| Grace Size | 2018 | 318 424 |
| Grace Speed | 2018 | 318 424 |

Grace уменьшает модуль на 119 байт и эту нагрузку на 189 тактов. Это прямое сравнение трёх режимов на одной frozen нагрузке; prospective selection и новые heldout этим тестом не доказаны. SQLite работает через тестовый портовый адаптер; её время не входит в такты CPU. VM inline ASM, физический ZX, ROM и contention не проверены.

Исправления исходника: ранее 40-байтовый буфер расширен до 61 байта для 60 символов и NUL; теперь шрифт дополнен glyph для ASCII 123..126. SQL-разделитель `|` имеет код 124, а прежний шрифт заканчивался на z (122), поэтому вычисленный адрес glyph выходил за таблицу. Сохранённый font-before FAIL получен проверкой независимой модели до native исполнения; это доказательство отсутствующего glyph в исходнике, не runtime compiler counterexample. Предыдущий источник сохранён.

Обе версии full main и все длины readline 0..61 повторены: шесть main запусков и 372 native helper вызова проходят. Остаток входа длиннее60 символов остаётся следующему prompt; весь набор control bytes не проверен. ASM/BIN, allocation/MIR, порты, команды, screen/RAM и SHA256 сохранены на шаре в `compiler-reports/zsql-zx-embedded-main/executed/`.

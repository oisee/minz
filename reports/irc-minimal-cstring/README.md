# Minimal IRC: правильный формат wire strings

Обычная строка Nanz — SString с байтом длины (Language Book v7, глава 18.1). `net_send` читает до NUL. Два исходных литерала поэтому отправляли длины и соседние строки. До исправления ожидание заморожено в `3af012d7`; negative replay сохранён в `ad445a33`.

Исправлены только два `net_send` литерала на CString. Raw/final VM и собранный Z80 исполняют реальный net_send с каждым фактическим pooled literal в трёх режимах. Исправленный результат — ровно NICK и USER с CRLF. Native net_write явно связан тестовым RET entry; фактический formal ABI, реальный возврат/SP, весь RAM/code проверены. PASS 0,123 с. Старый контрпример продолжает воспроизводиться.

Это entry proof, не полный сетевой main и не публичный network runtime. Весь main с 500 входными байтами остаётся следующим этапом; статус корпуса сохраняет эту границу.

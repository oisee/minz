# Прямой адрес в структурном masked store

Pointer-генератор sprite теперь передаёт вычисленный адрес непосредственно
в `hir_load`/`hir_store`. Промежуточная переменная `sprite_ptr` больше не нужна.
В lowering простого присваивания через постоянный указатель одинаковые
постоянные адреса используют один vreg. Чтения памяти остаются отдельными
и выполняются в исходном порядке; кэш действует только внутри одного
присваивания, без вызовов, callbacks и управляющих переходов.

Исходная прямая форма проигрывала сохранённому текстовому генератору:
смешанные маски 46→58 байт, 198→238 T. Повторное использование адреса
вернуло 46 байт / 198 T. Во всех девяти вариантах (три раскладки × ordinary,
Grace Speed, Grace Size) ASM совпадает с baseline. Это снятие регрессии
прямой формы, не дополнительное ускорение поверх предыдущего sprite PR.

Полный HardwareSprite-набор и сравнения baseline прошли за 7,668 с.
Проверяются память VM/Z80, PC/SP, маски, границы ZX, цепочки и full-machine.
Отдельные HIR-проверки сохраняют два чтения при одинаковом адресе,
различают разные адреса, не переносят кэш в следующее присваивание
и запрещают его через вызов функции. Общий fast checkpoint выполняется.

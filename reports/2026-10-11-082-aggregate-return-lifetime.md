Raw/final VM сохраняют ожидаемые значения. make возвращает HL адрес своей локальной ячейки и выпускает её INC SP перед RET; следующая функция получает ту же ячейку. VM OpAlloca добавляет память к heap и не выпускает её на RET, поэтому VM маскирует invalid native lifetime.

Book v7 chapter4 описывает обычные структуры/поля/методы, chapter7 обычные typed return. Явного правила lifetime struct-return там нет: не приписываем книге доказанное byvalue ABI. Но lowerStructLitAlloca прямо обещает support literals in return values; парсер/проверка допускают S-return/local binding без unsupported результата. Следовательно, принятую обычную программу нельзя молча компилировать в dangling-object behavior. Адресный lowering — деталь реализации, не source lifetime rule.

Конкретная реализация следующего шага:

1. Default struct-return ABI: каждый concrete StructTy return slot имеет caller-owned buffer полного layout size. В MIR Contract явная metadata для return-buffer slot/source return index/size/type; hidden pointer params отличимы от declared params. HIR CallableSignature сообщает то же canonical ABI, parser оставляет пользовательскую сигнатуру S и полный source context. Metadata входит в dump/JSON/clone/Verify/profile identity/fresh ownership checks, extern identity и indirect synthetic ABI. Нельзя пользоваться неявным совпадением имени hidden param.
2. Call lowering сначала выделяет caller-local result buffer (OpAlloca layout bytes), затем вычисляет пользовательские аргументы в прежнем порядке и передаёт hidden pointers + пользовательские args согласно fixed ABI. Физические hidden pointer homes — пары либо full16 spill, verified before emission; контракт optimizer может выбирать разрешённые пары только при сохранении hidden slots/size metadata. Result MIR value — caller buffer address, обычный scalar return pickup для него не нужен. Реальный CALL остаётся, возвращаемый HL может оставаться дополнительным совместимым pointer result лишь как redundant address, но не authority на callee local lifetime.
3. Return lowering оценивает исходный return expression ровно один раз, копирует значение bytewise в caller buffer, возвращает caller buffer identity. Нельзя просто переадресовать caller local binding на callee-owned address. Полный layout, nested structs и packed union bytes; ByteOffset не меняется. Copy op/byte sequence must preserve observable scalar access order and memory observer identity; no unsafe fusion. При потенциальном alias используем snapshot before writes или memmove semantics, включая target16 wrap. Это value copy, не глобальная static return slot (последняя сломала бы recursive/multi-call/held value).
4. Forwarding wrapper/return make(...) сначала получает buffer в own frame, затем копирует в outer caller buffer. Возможный tail-buffer forwarding — отдельная proven optimization. Recursion получает разные buffers в каждом frame; multi-return получает distinct buffer slots для struct components вместе с существующими scalar slots. Nested member returns копируют именно subobject layout. Direct, function address and indirect signatures share typed buffer contract; mismatched legacy pointers rejected до emission.
5. Explicit extern structs: require declared matching result-buffer ABI, not silently treating arbitrary native extern HL pointer as byvalue object. Public standard HIR/VM APIs maintain user-visible S result meaning; a VM bootstrap supplies hidden buffers internally rather than asking callers to supply extra unadvertised arguments. Controlled profiles/native workload entry adapters must do likewise or fail explicitly for unmodelled aggregate entry shape, never compare raw pointers as value-only oracle. Exact source/HIR/ABI/context fingerprint binds new ABI.
6. Optimizations guardrail: InlineTrivial and tailcall/constant-call/LUT use changed full contract and effects; moving copy/allocation requires explicit legality. Optional C89 PromoteStructReturns(ADR0025) may scalarize a bounded shallow subset, but cannot substitute for general default buffer ABI or make unpromoted path dangling.

Regression gates: unchanged frozen noninline make+intervening overwrite, two independent returns, mutate one returned local while other retained, return parameter/local/nested member; nested structs >4 bytes, multi-return struct+scalar, returning indirect call, recursion with independently live parent value; current Widemath all26 and impl-showcase exact original receiver paths. Raw/finalVM/native default/Speed/Size compare fields, state, stack/code and byte effects; subsequent CALL after both constructors mandatory. Existing original corpus candidate 50_impl_showcase covers receiver address/field use but no escaping return; Widemath W8 op_add/sub used through additional caller requires fixed lifetime. Do not mark original immediate W8 inspection as lifetime coverage.

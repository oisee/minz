# Проверка сохранности доказательств корпуса

Все 194 исходника каталога и его прямые ссылки сверены с SHA256. Затем проверены 85 упомянутых manifests и 4486 записей вложенных файлов: SHA256 и наличие в Git. Повтор: python3 scripts/audit_corpus_artifacts.py --output /tmp/corpus-artifact-audit.json. Это аудит сохранности перечисленных доказательств, не повтор исполнения программ, не проверка полноты всех неупомянутых файлов и не доказательство общего PASS. Shared copy проверяется отдельно при сохранении пакета.

# Цветной MARA/ZSQL: статический отчёт на ZX

Эта программа рисует заранее заданные SQL-команды и две строки MARA. Она не импортирует SQLite и не выполняет SQL. Проверен полный main после явного исправления шрифта: 492 байта текста, 20 упорядоченных вызовов окраски строк, весь bitmap и attributes, полная RAM с точными исключениями spill и наблюдаемого стека, исходный DI/HALT с SP EFFE и loader return word 7003.

Ожидания текста и цветов сохранены до native запуска из исходного main. Экран вычисляется независимо из frozen текста, цветов и font bytes; исходные ASM рисования исполняются без host-замены. Во всех трёх режимах результат одинаков: 1699 байт BIN / 478 352 такта. Дополнительного выигрыша Grace нет.

Прежний источник объявлял только 16 word globals для font, всего32 байта вместо заявленных91 glyph. Исправлено на явный 760-байтовый массив:95 printable ASCII glyph, та же таблица, что в исправленном ZSQL со встроенным шрифтом. Предыдущий источник сохранён. Font-before FAIL проверяет размер первого объявления (2 байта), а не суммарных соседних globals: это статическая проверка отсутствующей полной таблицы, не native miscompile. Фактический старый фрагмент занимает32 байта.

Native RAM включает код и шрифт; все20 attribute calls и492 символа проверены в порядке исполнения. Ввод отсутствует; портовый эффект — ровно один blue border output. ROM, реальная contention, interrupts, аппаратный экран и VM-equivalence не проверены.

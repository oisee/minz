# Original local-struct calls now return on Z80

Catalog085 marked reports/showcase-src/2026-03-13/ex19_assert_forms.nanz pending independent native evidence; its comments acknowledged VM-only struct paths. Before new native execution, workload/source SHA were frozen in45c4ccca. Independent expected values follow Book v7 §2.7 and §4.1 named byte field layout and §3.1 unsigned byte width: Manhattan is two host absolute differences added modulo256; accessors return their named byte.

The original manhattan(0,0,0,0) had correct raw/final VM value0 but did not return natively. Two alloca2 instructions emitted four DEC SP instructions, then RET read local data as the return address. get_x/get_y had the same missing two-byte cleanup. No source rewrite or changed expectation was needed.

The backend now proves outstanding local allocation depth through reachable CFG edges. A unique exit depth is restored by INC SP after return copies, preserving all result registers and flags. Different depths on separate returns and equal-depth joins work. Conditional returns restore only their return edge (including compound comparison trampolines). Functions with local frames retain CALL+cleanup+RET rather than unsafe tail JP, because callees may access pointers into live local storage. Growing allocation cycles, unequal-depth joins, oversized frames and explicit PUSH/POP/ASM combined with local allocations fail closed until a dynamic frame implementation handles them. Stack availability remains caller/platform responsibility; this is not an overflow runtime.

The unchanged whole module retains all40 source assertions. Native/raw/final VM independently pass3856 calls per mode (default, GraceSize, GraceSpeed):1296 Manhattan combinations from six byte boundaries and2560 accessor calls. Each call checks exact VM byte observation values/order, native local-byte contents/counts (including temporary AF save traffic occupying future local storage), full64KiB state outside actual stack/spill slots, original code, returned PC/SP and guards. Exact driver ABI uses the production allocation; the original body/name is retained.

Focused assembled tests cover83 return paths: different-sized early returns, equal joins, Z/carry/compound conditional returns, suppressed framed tailcalls, a stable-depth loop and a path returning without allocating. Unequal joins/growing loops reject explicitly. Full MIR2 package passes18.211s. A valid low-level test must allocate before a carry predicate: ADD HL,SP in alloca itself changes carry; this packet does not claim to repair arbitrary pre-existing flag lifetime bugs.

This is evidence for three original entries and bounded workloads, not all source entries or the entire194-path corpus. Historical before-failure ASM/BIN remains alongside corrected full-module artifacts. No optimization speed comparison against the non-returning binary is meaningful. The corrected first Manhattan workload costs525T (zero inputs),538T when the final coordinate differs.

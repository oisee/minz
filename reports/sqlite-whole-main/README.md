# Original SQLite whole-main native proof

Исходник `examples/nanz/sql_test6.nanz` и полный импортируемый sql/tui код сохранены без изменений. Base `869fb6cb`; freeze `ac512ed4` сделан до выполнения. Это отдельная runtime family: реальный `modernc.org/sqlite v1.46.1` исполняет CREATE TABLE, два INSERT и SELECT через test-owned строгий портовый адаптер.

Все три режима (ordinary / Grace Size / Grace Speed) проходят с preserving и полностью clobbering primary/index BDOS2 host: **1670 байт; 59 байт точного stdout**. Native instruction T-states без стоимости test-owned BDOS callback указаны в `summary.json` (это не полная оценка OS времени). Frozen command stream содержит 11 команд, строки SQL, handle/column и результаты. Native выполняет реальные ASM тела, возвращает main в исходный return PC со SP F000; минимальный SP EFF8. VM ASM output не симулируется.

Оракул stdout: `Open...\nExec...\nQuery...\nStep1...\nAlice\nStep2...\nBob\nDone.\n`. Каждая команда сверяется с замороженной последовательностью; статусы IN43 — 1,0,0,0,1,1,1,0,0. OUT проверяет оба байта адреса порта, IN — верхний байт текущего A. Независимые SQLite rows возвращают Alice/Bob. Записи recv проверяются по named body PC, адресу и значению в порядке Alice+NUL, Bob+NUL. Итоговый буфер равен Bob+NUL+e+NUL: хвост первой строки намеренно сохранён. Все 65536 байт RAM сверяются, исключены только фактически использованные 8 байт стека; код, строки, остальные globals и guards сохраняются. BDOS разрешён только по PC5 с реальным CALL return address внутри original tui_puts. Полный clobber A/F/BC/DE/HL/IX/IY не меняет оставшиеся SQL команды и вывод.

Bounded API проверка использует весь тот же original module: send/recv 0,1,17,255 байт; column_text handles1/255 и columns0/1/255, text255+NUL или empty; column_int значения 0,1,255,256,32767,32768,65535,-1,-32768 по модулю 65536; step/finalize/close statuses0/1/255. Реальные CALL/RET, оба портовых адресных байта, порядок OUT, return ABI, IX/IY, code/fullRAM и SP проверены. Это bounded домены, не exhaustive SQL semantics.

`_sql_recv_str` не имеет проверки длины: контракт требует NUL не позднее 256-го байта. Более длинный ответ не считается безопасным и не допускается этим proof. Неизвестный порт/команда/handle отказ; SQLite engine ошибки не превращаются в выдуманный успешный результат.

Загрузка явно test-owned: ordinary assembled image ORG0100, отдельный CALL main / HALT trampoline 7000, SP F000. Это **не linked production RuntimeCPM COM и не физический CP/M OS proof**. RuntimeCPM не изменялся и его ограничения не обходились. `Step` не вызывает SetBDOSHandler, поэтому тест обслуживает named PC5 сам и читает настоящий return word со стека. Первый PC0006 был ошибкой harness (без callback), не compiler miscompile; это не semantic regression.

Read-only provider audit: MZE `cmd/mze/sqlite_ports.go` возвращает open/query handles и step result через status43, как читает stdlib. MZX `cmd/mzx/sqlite_ports.go` записывает handle/result в resultLo, но status43 равен нулю: native sqlite_open/query/step получат неверные значения. В этом конкретном main hardcoded handle1 маскирует ошибку возврата; нельзя объявлять MZX правильным по stdout. MZX также не очищает strBuf после handle-only step/finalize/close (MZE очищает после каждой команды), что может загрязнить последующую строку. Провайдеры не изменялись; frozen полный код позволяет отдельно воспроизвести аудит.

Другие stdlib ASM API прочитаны, но не помечены доказанными: tui_goto/color/read_line/puts_padded полагаются на физические A/C/B/HL в комментариях без @z80 annotations. Single-arg tui_puts реально использует HL и проходит здесь; это не сертификат остальных TUI функций. Есть возможный integer overflow y+1/x+1 по байту и BDOS clobber requirements — отдельные семантические проверки нужны прежде исправлений.

Репродукция из minzc: `go test ./pkg/pipeline -run '^TestSQLiteOriginal(WholeMain|BoundedPortAPIs)$' -v`. `MINZ_SQLITE_MAIN_EXPORT` задаёт новый абсолютный каталог ASM/BIN/MIR/fullRAM/port ledger. Frozen pipeline.test и SHA в build.json на шаре. Запуск frozen exe должен иметь cwd minzc/pkg/pipeline, сохраняя frozen source dependency paths. Проверить packet: `python3 reports/sqlite-whole-main/audit.py`.

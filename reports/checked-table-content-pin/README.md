# Проверенная таблица: привязка к содержимому

Options.CheckedLocalTableSHA256 теперь может фиксировать точные JSON bytes внешней таблицы. Таблица читается один раз, SHA проверяется, затем те же bytes передаются в RegAllocTable.LoadJSON. Несовпадение или неверный SHA — ошибка входа, без fallback. SHA без пути также отвергается обоими входами CompileHIRSteps и CompileHIRWithOptions. Без SHA сохраняется прежняя политика: недопущенная запись или пустая таблица дают baseline. Перенос неизменённого файла по другому пути сохраняет ASM.

Проверены оба входа pipeline, изменение содержимого, relocation, неверные/orphan pins, unpinned fallback и все 256 native аргументов выбранного add5. Прежняя таблица даёт 8 → 6 байт модуля, 56 → 49 тактов fixture. Полный VIR PASS 2,392 с; направленные pipeline/table проверки PASS 0,112 с. Z3 применяется только в исследовательском тесте из отдельного окружения; production внешнего solver не требует.

Это основание для совместного профилирования, не завершённый PGO допуск. ProfileCompilationID по-прежнему отвергает внешние таблицы. Следующий этап: content pin в compilation identity, удержание одного snapshot через measurement и применение, collect/replay с проверкой изменённого файла и caller costs. Полный retained pipeline 94a41120 предшествует этому изменению и ещё работает.

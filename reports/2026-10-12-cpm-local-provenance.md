# CP/M: narrowed local pointer admission fix

Production `3c20e2d8` + native-offset followup `bab41a0e`, baseline `f34064f6` (runtime admission `36a2303a`). Independent review нашёл verified MIR/forced valid byte-spill placement, принятый конечным Z80Codegen: `Alloca2:ptr → Move:u8 → Store:u8`. Доказательство локального адреса копировалось без проверки destination type. Native записывал один байт pointer в `_spill_main_r2`, затем reload делал `LD HL,(_spill_main_r2)` и использовал соседний byte как старшую половину.

Замороженные [MIR/allocation/native observations](cpm-local-admission/before.json), ASM/BIN и before testsource показывают запись **42 по адресу 0xcd67**, вне двухбайтового объекта и runtime stack. В исходном placement spill=0x012d, stack=0x016b..0x056b; native main возвращается PC0/SP0xf000. Raw write observations включают также сохранение runtime SP: это не объявлено нарушением. Исходный verified MIR source сохранён; **обычный исходник/frontend miscompile не воспроизведён и не заявляется**. Byte register C placement отвергался assembler как `LD(C),A`; значимый контрпример — конечный успешно принятый LocMem byte placement.

Fix: local authority сохраняется только в `TyPtr` Alloca/Move/Field/PtrAdd с чистой разрешённой metadata, typed source derivation и native-width destination. Read-only callee pointer param также должен быть TyPtr; его derived Move/Field не могут сужать адрес. Условные/CFG pointer forwarding уже остаются вне допуска. PtrAdd offset определяется canonical i/u8/16 stored typed bits и совпадение исходного immediate с ними; bool/wide/noncanonical/metadata constants отвергаются. Это bounded admission, не новая general pointer conversion. Hard allocation hints/source location остаются; непереносимая sequential/call metadata не используется как авторитет.

After новый regression требует отказа до ASM outputs. Unit controls покрывают narrowed field/move, metadata, constant metadata/bool, canonical u8 offset1 и отказ u8 Const257 и положительный pointer Move/read-only load. CP/M stack proof/guards/named BDOS adapter tests сохранены и проходят. Original CP/M demo/main/puremethods, variants refusal и live-byte+predicate across all-clobber BDOS caller PASS5.101s; focused MIR2 CP/M admission PASS (retained replay) (retained executable replay log рядом). Полные pipeline/CLI не повторялись, ими владеет root.

Сохранены exact before/after executable XZ и SHA uncompressed bytes, source/ASM/BIN/MIR/allocation/logs. Распаковать xz; before run `-test.run '^TestCPMLocalReviewNarrowAddress$' -test.count=1 -test.v` воспроизводит accepted native counterexample; after run `-test.run '^TestCPM(RejectsNarrowed|Local|ReadOnlyPointer|Runtime)' -test.count=1 -test.v` требует rejection и сохраняет positive controls. Existing before evidence immutable. Этот fix не доказывает весь arbitrary MIR/ASM admission и не изменяет BDOS OS preconditions или default runtime.

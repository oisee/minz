# Закрыты ошибки условных циклов; безопасный byte packing

На cc502270 все группы, падавшие в полном pipeline на cb587fe4, повторно прошли: условные invariant-кандидаты, три исторических parser baseline и multifuction profile. В тот же прогон включены проверки FAT12 packing. MIR2 — PASS 0,008 с, pipeline — PASS 12,395 с. Это целевые проверки, не полный pipeline PASS.

Backend сохранял pending A в D даже при живой паре DE. Теперь при отсутствии свободного байтового регистра используется spill. Независимая модель unsigned wrap (Language Book v7 §3.2), raw/final VM и собранный Z80 проверяют 1152 варианта. Исторические неправильные ASM/BIN сохранены. Исправление cc502270, пакет docs/grace-conditional-invariant-fix.

FAT12 ld_word на неизменённом stdlib исходнике: 98 → 78 T и 21 → 16 B. Сокращается только финальная сборка непересекающихся байтов; исходные чтения, MIR и lifetime сохраняются. Оба бинарника проверены для всех 65536 слов по адресам 0x8000 и 0xffff; проверены порядок чтений и отказ второго доступа. Это не memory fusion. Исправление 91e2a9e1, пакет docs/grace-native-byte-pack.

Все три memory-host CLI сохраняют точный BIN при .bin и ASM при .a80 (094ffa44). Повторный интегрированный collect/replay тест прошёл за 46,563 с; независимый Python audit реального трёхвходового parser workload прошёл. Победитель: 992049 T, 2344 B. Историческая ошибочная .bin с ASM сохранена.

Пакеты скопированы на /mnt/safe/minz/grace/2026-10-11/compiler-docs и проверены SHA256. Полная сверка docs/reports выполнена на 6ec387d6: 14563 файла документации и 437 отчётов; последующие пакеты проверены отдельно.

# Plasma: весь исходный рендерер на VM и Z80

Неизменённый `examples/zx/plasma.nanz` прошёл полный `main` в Ordinary, Grace Size и Grace Speed. Проверены 6144 записи bitmap и 768 атрибутов: точный адрес, значение и порядок каждой записи. Затем сравнивается вся RAM, кроме точных spill slots и фактически использованного стека; проверяется возврат в PC 7003 с SP F000. Исполняется настоящая inline-инструкция `LD (HL), A`, без перехвата её вызова.

Независимая модель вычисляет четвертьволновую целочисленную аппроксимацию, смешение волн, dither и адреса экрана. Типизированные промежуточные значения заворачиваются согласно Nanz Language Book v7, раздел 3.2. Ожидания не извлечены из LUT или результатов VM.

| Режим | Байты полного BIN | Такты main | Записи экрана |
| --- | ---: | ---: | ---: |
| Ordinary | 1555 | 7 562 297 | 6912 |
| Grace Size | 1555 | 7 562 297 | 6912 |
| Grace Speed | 1555 | 7 562 297 | 6912 |

Raw и final MIR VM также проходят полный main с явно подключённой моделью `zx_poke`: модель записывает адрес и значение в VM RAM и проверяет порядок. Это проверка алгоритма при заданном ASM-контракте; native часть независимо проверяет исполняемые байты этого контракта. Полный тест — PASS за 0,636 с.

Источник заканчивается обычным возвратом после render, несмотря на комментарий про DI/HALT: проверяется фактическое поведение исходника. Это один статический кадр phase=0 в плоской RAM. Реальная ZX contention, ROM, interrupts, дисплей и физическое железо не моделируются. Дополнительного выигрыша Grace нет.

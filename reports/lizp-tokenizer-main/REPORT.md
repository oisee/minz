Independent model: whitespace bytes 32/9/10/13; comments skip from semicolon through optional newline; parens have categories1/2; maximal decimal digits category4; quoted bytes through closing quote or EOF category5, with no escape grammar; other maximal non-delimiter bytes category3. Embedded NUL is EOF. Category6 is advertised in a source comment but next_token never emits it. `123abc` is NUMBER then ATOM; `-12` is ATOM. These expectations derive from the exact declared grammar, not another compiler.

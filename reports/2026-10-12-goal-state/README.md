# Текущая карта общей цели

Цель активна. Это сверка требований с текущими источниками и сохранёнными доказательствами, не заявление о завершении. Подробные идентификаторы и SHA — в state.json.

| Требование | Что подтверждено | Что осталось |
|---|---|---|
| Надёжный HIR → MIR2 → Z80 для заявленного корпуса | Все194 пути имеют явный статус; независимые/ограниченные VM/Z80, CP/M и Agon проверки различаются | Текущий полный pipeline ещё работает. Lizp cond return и учебный PL/M Hello требуют решения семантики; runtime границы остаются явными |
| PFCCO/PBQP/таблицы дают полезные назначения | Weighted12-вариантная матрица:44→20B, caller238→142T с moves/saves; отдельные PFCCO семейства и отрицательные admission проверки | PBQP не объявлен лучше greedy на tokenizer. Local-table admission не доказывает произвольную shape/CFG/island композицию |
| Grace полезен на нескольких программах и heldout | Frozen parser heldout−2,61%T; hashmap48 heldout calls−8,11%T,−20B; выбранный BIN одинаков на train/heldout | Это bounded frozen протоколы, не универсальное обещание; общий gate не завершён |
| LIR удалён, польза и тесты сохранены | Нет живого пакета/импортов;53-файловый архив проверен; typed identities, multiply, bounded fusion, constraints/tests перенесены. Composition математический oracle↔finalMIRVM↔Z80 по10,6млн вызовов на слой | Полная эквивалентность research WFC и произвольные islands не заявлены. VIR может остаться исследовательским путём |
| Воспроизводимые локальные/общие артефакты | Источники, профили/решения соответствующих опытов, MIR/ASM/BIN, логи и manifests сохранены; новые пакеты SHA-проверены на шаре | Сохранить терминальный gate и синхронизировать итоговую публикацию после него |

Agon теперь имеет точный full-device command/text replay всех5 примеров×3 режима и отдельные exactRET/SP/IY/IX/24-byte caller-frame проверки на тех жеBIN. Это реальные eZ80/MOS/fullVDP внутри эмулятора, не аппаратное исполнение и не аудит всех записейRAM. Эти late проверки не включены в неизменный pipeline executable b6b4e0c7.

Приоритет дальше: продолжать живой gate без перезапуска; разбирать любой настоящий FAIL; после ответа закрепить Lizp/PLM контракты и независимые проверки; затем сверить окончательное состояние и публикацию. Pure Speed по-прежнему минимизируетT без штрафа за байты; Size отдельная цель. Железо — следующий уровень.

Основной отчёт уже в main черезPR78, compiler changes остаются в feat/grace-hir-vm. Опубликованный Sites snapshot старше новых runtime доказательств. Исторические completion-audit файлы относятся к прежним bounded целям и не закрывают эту расширенную цель.

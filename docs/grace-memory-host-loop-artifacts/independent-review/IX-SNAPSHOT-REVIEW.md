# Separate next capability: compiler-owned IX return snapshot

Original baseline remains valid: its closed runtime refused unrecognized IX stack loads in peeled candidate. That refusal is a missing capability, not wrong baseline acceptance. Actual genCall sequence saves IX and result pairs, anchorsIX=currentSP using LDIX0/ADDIXSP, copies snapshot bytes to caller-save image, loads results/flags, incrementsSP to discard snapshots, restoresIX/caller pairs.

Minimum independent descriptor contract: internally generated call-snapshot group identity and per-operation PC/opcode/role, exact IX anchor plus saved-pair slot offset/depth and currentSP delta. Runtime validates active initialized register-save slots from actual PUSH operations, exact bounds before effects, and expected grouping/order. Never generic permission for `(IX+d)` when effectiveaddress lies in stack, or currentIX numericallyequalsSP. Static offset alone can overlap a return-address frame.

Readrole snapshot permits repeated non-destructive reads; unlike POP it must not clear slot initialization. Writerole may patch ONLY exact caller-save/resultpair slots declared for that call result. It must not patch return-address frame or unrelated parentcall slots. Value comes from actual source snapshot byte; preserve original register halves/order and flags. If recording transfer value authority, bind exact preceding sourceread, destinationbyte and scratchA without interveningclobber. Otherwise runtime frame POP consumes final value but no source-equivalence claim beyond raw/native oracle.

Anchor lifetime must account for extra PUSHHL while IX stays anchored: expected currentSP delta explicit, not blanketSP==IX. Discard snapshots by INCSP must retire corresponding live slots; initializedbytes cannot survive a free-slot interval and become future authority. Parent/recursive frames cannot consume a stale child snapshotgroup. Endgroup requires exact restoreIX/stackdelta and all declared writes/reads consumed; conditional repeatedgroups instantiate fresh bounded per-activationstate.

Negative probes: same numericIX without compileranchor; anchor clobber/add aftercreation; slot offset into returnaddress; source/destination swapped; unexpected thirdread/store; wrong width/indexprefix; snapshot readuninitialized; POP-consumed snapshot read; duplicate/unmatchedgroup; skippedPUSH; forgedcurrentSP while anchorcorrect; validnestedPUSHHL supported onlydeclareddelta; INCSP freeslot thenstale read; recursivegroup collision; metadata marker relocation/peephole removed operation; wrong registerbyte value or scratchAclobber. Bound errors trap BEFOREaccess, including out-of-stack adjacent writable region. Infrastructure/provenance failure returns no attested semantic host prefix.

No production edits/tests here for this capability. Native/backend owners implement separate internally emitted descriptors and runtime, then independent bounded tests must establish exact original/sourcecandidate events/binary/cost. Existing global/spill recipe must not be weakened to authorize IX stack operations.

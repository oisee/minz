# Корпус: два исходных README-примера CP/M

Все 194 пути сохранены. `hello_cpm.nanz` и `hello_cpm_fib.nanz` переведены из категории непроверенного inline ASM в native CP/M runtime после исполнения исходного main без правок исходников: три режима компиляции, два контракта BDOS2, точный вывод, возврат ОС, PC/SP, RAM и стековые проверки. Шесть public CLI COM совпадают с исполненными бинарниками. Отдельные исходные fib/gcd assertions проверены в raw/final VM и собранном Z80; арифметика в main могла свернуться при компиляции.

Теперь native CP/M runtime путей четыре, inline ASM — 29. 133 independent/bounded VM/native и два native SMC остаются отдельными категориями. Полный набор программ на реальном железе не проверен. Остальные статусы сохранены; renderer, сеть и другие внешние окружения не объявлены исполненными по проверке чистых функций.

Registry сверяет SHA256 исходников и указанных доказательств. Полный каталог: PASS за 2,926 с. Этот результат проверяет согласованность каталога, а не повторно исполняет весь корпус.

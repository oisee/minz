# Сохранённый source checkpoint

На шаре сохранены и побайтно проверены все отслеживаемые Git файлы minzc, stdlib, examples и scripts текущего checkpoint. Точный commit, число файлов и SHA256 манифеста указаны в source-checkpoint.json; сам манифест содержит путь, размер и SHA256 каждого файла. Это сохранность исходников, не утверждение единого compiler PASS.

Новые пакеты нулевых упрощений, CP/M-методов, C89 управляющих эффектов и lexical binding также скопированы в канонический compiler-reports. Предыдущие source checkpoints и исторические логи оставлены отдельно.

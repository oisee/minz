# Интеграция проверок CP/M-методов и переноса LIR

CP/M-методы повторно проверены на checkpoint `cc0165db`, нулевые упрощения — на `fac1133d`. Все 34 файла пакета нулевых упрощений и 28 файлов CP/M-методов совпадают с SHA256 в манифестах, отслеживаются Git и сохранены на шаре.

## Что подтверждено

- Нулевые упрощения перенесены в обычный MIR до распределения регистров. Проверка в рабочей ветке: pipeline PASS 0,047 с, MIR2 PASS 0,574 с. На новой проверочной программе полный BIN уменьшился со 175 до 86 байт, нагрузка — со 158 812 до 145 384 тактов. Это результат тестовой программы, а не прикладного корпуса. Сохранены исходники, MIR, ASM, BIN и результаты повторного запуска.
- Два чистых метода исходного `51_impl_cpm_demo.nanz` проходят все 256 радиусов и 65 536 пар ширины/высоты по двум адресам в трёх режимах. Повтор в рабочей ветке PASS 2,603 с. Проверяются реальные CALL, программное умножение Z80, значения, порядок чтений, память и восстановление стека. Всего 394 752 вызова. Полный исходный модуль сохранён; `main`, печать и BDOS этим тестом не подтверждены.
- Полный CLI executable checkpoint `31d6abd0` завершился с кодом 0 и строкой PASS. Он включает исправления C89 switch и PL/M, но предшествует нулевым упрощениям и новым исправлениям C89 циклов. Лог сохранён без изменения.

Полный pipeline `29df08bb` ещё выполняется. Его результат не подменяется focused проверками; этот executable предшествует последним frontend исправлениям. Полный MIR2 после нулевых упрощений запущен отдельно, итог ожидается.

# Measured choice boundaries

This stage changes workloads and audit artifacts only. The original SelfLanz source and authoritative CLI executable 1bd95516 remain unchanged. Small direct calls explore observed zero-body loops and a measured winner crossover. Selection is never predicted from individual costs.

Accepted workloads are zero-body region_match plus intern_region, and first-byte equality/mismatch variants with a zero-length append. Both exact source sites must have positive entry counts. A preloaded repeated intern hit has append entries zero and must refuse. Partial semantic read/write denials and a one-step VM budget workload must refuse the measured selector; diagnostic partial observations remain separate from selection evidence.

Raw VM profiles and independent arithmetic/ordered-memory models are reviewed before any native CLI run. Each admitted workload is measured for both goals; refusal runs must create no selected native artifact or decision. Input workload bytes, source, executable identity, profiles, diagnostics, commands, exit codes and logs are preserved. No compiler, runtime, permission or selector changes are part of this stage.

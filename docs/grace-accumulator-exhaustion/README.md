# Сохранение A при исчерпании scratch

Два дополнительных production пути saveABeforeOverwrite и saveAccOperandIfLive выбирали D даже при живой паре DE. Прямое исполнение emitted ASM воспроизвело 0x1234 → 0x2534 при A=37. Теперь свободный scratch запрашивается без fallback; если его нет, A сохраняется в named spill. Регрессия проверяет исходный DE и сохранённый A. Все основные и индексные пары заняты живыми значениями.

Полный MIR2 после исправления PASS 6,865 с. Независимые native условные циклы, byte packing с вызовами/условиями и полный FAT12 word/wrap диапазон PASS 5,704 с. Это целевые проверки и пакет MIR2, не PASS всего pipeline. Legacy scratch fallback умножения остаётся отдельным предметом аудита.

# Корпус: native ASM и Pascal Hello

194 точных пути сохранены. Шесть исходных ASM примеров имеют отдельную категорию executed-native-asm-bounded: actual Z80 ABI/эффекты в независимых доменах, без VM ASM эквивалентности. Pascal Hello получает native CP/M runtime статус после исполнения unchanged main/public CLI COM. Factorial получает положительные FACT/loader доказательства, но production decimal runtime остаётся неподтверждённым.

Категории: 133 independent/bounded VM/native, два native SMC, пять native CP/M и шесть native ASM. Остальные 48 путей имеют явные ограничения: 22 inline ASM, 18 external runtime, пять Agon/MOS, два pending и один host-only. Bounded entry не означает всё приложение; injected device hosts не означают проверку на железе.

Source/evidence SHA проверены registry. Focused catalog PASS 1,940 с; это проверка согласованности, не повтор исполнения всего корпуса. [Root native результаты](../grace-integration-237/README.md).

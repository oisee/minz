# Grace PGO: общие правила, реальные исходники и MIR lineage

Измеритель `MeasureGraceVariantSets` сравнивает отключённые и включённые HIR constant-if/invariant-base правила совместно с вариантами pointer-walk. Настоящий базовый вариант отключает все HIR Grace правила; последующие обычные MIR оптимизации одинаковы. Максимум четыре pointer-site дают 32 набора. CLI joint-auto использует этот измеритель. Старый `MeasureProfileVariantSets` остаётся сравнением pointer-вариантов с общими правилами включёнными.

Каждый кандидат сохраняет HIR и текущие метки циклов. Запрошенный pointer-walk должен фактически появиться в lineage; исчерпание бюджета переписываний отклоняется, а не выдаётся за измерение преобразования.

| Нагрузка | Исходный | Общие HIR правила | Выбор |
|---|---:|---:|---|
| region_match: длины 0, 1, 5, offset 1 | 2970 T / 97 B | 1602 T / 52 B | invariant-base |
| неизменённый grace_hir_constant_if: wrap(255), choose(42) | 24 T / 3 B | 24 T / 3 B | исходный |
| u16 накопление: длины 0, 1, 5, 255 | 83615 T / 64 B | 83615 T / 64 B | исходный |

Для region_match выигрыш составляет 46,1% тактов и 46,4% байт. Это сумма измеренных вызовов, без bootstrap; размер включает весь модуль. Последний пример проверяет Z80-регрессию, а не срабатывание invariant-base: правило требует pointer-параметр.

Обнаружен и исправлен сбой Z80: immediate ALU загружала индекс в A, затирая живую границу цикла. При пяти итерациях u16 накопление возвращало 1 вместо 5. Immediate-путь теперь сохраняет живое значение A так же, как общий ALU-путь.

193 вызова из полных неизменённых исходников weighted, constant-if и sha256 проходят независимые арифметические оракулы, raw VM и исполнение собранного Z80. Проверены отдельные функции SHA, не полный хеш. popcount с ranged-параметром пока отклоняется: LUTGen заменяет параметр его базовым типом, что не проходит строгую проверку ABI измерителя. Отказ явно покрыт тестом.

MIR2 переносит SiteID/Role/Rule при клонировании и переносе блоков, split-return, слиянии Grace, sinking, compare fusion, unroll и tail-recursion. При конфликтующих метках блоки сохраняются раздельно. Удаление блока чистит его метку, LUT-замена очищает прежний lineage. Verifier отклоняет метки отсутствующих блоков. Это атрибуция, не доказательство корректности unroll; произвольные мутации меток и generic HoistInsts требуют отдельного покрытия.

Raw VM и Z80 сохраняют и сравнивают globals/resources после каждого возврата, включая void. Ошибка первого set больше не скрывается последующим reset. Снимки принадлежат результату, не разделяют изменяемые буферы; старые результаты без снимков отклоняются измерителем.

Joint harness проверяет границы обращений и значения памяти на границах вызовов. Он пока не доказывает точное число чтений для произвольного caller; отдельный exact-sum измеритель проверяет более сильный контракт обращений. Полный SHA, closure ABI и общий регистратор access-trace остаются следующими этапами.

Артефакты: [grace-pgo-common-artifacts](grace-pgo-common-artifacts/), включая реальные исходники, workload/profile/evidence, ASM, бинарники, отзывы и журналы проверок.

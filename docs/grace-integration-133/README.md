# Интеграция 133: полноразрядное сравнение и граница VIR

Код `1b64163a`: исправлено сравнение spilled/register u32/i32 в обычном Z80 backend. Независимые исходниковые проверки, включая настоящий helper CALL, проходят вместе с регрессиями сохранения живых flags и широких сдвигов. [Лог](source-and-flags.txt). Отдельная физическая матрица: **11 520 native запусков, PASS 8,548 с**; проверяются C/Z, A, IX, обе банки пар и восстановление SP. [Лог](physical.txt).

[Исходный контрпример, точные ASM/BIN/MIR и границы проверки](../../reports/2026-10-11-u32-comparison-native.md). SHA256 всех 104 payloads исходного пакета повторно проверены при интеграции. Это исправление корректности; выигрыш скорости не заявляется. Unsigned widening casts исправляются отдельно. Полный pipeline checkpoint a7954042 ещё выполняется; этот пакет не объявляет его PASS.

Alice разрешила перепроектировать незавершённый VIR. [ADR0047](../adr/0047-mir-native-candidates-and-offline-vir.md) фиксирует рабочий путь HIR → MIR2 → Z80, перенос проверенных назначений и отсутствие Z3 в обычной компиляции. Research island emitter пока не переносит значения между независимо решёнными частями. Следующий допуск таких кандидатов требует явных live-in/live-out, корректных parallel copies, alias/flag/bank/stack contracts и полной стоимости стыков. WFC остаётся исследовательской гипотезой, а не заявленным production выигрышем.

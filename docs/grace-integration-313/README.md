# Корпус: полный rotozoomer и явные оставшиеся границы

Rotozoomer прошёл полный неизменённый main: все 32 кадра 256×192, палитра, порядок pixel calls и точные пути save. Независимый signed16 оракул проверяет цвета и координаты всех 1 572 864 пикселей за запуск. Raw/final VM и native в трёх режимах прошли за 91,570 с, с full native RAM и возвратом PC/SP. Все режимы дают 2656 байт и 5 523 758 850 тактов; выигрыша Grace нет. [Полный результат](../../reports/rotozoomer-main/README.md).

Каталог сохраняет все 194 пути. **153** имеют независимые или ограниченные VM/Z80 проверки. Отдельно отмечены 14 native ASM, 7 CP/M runtime, 2 SMC, 10 inline ASM без завершённого аудита, 5 Agon MOS, 2 pending semantic/runtime и 1 host memory model. Эти категории не суммируются в обещание универсальной корректности. [Каталог](catalog.json) · [Проверка экспорта, PASS 3,461 с](catalog.txt).

Оставшиеся pending: Lizp cond_test требует решения о неявном return; PL/M hello содержит пустой PRINTCHAR и литерал без NUL, поэтому bounded proof с явно добавленной trailing-zero памятью не равен переносимому Hello World. ZVM story[131072] получает ожидаемый отказ для обычного 16-битного Z80 и требует отдельной модели памяти. Для устройств и ASM нужны собственные независимые модели исполнения.

Полный pipeline на checkpoint94a41120 запущен и ещё не завершился. Он включает NC/IRC, но предшествует новому rotozoomer whole-main test; тот проверен отдельно. Полные HIR/frontends/VIR идут отдельной командой. Результат этих незавершённых прогонов пока не объявляется PASS.

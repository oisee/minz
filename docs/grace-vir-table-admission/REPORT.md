# VIR: неполные таблицы больше не допускаются к генерации кода

База `0717d100`. Исправлен подтверждённый риск из ревью Astra: `verifyABICompat` пропускал отсутствующие обязательные vreg; `Lookup` возвращал hit для укороченного назначения, а `emitFromTable` превращал отсутствующий операнд в -1, который matcher воспринимал как отсутствие ограничения. Минимальная отрицательная регрессия до патча: отсутствующее назначение результата/ABI v3 принято, emitter возвратил успешный ASM.

Общий проверяющий код независимо собирает обязательные vreg из dst/src и inline asm входов/выходов. Он используется в обоих форматах Lookup (JSON и binary), ABI gate и непосредственно перед table emitter (включая объединённый результат cut-vertex). Неполное назначение либо неверный индекс места даёт miss/ошибку до выдачи ASM. Определённые результаты проверяются по разрядности места; результаты сравнений — по flag-width. Обязательный ABI параметр должен существовать и совпадать с контрактом; прежние DstHint/SrcHint ограничения сохранены. Отказ оставляет прежний путь fallback к решателю/PBQP, без расширения допуска и без включения VIR по умолчанию.

Проверки без Z3/GPU:

- Отрицательные: отсутствующий результат, отсутствующий ABI параметр, укороченные JSON/binary назначения, отрицательный/вне диапазона индекс, u16 в A, несовместимые ABI/подсказки и отсутствующий inline asm output.
- Положительный: полное назначение для `7+5` даёт BIN `3e07060580c9`; реальное исполнение на Z80-эмуляторе возвращает A=12 и восстанавливает SP=f000. Измеренные 53 T включают CALL, RET и остановку DI/HALT.
- Существующие проверки binary loader, настоящего внешнего 4v fixture (если файл доступен), carry helper: PASS. Полный протокол содержит пропуски, если fixture отсутствует.

Это минимальная проверка допуска, не сертификат корректности всей таблицы: помехи/алиасы, clobber, цена и безопасная вставка движений не доказаны. Разрядность исходных значений без определения в VIR не выводится заново; она по-прежнему ограничена описаниями паттернов и ABI. Широкая переработка islands/cut decomposition, общая проверка таблиц и устранение VIR/LIR — отдельные задачи. Полный долгий pipeline не запускался.

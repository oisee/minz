# Weighted byte checksum: доказанная композиция scalar и pointer walk

Grace распознаёт точный root-loop `sum+=a+b; sum+=u16(ptr[i]); i++` с u16 literal/parameter seed и неизменными u16 scalar operands. Узкий recognizer после scalar hoist допускает ровно дополнительный чистый preheader initializer и единственное использование временной переменной. Он сохраняет позицию цикла для replacement/rollback; facts используют фактическую позицию. Weighted fast path использует pointer iteration и explicit load после weighted update, сохраняя порядок арифметики и потенциального trap. Address guard и original indexed fallback сохранены; finalindex=n только после завершения fast path.

Новый API `MeasureWeightedJointSourceSiteVariantSets` и CLI `--hir-profile-weighted-sites` (requiresjoint-sites/invariant-sites/joint) используют schema `minz.weighted-joint-source-site-variant-sets/v4`. Только original exact weighted source допускает пересечение scalar/pointer choices. Hoisted input prefix, предыдущие policies/lineage, shared/mutated factories, forged profile и превышение четырёх choice dimensions отклоняются. Overlap занимает два независимых choice bits; до32candidates. V3 и legacy module APIs требуют явный v4 для weighted overlap; disjoint fixtures сохраняют прежний контракт.

Структурный validator перед и после compilation проверяет source proof, unchanged function metadata/globals/target, seed/zeroindex/return, exact weight initializer, fresh binding, guard, ordered pure accumulation/load, stride/count/start, отсутствие MutateInPlace, exact fallback и finalindex. Attribution хранит предыдущий scalar rule на pointer fast/fallback; marker сам по себе ничего не доказывает. Каждый кандидат сохраняет обе проверенные composition records, HIR/lineage, raw state, actualtarget state, binary digest и стоимость. Общие не доказанные пересечения остаются запрещены.

Firstinvalidaddress и unchanged input проверяются независимо; равенство VM gas не заявляется.

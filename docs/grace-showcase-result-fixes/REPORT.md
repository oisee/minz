# Showcase: исправлены результаты crypto и dsp

Ветка основана на `4f556d23`. Исходники примеров и их ожидания сохранены.

- `dsp.lizp`: Lizp превращал параметр `t` в литерал `true`. До исправления HIR для `sawtooth` содержал `true % period`; MIR возвращал 25 вместо 0. Привязки `t`/`nil` в параметрах и `let` теперь переименовываются до раскрытия сахарного синтаксиса с сохранением области видимости; генерируемое имя не совпадает с именем в исходнике. Непривязанные `t`/`nil` сохраняют прежнее значение.
- `crypto.lizp`: MIR давал 68, Z80 — 65 для `caesar_encrypt(65,3)`. Сохранение живого флага использовало только carry (ещё и байт 255 вместо канонического 1), хотя `>=` использует NC, а равенство — Z. Второй предикат, назначенный PBQP в обычный регистр, не материализовался перед AND. Теперь сохраняется полный предикат; перед ALU он получает канонический байт, при сохранении флага остаётся живым A.
- Дополнительная регрессия `ch + ((ch >= 65) & (ch <= 90))` обнаружила восстановление уже мёртвого `physOverride`: оно затирало новый AND-результат в A. Теперь мёртвые переназначения отбрасываются. Исключение для текущего результата сохраняет временные назначения рекурсивного spill staging; эта зависимость проверена полным MIR2 пакетом.

Оракул: Language Book v7 §21.4 задаёт Lizp как сахар над типизированным Lanz/HIR. Арифметика тестов рассчитана независимо в Go: булевы сравнения дают 0/1; операции u8 вычисляются по модулю 256. Пример `sawtooth` не переинтерпретирован как математическая дробь без переполнения: u8-произведение усечено перед делением.

Проверки:

- Весь `pkg/mir2`: PASS, 7.538 s; весь `pkg/lanz`: PASS, 0.011 s.
- Весь `pkg/lizp`: PASS. Новые тесты: 90 проверок привязок, живого аккумулятора и границ sawtooth; 2700 проверок всех пар шести сравнений с AND/OR/XOR; 61 проверка реального crypto, включая 54 дополнительные границы Caesar. Каждая проверяется MIR2 VM и собранным кодом на Z80-эмуляторе.
- Исходные showcase `crypto.lizp` и `dsp.lizp`: PASS; BIN 99 и 115 байт.
- Два теста стадий iterator, включая захваты и живые суммы, Grace on/off: PASS, 0.509 s.

Полный showcase и долгий полный pipeline здесь не запускались. Протокол не утверждает корректность всего корпуса. Сохранены исходные HIR/MIR/ASM, окончательные логи и два промежуточных диагностических лога: пойманное затирание нового A и исправленная ошибка удаления временного spill назначения. Первый монолитный тест 2700 утверждений остановлен SIGTERM из-за квадратичной стоимости многократной сборки; окончательная матрица разбита на 108 небольших модулей и полностью завершена.

# Mixed copy + weighted PGO on a persistent Pascal-string intern caller

This directory preserves measured evidence for all eight independent choices (copy, weighted scalar, weighted pointer) under speed and size objectives, including both pipeline API and actual built CLI runs. The typed program ports the length-prefixed string search/reuse/allocation logic of self_tokenizer into bounded caller resources. The original extern tokenizer is not claimed tested here.

`selector/` contains original source, workload, observations, arithmetic oracle, both complete evidence documents and selected ASM/binary. All candidate binaries are also extracted losslessly from evidence. `cli/` preserves built CLI input HIR, raw/optimized MIR, profile, decisions, target run, selected ASM/binary, and both full eight-candidate documents. Large JSON files use lossless gzip; ASM, binary, source and small JSON remain directly readable.

`audit.py` independently simulates sequential Pascal-string intern: search length-prefixed entries, short-circuit byte comparisons, reuse or append, then wrapping weighted checksum and persistent globals. It checks every result, full resource/global snapshot and exact resource/global read/write count for 30 calls × eight candidates × raw/postcompile raw/target × four API/CLI objective records = 2,880 candidate calls. The host oracle reads saved inputs only; it never invokes the compiler or HIR evaluator. It also validates requested bits and proofs, binary SHA256 against target evidence, module byte counts, summed T-states, strict winner selection and exact selected binary. `audit-report.json` records the result.

Speed selects candidate 7 (all three choices): 962,137 T-states, 826 bytes. Size selects candidate 2 (weighted scalar only): 1,089,098 T-states, 539 bytes. Baseline candidate 0 is 1,635,072 T-states and 626 bytes. Costs cover the persistent caller invocations, excluding workload bootstrap. The final arena bump is 559 and there are 15 intern hits.

`audit-evidence.go` unmarshals the four evidence records into the compiler's actual Go type and verifies their self-excluding JSON SHA256 using Go marshaling. This avoids Python/Go serialization differences. Run from `minzc`:

```
python3 ../docs/grace-pgo-mixed-intern-artifacts/audit.py
GOCACHE=/tmp/minz-grace-gocache go run ../docs/grace-pgo-mixed-intern-artifacts/audit-evidence.go ../docs/grace-pgo-mixed-intern-artifacts
```

`intern-baseline-history/` preserves the earlier failed original target evidence separately from the fixed successful baseline, plus source, backend patch, focused/full gates and tracker/TSMC review. The failed baseline had correct raw VM results but a word spill copy overwrote live HL; it is diagnostic history and is not included in speed comparisons. The corrected machine baseline and every measured candidate agree with the independent host oracle. The audit separately checks the preserved fixed baseline raw and target runs (30 calls each), its 626-byte binary hash and 1,635,072 T-state sum. The nested historical manifest remains its original snapshot manifest; this directory's root manifest binds the current saved bytes.

`budget-assembly-compare.go` is a compile-only comparison of the unchanged `grace_rule_budget.nanz` fixture against archived commit b9ad1f73 and the integrated compiler. It compiles all four constant-if/invariant rule choices with the real first Grace application followed by CompileHIRSteps, without repeating the previously completed 722.080-second machine budget gate. The exact assembly/binary comparison report and both sets of ASM/binaries are saved locally. The size setting is deduplicated by its actual code path: CompileHIRSteps reads OptSize only when passing OptimizeForSize into HIR Grace; this gates guarded pointer and forward-copy rules. This fixture has an empty pointer policy and no enabled forward-copy rule, so both size settings produce the same rewrite path. No eight independent compilations are claimed. Incomplete initial single-pass attempts are separately labeled historical evidence. This establishes whether the new word spill fix changes that fixture; it does not replace the general compiler gates. Reproduce compilation from each checkout with `go run /path/to/budget-assembly-compare.go /path/to/output`, then run the assembler audit from minzc with `go run ../docs/grace-pgo-mixed-intern-artifacts/budget-binary-audit.go ../docs/grace-pgo-mixed-intern-artifacts`.

`manifest.json` lists relative paths, stored sizes and SHA256; it excludes itself. Regenerate after appending later gates or artifacts. Production compiler files were not modified by this audit.

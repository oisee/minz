# Read-only CLI native-output design review

Owner branch feat/memory-host-arena-append-cli, permanent memory-host-arena-append-cli, base b1e0fa66. This is an early design review before production source/plan exists; final code and built CLI output still require review. Parent compilation source is not edited.

The finite selector already independently compiles/measures four closed-host native baselines. CLI should export the selected Target.Assembly and Target.Binary exactly, bind both hashes to selected evidence and typed precompile record, and avoid a subsequent compile that could produce different code or unbound default flags. Current target includes the closed workload adapter and fixed code/stack/return layout. It must be named/documented as a bounded-workload native artifact, not a generic callable application binary.

Dedicated opt-in dispatch must reject incompatible old PGO/emit/backend/target/assert/optimization flags rather than quietly ignore them. Goal chooses among measured costs; Osize in this mode must not imply a changed compilation policy if candidates use baseline default options. Default CLI route must remain unchanged when the flag is absent.

Own and bound source/workload/profile bytes before callbacks. Closed workload JSON requires exact schema and strict duplicate/unknown/case-sensitive fields, canonical typed shapes, bounded input lengths. If profile omitted, generate through the existing closed source profiler, save it, then use strict loader/replay; never synthesize counts. Extern admission remains exact registered byte hosts with finite regions/signatures, no user callbacks, assembly or numerical protected-memory grants.

Artifact path validation must protect source, imported dependency inputs, workload and profile from replacement, including existing inode aliases/symlinks and unresolved path parents. Prefer an explicitly separate output directory with all outputs chosen internally. Export should finish evidence validation before writing reviewable results, preserve partial failure semantics explicitly, and provide manifest/schema-selected identity. Existing user artifact overwrite behavior needs a concrete policy; no source file may be an output.

Required meaningful tests: noflag/default dispatch equality; incompatible flags refuse before execution/writes; malformed/stale workload/profile refusal; path collisions; exact selected ASM/BIN bytes/hash; speed and size outputs match corresponding selected typed candidate, builtin restrictions and source origins intact. Built CLI all30 actual output audit should run once by owner after freeze; independent reviewer audits saved bytes without CPU duplication. Native/codegen permission source remains unchanged unless an actual separate repair is reviewed.

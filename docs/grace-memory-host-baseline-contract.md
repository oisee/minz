# Bounded memory-host baseline contract (implementation draft)

This stage introduces a separate `minz.memory-host-workload/v1` baseline API. It does not permit hosts through existing no-host workload or PGO selectors. It establishes original-source VM/native workload evidence; no parser rewrite, PGO decision, source-equivalence certificate or verified postallocation optimized-VM result is claimed.

The owned descriptor contains only built-in `read-u8-at-u16` / `write-u8-at-u16` signatures, fixed named byte regions and write permissions, initial exact-width global bytes, ordered literal integer calls, per-call global changes and region clear/patch setup, and explicit code/stack/return layout. Setup may load read-only regions: permissions apply to executed program writes, and setup is outside measured execution. Literal signed/unsigned/bool values must fit their declared type; implicit host callback/environment access is absent.

All source extern declarations must match the registered closed builtin set. ASM, ports, SMC and indirect calls remain forbidden. Missing compiler print intrinsics are accepted only in provably unreachable functions under the exact workload direct-call closure. Their emitted bytes count toward module size; executed native instruction ranges must remain within the allowed closure. Full source semantic fields and origins remain part of compatibility, including unused functions.

Memory-host accesses can touch only declared regions, never numerically matching globals, code or stack. VM ordinary globals require instruction-identity provenance from an exact global symbol and bounded constant offset. Unknown pointers are region checked even if their address equals VM global storage. Ordinary region reads and equal-value writes are audited in order. A pre-byte VM hook checks permission before mutation; its nil default preserves previous VM behavior. The existing whole-heap range check remains atomic: partial prefixes apply to the new per-byte permission hook, not arbitrary old heap-boundary failures. This contract always creates the complete64KiB heap.

Successful and failed invocations carry exact byte events, results, all globals and all region snapshots. A failed call retains completed effects and the corresponding snapshot; it is separate failure evidence, never a successful optimization attestation. Memory persists between calls unless the descriptor explicitly resets it. Workload bytes, built-in semantics, layout, resource bytes and resets are hashed; compiler executable and original source compatibility are bound independently.

`RunMemoryHostBaseline` lowers original verified source. `RunMemoryHostMIRBaseline` accepts verified SSA MIR for controlled diagnostic baseline runs and still rejects malformed IR; it is not a rewrite certificate. The existing postallocation MIR representation may reuse virtual registers and therefore is not admitted by this API. Native baseline compilation must be privately fresh from the original source, followed by actual internally generated ABI-checked byte adapters and the independent source VM oracle. Saved optimized MIR is diagnostic evidence only.

First meaningful tests cover persistence, resets, ownership, equal-value writes, invalid first/second bytes, ordered failure prefixes, address65535→wrapped0, strict signatures and integer bounds, unknown/extra hosts, region overlap/overflow, global widths, stale region/reset/layout context, unreachable versus reachable print builtins, foreign old workload schema, and unknown numeric pointers to globals. Original SelfLanz retains its faithful30-call persistent interning oracle, ten globals, complete RAM snapshots and255/256/257-byte quirks.

This draft accompanies the source during parent review. Final native provenance coverage, gates, measured costs and publication status belong to the completed stage report rather than this draft.

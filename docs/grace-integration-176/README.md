# Интеграция 176: проверка CLI косвенных вызовов на Z80

Интегрирован `2612a266` (donor `8fa57df7`). Три группы прежних ожиданий отказа/предупреждения теперь проверяют поддерживаемую компиляцию. Точный исходник `func_ptr.c` проходит независимый native CALL шести функций с проверкой числового результата, исходного PC возврата, SP и сохранности памяти. Вывод ASM совпадает с API для того же исходника; BIN сверяется с форматом выбранной платформы. Неверные sandbox-ожидания и отказ для удалённой семантической сигнатуры сохраняются.

Root независимо повторил четыре focused группы: PASS (точный лог рядом). Это не полный CLI PASS. Новый полный CLI исполняется из заранее сохранённого бинарника с SHA256 и копией на шаре; окончательный результат будет записан отдельно. Предыдущий полный запуск завершился с тремя падениями, сохранёнными в175.

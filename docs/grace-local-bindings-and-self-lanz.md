# Локальные integer bindings и полный SelfLanz baseline

Неизменённый `self_lanz_parser.nanz` выявил ошибку lowering: объявление
`let len:u8 = pos-start` связывало u16-регистр с именем u8, не выполняя truncation.
На атоме длиной 256 проверка `len==0` пропускалась, parser создавал лишний node
и менял persistent string arena. Граничные вызовы сохранены в workload.

Lowering теперь преобразует значение к объявленному integer типу после одного
вычисления initializer/assignment. Это относится к scalar declarations,
локальным assignments, результатам fold и scoped LetIn. Расширение signed
значений использует sign extension. В LetIn также восстановлено внешнее
binding, его тип и alias/array metadata после вычисления body.

Проверки охватывают let/var/assign, передачу bound значения в функцию,
ровно одно вычисление с побочным эффектом, unsigned/signed widening,
результаты fold и shadowing LetIn. NoReg callable aliases и pointer/array/struct
binding не получают integer coercion. Перед исправлением выявлены отдельные
Z80 ошибки bool→u16 и сохранения HL-параметра при записи globals; их исходники
и результаты сохранены как отдельная история, исправление этого этапа их
не заявляет.

Полный исходный parser использует внешние `peek/poke`. Для baseline тестовый
harness предоставляет matching VM hosts и реальные ABI-адаптеры Z80:
peek(HL) → A, poke(HL,C). Source compiler output получает только тела внешних
адаптеров. Код размещён с 0x0400 ниже node arena 0x8000; ABI allocation и
границы кода/стека проверены. Стоимость включает вызываемые адаптеры.
Существующий production PGO harness сохраняет строгий отказ для Extern.

Все 30 последовательных вызовов прошли raw VM, optimized MIR и actual Z80:
результирующее дерево, все 10 globals с реальными byte/word ширинами,
4096 байт node arena, 8192 байта string arena и точная последовательность
ресурсных peek/poke events. Интернирование строк сохраняется между вызовами;
node bump и позиция сбрасываются тестовым driver одинаково для каждого режима.
Независимый Python oracle подтверждает исходную семантику, а не сравнивает
только две версии compiler. Стоимость: **1221494 T / 2091 B**.

Это корректный машинный baseline рекурсивного parser, включая границы 256/257,
не production PGO оптимизация parser и не ускорение относительно прежнего
ошибочного исполнения. Артефакты прежнего неверного дерева сохраняются отдельно.

Повторные actual CLI измерения подтвердили все четыре кандидата обоих режимов
на hashmap и tokenizer. Hashmap сохраняет прежний выбранный бинарник
123708 T / 965 B. Новые tokenizer кандидаты: 2240897 T / 4303 B,
2184763 T / 4689 B, 2230476 T / 4432 B, 2174342 T / 4818 B.
Speed выбирает последний, size — исходный. От прежних измерений выбранные
варианты сократились на 16753 T и 14 байт; все новые бинарники перепроверены,
а прежние значения сохранены для сопоставления. Проверки semantic state/access
предшествуют сравнению стоимости; исторический hardcoded cost не используется
как oracle корректности.

Общие HIR / MIR2 / Nanz / C89 прошли за 28.580 / 6.048 / 1.732 / 9.587 с;
CLI — 24.772 с. Showcase сохранил прежние 31 падение, новых нет.
Полный pipeline прошёл за 276.296 с. Budget-проверка заново скомпилировала четыре варианта за 243.881 с.
Независимый assembler подтвердил source / ASM / BIN равенство с предыдущим
этапом: 344 / 344 / 232 / 344 байта. Прежняя длинная машинная проверка применима
по полному равенству бинарников; повторный её прогон не заявляется.

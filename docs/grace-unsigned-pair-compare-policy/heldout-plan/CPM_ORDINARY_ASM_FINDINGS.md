# Ordinary SelfLanz ASM: pre-smoke findings

Read-only inspection of `grace-checkpoints/cpm-lanz-smoke/self-lanz.a80`, generated by the ordinary compiler route. This is not the closed memory-host image. No CPU execution or production edit.

The `peek` and `poke` labels have empty bodies, while contracts advertise HL→A and HL/C. `node_tag EQU peek` therefore references a real external that has no linked implementation. Supplying genuine target byte-load/store adapters addresses that missing dependency.

Two additional issues require separate attention before describing the full main as working:

- `main` ends in `XOR A; DI; HALT`, not `RET`. A wrapper that calls main and then exits through `JP 0` cannot reach that exit unchanged. Any CP/M-specific main-terminal rewrite must be explicit in the derived artifact.
- Generated `_mir2_str_N` objects use `DB length, text`. The ordinary main passes `_mir2_str_3` directly to `peek` and copies until NUL; the print intrinsic similarly walks strings until NUL. The saved objects have length prefixes and no explicit NUL terminators. The source input object begins with byte 45, so simply linking memory adapters does not establish the intended source/text behavior. This is a possible preexisting string-representation mismatch, requiring an independently checked source/ABI remedy or an honestly recorded failing smoke. Do not silently reformat all data and call it unchanged compiler output.

Existing transfer/PGO results remain separate: their workloads call parser/helpers with explicit resource bytes and never execute this main or its printers. The ordinary main/string issue must not be claimed fixed by those results.

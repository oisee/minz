# Call-spill certificate plumbing

Compile-only capture of the current source/Steps assembly and typed access descriptors. No machine execution. The assembled artifact omits the closed runner's injected host adapters, so its addresses are diagnostic and differ from the failing CLI artifact.

Owner scope: target capture/evidence fields and policy-envelope hash validation. Backend owns typed snapshot descriptors, exact recipe resolver and runtime access enforcement. Numeric stack ranges are not authority.

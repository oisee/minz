# Перенос заранее выбранных вариантов SelfLanz

Исходный Nanz не изменён. После фиксации решений на обучающем наборе выполнены 16 запусков Z80: 12 основных результатов и 4 базовых запуска той же backend-политики для проверки доказательства. Выбор на оценочных данных не повторялся.

|---|---:|---:|---:|---:|---:|
| short-reuse | 330515 / 2000 | 326650 / 2100 | -1.169% | 327008 / 1978 | -1.061% |
| long-atoms | 4110605 / 2000 | 3968826 / 2100 | -3.449% | 3968942 / 1978 | -3.446% |
| nested-mixed | 1297899 / 2000 | 1271819 / 2100 | -2.009% | 1281762 / 1978 | -1.243% |
| fresh-dominant | 789462 / 2000 | 696957 / 2100 | -11.717% | 699845 / 1978 | -11.352% |

Основные варианты фиксированы: контроль — политика 0, маска 0; Speed — политика 1, маска 3; Size — политика 0, маска 2. Дополнительные базовые измерения политики 1, маски 0: 329597, 4110217, 1286305 и 786526 T соответственно; размер каждого — 2001 байт. Они служат проверке вариантов той же политики.

Два независимых аудитора проверили 200 сохранённых наблюдений: возвраты, все глобальные значения, области памяти, порядок host-событий, происхождение HIR, доказательства преобразований, ASM/BIN и SHA. Повторная проверка сжатого пакета также прошла. ELF оценочного теста сохранён отдельно от executable обучающего запуска.

Наборы уже были известны при разработке. Это ретроспективная проверка переноса вне обучающего набора; она не доказывает качество на неизвестных данных, универсальную прибыльность или запуск полного main под CP/M. Исполнялся закрытый Z80 function harness.

Полный экспорт завершился за 91.40 с, код выхода 0. Ошибка первого запуска из неверного рабочего каталога возникла до исполнения Z80 и сохранена отдельно. Production-код и стандартные настройки не менялись.

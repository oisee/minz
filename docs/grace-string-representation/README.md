# String representation repair: frozen bounded implementation

Six production paths preserve SString/LString/CString storage and dispatch direct literal printing to ordinary counted HIR loops. Arbitrary pointers retain the existing CString intrinsic. Processed UTF8 byte bounds are checked in the parser and native emitter. Empty storage has no invalid DB trailing comma. VM print.char writes one byte rather than reencoding it as a Unicode rune.

Generated bindings are reserved against all source names (including tuple and loop binders), current environment, aliases and globals. A visited pointer guard and skipped type descriptors keep recursive public HIR types from causing scanner recursion. The VM refuses string storage beyond its memory limit before mutating heap/cache; an explicitly larger VM can represent a65535-byte LString, which does not claim a fitting64K executable.

Raw and optimized VM tests verify first-byte loads, exact builtinUTF8/embeddedNUL output, live successor values and sourceglobal/local collision preservation. Storage/cache tests cover all three kinds, empty values,255S/256L and representablelength refusals. The corrected native pipeline/PBQP fixtures passed all 15 cases once: exact storage bytes, printoutput/terminatingSPPC, neighboring CString and live global successor across ordinary counted loops are ready for review. Output equality is not claimed as an independent proof that every memory read stayed inside a literal.

The first native pass was preserved as failure history: the fixture used ROM-protected low memory and the wrong HALT PC expectation; it also exposed a real print.char argument-materialization defect. The corrected emitter uses the allocated argument and preserves a live accumulator around output. The corrected 12 output and 3 storage cases passed, exit 0, using preserved executable 8d60ea6b6a80a76e89046cde9bbeacd9946ea5abc85a6883f469e5821f8801db. All original histories, exact assembled sources, binaries, output/expected bytes, globals, register/cycle state and executables are preserved.

No SelfLanz source, CP/M wrapper or PGO selector has changed. This fixes string storage and literal-print semantics; no workload profitability claim is made. Both independent saved-payload audits passed all 15 corrected cases. Exact saved assembly reassembled to each BIN without CPU execution; source/output bytes, global snapshots, termination and executable identity also passed.

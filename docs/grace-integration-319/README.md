# ZSQL: исходный диалог проверен на собранном Z80

Неизменённый `examples/nanz/zsql.nanz` проходит полный `main`: создание таблицы, вставка строки и SELECT, затем оставшиеся запросы исходного цикла. Проверены 32 строки ввода, 388 байт вывода, порядок SQL-вызовов, записи результатов и хвосты входного буфера, вся RAM с точными исключениями для spill и стека, PC и SP. Три режима компиляции и два контракта порчи регистров BDOS дают одинаковый результат: 1545 байт / 42 787 тактов. Работа сервисов SQLite и BDOS не входит в эти такты.

Это native-проверка с настоящей SQLite и тестовым BDOS; она не доказывает эквивалентность inline ASM на VM, работу публичного CP/M runtime или железа. [Полный отчёт и сохранённая ошибка ассемблера](../../reports/zsql-port-main/README.md).

Каталог сохраняет все 194 пути. Независимые или ограниченные проверки VM/Z80 есть у 153; отдельно native CP/M runtime — 10, native ASM — 15, native SMC — 2. Ещё 6 inline ASM путей ждут аудита, 5 требуют Agon MOS, 2 ждут независимого оракула и 1 требует иной модели памяти. Записи SQLite и SAP обновлены на текущий SHA общего теста, без изменения исторических логов.

Пять двоичных эталонов ранее были сохранены локально и на шаре, но исключались общим Git ignore. Теперь они явно включены в Git: stdout SQLite, SAP MARA и ZSQL, ROM output TUI ZX и серверный буфер IRC. Их SHA256 совпадают с сохранёнными манифестами. Это закрывает пробел воспроизводимости свежего checkout.

Полный pipeline `94a41120` продолжает выполняться. Его executable предшествует исправлению coalesced edge copies и quoted local labels; результат этого прогона нельзя объявлять полным gate текущей ветки.

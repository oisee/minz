# Строки: одинаковые байты в VM и Z80

Статус: исправление представлений включено в `feat/grace-hir-vm`;
общий этап ещё открыт из-за ошибки вывода в другом пути компиляции.
В GitHub main этот набор не включён.

## Что меняется

Nanz Language Book v7 §18.1 задаёт три представления:

| Литерал | Байты для AB | Как заканчивается |
|---|---|---|
| `"AB"` | `02 41 42` | Счётчик длины в первом байте |
| `l"AB"` | `02 00 41 42` | Двухбайтовый little-endian счётчик |
| `c"AB"` | `41 42 00` | Нулевой байт |

Раньше VM хранила все три как CString, а literal print искал NUL.
Теперь VM и ASM сохраняют объявленное представление; S/L literal print
использует обычный цикл со счётчиком. Встроенный VM print.char выводит
байт без повторного UTF-8 кодирования. Z80 print.char берёт аргумент
из назначенного физического регистра и сохраняет живое значение A.
Произвольный указатель print сохраняет прежний CString-контракт.

Границы длины проверяются по обработанным байтам: SString до 255,
LString до 65535. Это границы формата; большой LString не означает,
что вместе с программой он помещается в 64 KiB Z80. VM отказывает
при превышении своего лимита памяти до изменения heap/cache.
Внутренние имена counted print не совпадают с исходными bindings.

## Что проверено

В основном пути CompileHIRSteps прошли 15 actual Z80 случаев:
пустые строки, C/S/L, UTF-8, embedded NUL, S255, L256 и чтение
первого байта представления. Проверены точные байты вывода, globals,
живой результат после печати, PC/SP и завершение. Сохранены исходник,
полный ASM со стартом, BIN, allocation, symbols, такты и executable.
Два независимых аудита проверили результаты и повторную сборку ASM
в тот же BIN без повторного исполнения CPU.

Первый неуспешный запуск сохранён отдельно: в тесте были неверный
HALT PC и ROM-защита низкой памяти; он также выявил настоящий дефект
материализации аргумента print.char. Исправленный запуск не подменяет
историю первого. Равенство вывода само по себе не доказывает границы
каждого чтения памяти.

## Открытая ошибка второго пути

CompileHIRWithOptions после allocation запускает InsertAccSaves.
Этот проход создавал номер временного регистра, занятый другой
функцией, и перезаписывал назначение её указателя. Исправление
`92a7ca2d` делает новые регистры свежими для всего модуля.
Полный MIR2 gate прошёл; showcase снизился с 31 до 26 прежних
падений без новых: 19 missing imports, пять HIR refusals и два
несовпадения результата. Пять исторических падений исчезли.

Actual Z80 проверка тех же 15 случаев через второй путь дала
11 успехов и четыре ошибки SString: печатается только первый байт.
Сохранение A выбирает D, занятый половиной DE-указателя, и позднее
затирается другой инструкцией. Исправление должно учитывать время
жизни и обе половины регистровых пар. При нехватке регистров значение
нужно сохранять так, чтобы оно переживало рекурсивные вызовы. Этот
backend этап ведётся отдельно; готовность пока не заявлена.

После его закрытия — полный Self-Lanz main под CP/M BDOS emulation
с явным CString исходника и проверенным startup/stack/memory adapter.
Успех функции в тестовом harness не является успехом всего COM.

# Explicit eight-candidate search CLI

Isolated implementation based on c096cca0. --memory-host-arena-append-search selects a separate finite policy0/1 × mask0..3 search. Named Legacy and PreserveForSpeed association files must be supplied together or omitted together. Existing old/fixed modes remain unchanged and explicitly incompatible. Empty flag presence is tracked.

Owned known original SelfLanz bytes and complete single-unit parse are checked before collecting either native association. The search owns both inputs and workload; current-executable replay and independent expected-source checks remain in the public search API. All fifty output payloads are encoded and inventory-checked before filesystem writes, and all input/output paths are checked before execution and again before writes. Semantic/admission refusals create no artifact directory; IO failures can leave partial files.

Decisions bind source name/hash, exact search bytes, both exact saved association bytes and the selected policy/mask/native hash. Selected ASM/BIN and optional -o come directly from that candidate's target evidence.

Focused admission passed 0.524 s, and named input caps/old-mode admission passed 0.313 s. The short same-executable native collect/replay test is in progress. No full30 CLI performance evidence has been executed. Parent source is unchanged by this isolated branch.

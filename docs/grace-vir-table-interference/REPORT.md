# Независимый допуск живых значений таблицы

До изменения три отрицательных случая принимались: разные одновременно живые значения в A, живое слово HL и байт L, а также ADD с результатом в регистре исходного значения, используемого позже. После изменения они отвергаются независимым обратным проходом по VIR.

Определения проверяются против значений, живых после инструкции; входы проверяются между собой до инструкции. Умирающий источник может делить регистр с новым результатом. MOVE равного значения допускает совпадение на своей границе; более позднее совместное использование консервативно может уйти в fallback. Специальные пары/половины используют z80spec, прочие descriptors — Alias.

Существующие положительные native случаи 7+5 и сохранения37 через XOR A проходят; допуск clobbers, widths, missing locations и бинарных таблиц также PASS. Это проверка предоставленной линейной последовательности, не доказательство CFG liveness, scratch каждого pattern или полноценной оптимальности табличного решения.

# Native global-access provenance: bounded first contract

Checkpoint reviewed:058458cb, `memory_host_target.go`, `memory_host_z80_memory.go`, `memory_host_workload.go`. Shared owner files were not edited. Independent diagnostic is `minzc/pkg/pipeline/memory_host_provenance_review_test.go`; exact log is `numeric-global-gap.txt`.

The VM authorizes an actual Load/Store instruction only when its pointer is independently traced to one global AddrOf plus nonnegative constant offset and complete width fits that storage. A numeric OpConst pointer is not authorized, even if its runtime integer equals VM.GlobalAddr. The native runner instead marks all assembled global bytes readable/writable and read/write consult only these permission bits. Consequently `LD HL,0x8000; LD A,(HL)` and `LD HL,0x8000; LD(HL),A` can read/write a byte marked global with no native resource event, despite numeric-pointer MIR being unproved. The diagnostic establishes the runner-layer gap, not a successful whole public runner oracle forgery; public VM/native replay can still reject the example. Equal final state is not an access-provenance proof: unchanged write, read result discarded, or wrong read substituted by equal contents can leave comparisons unchanged.

Recommendation: bounded emitted access sidecar rooted in final MIR instruction provenance. Do not implement general runtime register/stack taint as the first contract. Tracking pair halves, EX/EXX, indexed registers, arithmetic, spills, call contracts and stack-return distinctions through every supported Z80 opcode is a larger second interpreter. Clearing taint on calls rejects valid preserved pointers; propagating it by numeric equality launders addresses; treating stack bytes as all trusted launders caller-supplied values. Current closed-memory access checks must additionally gate globals, stack and compiler spills by instruction provenance instead of making any numeric hit trusted.

## Exact artifact and source binding

1. Regenerate native assembly and access sidecar internally from the final MIR module plus actual allocation, with no caller-supplied ASM/sidecar authority. The public runner currently accepts Steps.Assembly; reject mismatch against regenerated backend artifact. Bind source compatibility, final verified MIR digest, allocation digest, target model, actual assembly bytes, final executable BIN SHA, and the sidecar SHA. Source/final MIR structural metadata validation alone does not bind arbitrary assembly to MIR. A sidecar is a backend-produced attestation, not independent proof that codegen preserved source semantics; raw/target oracle remains required.
2. Compute permitted globals from `MemoryHostGlobalAccesses` on final MIR. Refine output to descriptor{actual instruction identity, stable function/block/instruction position, global symbol, exact nonnegative offset, byte width, read/write}. Do not carry pre-optimization instruction pointers blindly. Reject malformed/detached/ambiguous provenance and overflow; a runtime address must equal the exact symbol+offset+byte index, not merely land within some global. No numeric origin, dynamic offset, phi, loaded global pointer or call argument can acquire global permission through equality.
3. Emit zero-byte unique access markers around EACH actual global memory operation, not the whole genInst range. One MIR instruction may generate scratch loads/stores, register saves, global low/high byte operations and compiler spill accesses; marking its whole range would grant unrelated instructions global authority. Every marker carries root descriptor plus exact byte operation/offset and direction. Resolve from final assembled Listing. Independently decode the actual opcode at the PC and validate access recipe/count/direction, including direct16-bit operations. No marker accepted on immediate/address-setup instructions. For two-byte globals preserve correct byte order and partial-failure prefix. Optional backend support can initially reject an unfamiliar emitting path rather than broadening permission.
4. Account explicitly for `fixOrphanedTSMCStores` and final `asmPeepholePass`: markers must survive every rewriting pass and either preserve validated access boundaries or transform descriptors correctly. Plain start/end labels around genInst are insufficient. A marker barrier that disables peepholes may change measured BIN; verify the original SelfLanz exact BIN/T-state identity. If it changes code, retain actual changed measurements and do not claim existing baseline identity.

## Runtime enforcement

Before each instruction save instruction-start PC. Fetch bytes retain the existing exact consumed instruction extent model. At EACH non-fetch data access, classify address. For a global byte require matching internally bound descriptor at that PC, expected direction and exact current address/byte index; consume a bounded operation budget and reject missing/duplicate/extra accesses. Never authorize by runtime value equality, instruction range, function reachability or opcode mnemonic alone. A host peek/poke adapter is permitted ONLY declared resource regions, even when numeric argument equals a native global or spill address. Region accesses continue to emit every ordered byte event. Protected reads/writes trap before effect; first valid byte of a later-invalid multi-byte operation remains observable. End-of-instruction checks ensure required operations were actually executed (subject to supported conditional op semantics; no conditional-global instruction accepted initially).

For stack and spill regions use separate backend/frame operation descriptors; do not reuse global permission. First version can restrict stack memory opcodes to well-formed PUSH/POP/CALL/RET with actual SP and bounded frames and compiler spill accesses to symbol-rooted emitted records. Arbitrary `LD(HL),...` hitting stack or `_spill_` storage must refuse. Source structs/allocas/call-indirect/self-modification remain excluded unless separately proved. This is necessary for an honest closed-memory contract, although global permission is the immediate gap.

## Minimum acceptance/rejection tests

- Original unchanged SelfLanz30: source/workload/ABI adapters and full independent tree/arena/global/event oracle unchanged. Record internally regenerated assembly/BIN, sidecar hashes, all actual global access descriptors/counts and exact1221494T/2091B reference identity only if measured unchanged.
- Positive direct global byte and word accesses, symbol+bounded constant offsets, optimized direct-addressing, spills/calls adjacent to global accesses; same behavior as raw VM. Global loads containing a region pointer remain legal GLOBAL loads; the pointer's later host use must be resource-bound, not global-rooted.
- Numeric pointer equal actual native global base and second byte; dynamic integer/add/call-param/loaded integer/phi producing that number; each must trap before access, including unchanged stores and discarded reads. Host adapter must reject global, code, stack, spill addresses.
- Forged sidecar: wrong symbol/offset/direction, duplicate/extra PC, different BIN/ASM/MIR/allocation, boundary moved onto scratch access, orphan label. Same numeric address at a different PC must refuse. Authorized PC with corrupted pointer to another global or different byte must refuse.
- Global two-byte first-byte success/second-byte rejection, reversed order, third access and unexpected wider access; full partial state/event prefix. Marker movement/merging through final peephole and orphaned spill rewrite must either validate precisely or refuse.

This is a separate opt-in bounded memory-host baseline contract, not a new optimization profile and not arbitrary assembly support. No invocation counts or provenance are inferred from numeric PC/global membership. Start with the actual SelfLanz emitting forms; widen only after independently exercising new emitted forms. A source-specific hardcoded list of symbol PCs could run this corpus but does not safely bind new compilation artifacts and should not be called a reusable contract.

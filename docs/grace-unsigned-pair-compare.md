# Unsigned pair comparison: isolated Z80 experiment

На неизменённом Self-Lanz частный прототип сравнения u16 сохранил поведение
и сократил время исполнения. В сочетании с normal-global diamond forwarding
получено **1096139 T / 1998 B** против **1135370 T / 2000 B**: −39231 такт
(около 3,46%) и −2 байта. Production-компилятор пока не менялся.

## Условие применения

Прототип допускает только Ult/Uge для точных u16 в двух разных обычных
парах HL/DE/BC, с результатом в F. A должен быть свободен; живые pending
accumulator/flags, константы, signed ordering, составные предикаты, spills
и индексные регистры используют прежний путь. Дополнительное условие:
прежний destructive SBC должен требовать сохранения живой пары.

Сравнение сначала проверяет старшие байты, затем при равенстве младшие.
CP оставляет C равным unsigned lhs<rhs, а Z — равенству целых слов.
Обе пары сохраняются; A и его кэш инвалидируются. Локальные 20/23 такта
подтверждены машинными тестами, но не служат оценкой всего workload.

Это отдельный opt-in в экспериментальной ветке. Он не расширяет разрешения
memory-host, допустимые ISA recipes или публичный selector. Diamond helper
тоже остаётся частным экспериментом; исходник и исходный raw oracle сохранены.

## Сквозной результат

Один замороженный диагностический executable, 30 последовательных вызовов
для каждого варианта, реальный parser → HIR → MIR → allocation → assembly
→ Z80 binary → emulator. Original должен точно совпадать с актуальным
production по ASM/BIN, native bindings, T, шагам и наблюдениям.

| Вариант | T-states | Байты | Шаги |
| --- | ---: | ---: | ---: |
| Original | 1135370 | 2000 | 109829 |
| Compare | 1132449 | 2001 | 109966 |
| Reuse + compare | 1096139 | 1998 | 108955 |

Compare отдельно экономит 2921 такт при +1 байте. Он меняет сравнение в
intern_region; cur остаётся прежним. Комбинированный вариант также сохраняет
DE/HL при сравнении в cur и устраняет повторную загрузку pos. Результат
относится к этому workload. Свежая атрибуция динамических PC не собиралась.

Для контраста [предыдущий reuse без нового сравнения](grace-normal-global-diamond.md)
был медленнее: 1137339 T / 1998 B. Его отдельный executable context сохранён;
счётчики и происхождение не переименовываются под новую сборку.

## Проверки и сохранение

Focused: четыре теста PASS 0.016 s, включая 160 actual machine cases,
границы 0/255/256/32767/32768/65535, оба предиката, входящие флаги,
сохранение пар и потребление предиката через ветвление/возврат.
Независимая арифметическая модель: 786513 случаев PASS.
Сквозной actual: PASS 3.593 s. Независимый saved-only audit подтвердил
все 90 raw/native наблюдений, память, результаты, упорядоченные host events
и привязки native SHA. Финальные независимые аудиты завершены; пакет сохраняется локально.

Два ранних отказа сохранены отдельно: тест кэша с неполной конфигурацией
живых регистров и original из диагностической ветки на старом backend.
Последний дал 1221494 T / 2091 B и был отклонён по production reference.
Исправили состав экспериментальной ветки точными production-файлами;
повторный original совпал. Старый отказ не считается результатом кандидата.

[Манифест артефактов](grace-unsigned-pair-compare-artifacts/manifest.json).
Исходники прототипа, логи,
ASM/BIN и проверки сохраняются; основной pipeline после отчётного этапа
не перезапускался, production остаётся 2908f18f. Временный executable
`go test` после запуска удалён; его точный context SHA сохранён, но сам
исполнявшийся тестовый файл не восстановлен. Реконструкция не выдаётся за него.

## Дальше

Перед возможным включением generic backend gate нужны более широкие
проверки живого A, pending flags, обычных fallback, разных потребителей
предиката и сохранения native provenance. Затем — полные пакеты и корпус
на новой сборке. Решение о profitability каждого source rewrite по-прежнему
принимается по измерениям; текущий успех не доказывает законность произвольного CSE.

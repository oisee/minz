# Original named pipes and real import consumers: native evidence

Проверены пять exact source файлов архива 2026-03-14 без изменения исходника: `ex28_pipe.nanz`, `ex23_import_unqualified.nanz`, `ex24_import_qualified.nanz`, `ex25_import_alias_glob.nanz`, `mathlib/ops.nanz`. Сохранены точные исходники и их SHA256. Это четыре executable consumer и одна отдельная callable library, а не пять полных приложений или доказательство всей stdlib.

[Language Book v7 §19.2](../Nanz_Language_Book_v7.md#192-pipe-declarations): «composed first applies doubled (×2), then adds 1»; `use` snapshots pipeline stages at definition time. [§19.3](../Nanz_Language_Book_v7.md#193-applying-pipes) определяет `.apply`. Countdown `range(0..n)` из главы 6 имеет элементы n..1. Независимый host oracle суммирует их преобразованные байты и даёт 30 для `sum_doubled`, 15 для `sum_tripled`. Обе полные исходные функции и два original asserts исполняются; параметризованный уменьшенный pipeline вместо них не создан.

[Глава 17](../Nanz_Language_Book_v7.md#chapter-17-module-imports) задаёт реальные imports. Parser разрешает локальный `mathlib/ops.nanz` из исходного BaseDir. Проверены unqualified `compute(x)` на всех 256 byte values с независимым `(2*x+1) modulo256`; полный qualified consumer даёт 25, alias consumer — 10. Четыре original import asserts сохранены и выполнены ordinary pipeline. Сама библиотека отдельно проверена: все byte inputs double/triple и add с пятью addend boundaries 0,1,127,128,255, всего 1792 вызова. Это полезная проверка overflow/call ABI и настоящего module resolution; локальная mathlib не выдаётся за production stdlib.

Всего **2052 независимых вызова** плюс **6 original assertions**. Каждый вызов сравнивается на raw HIR-lowered MIR VM, final ordinary-pipeline MIR VM и фактически собранном Z80. Нативный ABI-aware assembly bootstrap устанавливает входы, CALL выполняет исходный entry и RET возвращает harness. Проверяется результат A, точный PC/SP возврата, stack bounds, guards и неизменность всего compiled image после каждого вызова. Эти pure программы не имеют mutable globals/OS output; возвращаемый byte — их полный наблюдаемый результат. Source algorithm, runtime/compiler/backend не менялись; miscompile не найден.

В сохранённых образах размеры включают все test bootstrap calls: pipe 47 B, unqualified 1539 B, qualified 7 B, alias 7 B, library 13323 B. Это не сравнение размера production программ и не optimization benchmark. `oracle.json` каждого файла содержит точный source SHA, все inputs/expected results и actual native results; ASM/BIN сохранены. Каталог сохраняет все 193 пути и теперь отмечает 30 exact files с явно ограниченным независимым native доказательством. Library и parameter-free cases имеют свои честные границы.

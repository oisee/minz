# IRC runtime и повтор прежних падений

IRC client добавляет конечные пути отказа и рабочий участок исходного бесконечного main. Проверены raw/final VM и собранный Z80 с независимыми событиями, глобальной памятью и full RAM. Каталог теперь содержит 152/194 пути с независимым или ограниченным VM/Z80 покрытием; остальные статусы и границы сохранены.

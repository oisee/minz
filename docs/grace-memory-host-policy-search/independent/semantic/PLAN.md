## Ranking and errors

Enumerate stable order Legacy masks0..3 followed by PreserveForSpeed masks0..3. GoalSpeed compares measured total T only; GoalSize compares measured binary bytes only. Strict improvement replaces the winner, so equal primary costs retain the earlier policy/mask. This deterministic Legacy-first tie fallback matches existing mask order and avoids inventing an unrequested secondary cost rule. No pipeline OptimizeForSize inference, weighted affine prediction, cross-workload aggregation or speculative compare invocation estimate occurs.

An error in either association replay, candidate legality/ownership or native execution returns nil search evidence, not a winner over an incomplete subset. Infrastructure/gas failure remains an error; a failed typed host prefix does not become an admissible complete selection. Fail closed if one policy is unsupported or lifecycle/schema drifts. Diagnostic error logs can be preserved separately; do not attest a partial eight-row search or silently substitute Legacy. Files/CLI support is a subsequent explicit slice, with all prospective input/output aliases checked before CPU and writes.

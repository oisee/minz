This is a read-only CLI integration plan for the frozen policy-aware association/selector v2 APIs. It changes no compiler, runtime, CLI source or measurements. Existing `--memory-host-arena-append` and ordinary compilation keep their current Legacy behavior and v1 output contracts.

The minimal separate CLI shape is:

- `--memory-host-arena-append-policy DIR` selects the new bounded mode.
- `--memory-host-compare-policy legacy|preserve-speed` is mandatory in that mode. No default, numeric enum, case alias or inference from Osize is accepted.
- `--memory-host-workload FILE` supplies the unchanged strict closed workload format.
- `--memory-host-association FILE` optionally supplies the WHOLE policy-aware association v2. Without it, collect an original association v2 in the same executable, then pass that exact envelope through fresh selector replay.

The new mode refuses the old directory/profile flags. The old mode refuses any new policy/association flag. A policy or association flag alone refuses, instead of silently modifying ordinary compilation. Both modes remain exclusive with HIR/profile/gpu/emit/optimization-disable/assert-filter options. Require original `.nanz`, Z80 and CPM. Reuse the existing owned, bounded workload decoder; cap association bytes at the public 32 MiB limit before factory activity. Do not accept an extracted raw profile, v1 baseline or v1 association as a v2 input.

Parse the same cached original bytes under the same source filename and TargetCPM for every factory callback. Preserve the current complete single-source-unit/import refusal: every source unit map must exactly bind the cached main source. No imports or caller assembly are admitted. Resolve and compare every input, artifact destination and optional `-o` through canonical parents and SameFile before measurement and immediately before writes. Protect source/workload/association against symlinks, hardlinks and candidate output paths. The new fixed output inventory must participate in this preflight.

Own a single MemoryHostBaselineOptions value from the validated textual policy. Collection calls RunZ80MemoryHostLoopProfileWithOptions. Selection calls MeasureMemoryHostArenaAppendWithOptions and consumes the whole association envelope; its strict loader rejects wrong policy/context/source/workload, incomplete samples and inconsistent native bindings before accepting fresh replay. All four candidate baseline v2 envelopes retain the same requested policy. There is no fifth selection dimension, CSE, native permission change or old-cost reuse. Osize means GoalSize ordering of the four actual binaries at that fixed policy; it does not turn on compiler OptSize.

Export `association-v2.json`, `selection-v2.json`, `decisions-v2.json`, original `source.nanz`, owned `workload.json`, `selected.a80`, `selected.bin`, and each candidate's `baseline-v2.json` plus target ASM/BIN/MIR/allocation. Preserve mandatory v2 envelopes rather than publishing extracted diagnostic v1 baselines. Decisions schema `minz.memory-host-arena-append-cli-decision/v2` includes compile_options, goal, selected mask, choices, SHA256 of the exact saved selection bytes, binary SHA, T-states and bytes. Selected ASM/BIN must come directly from the selected candidate evidence; do not rerun codegen or fabricate ProfileDecision. Optional `-o` copies exactly selected assembly. Output is a bounded-workload native artifact, not an unrestricted callable-program claim.

Minimal checks before measurement: required/exclusive policy flags, bad text and incomplete mode, source/import refusal, strict duplicate/case/null/unknown associations, v1/bare-profile refusal, same-executable wrong-policy refusal, preserved input/output alias refusal, no output on refusal, policy-owned decision fields and exact saved-byte SHA. Existing old-mode/default route tests must remain unchanged. Focused tests must restore added flag state. No broad or full30 CPU run until source freeze and independent review.

After review, build and preserve one exact executable. Run full30 once with preserve-speed/Speed and once with preserve-speed/Size to exercise actual CLI goal dispatch; retain all candidates and source counters. A short same-executable collect/supplied replay with real external `-o` verifies exact replay/output binding. A cheap legacy control proves the explicitly selected Legacy policy produces v2 while the old mode retains v1. Use independent original-source state/event/counter and typed/native saved-data auditors. Keep contexts distinct from previous executables; do not reuse old profiles under new executable labels. Final gate/publication status belongs to root.

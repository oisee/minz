The initial generic API kept its original source identity intact but did not check compiled candidates after the final factory sentinel. A candidate's separately constructed mutable ranged parameter type could be changed from u8<0..255> to u8<0..7> at that sentinel. The selected assembly still matched saved bytes, but the retained postcompile semantic graph no longer described the measured candidate. The negative regression failed before the fix. Merely rechecking the MIR dump was insufficient because lowering canonicalizes some type information.

Every candidate now retains snapshots of postcompile full HIR compatibility, full MIR JSON semantic metadata, MIR dump (including ABI), assembly and allocation. All are rechecked after the last factory callback before returning any winner. Mutation of any evaluated candidate cancels the entire result. The counterexample and all prior complete/tie/fail-closed native regressions pass. Historical measurements retain their original executable identities; they are not rewritten as runs of this fix.

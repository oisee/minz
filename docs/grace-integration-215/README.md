# C89: порядок побочных эффектов в управляющих операторах

Исправление `b1219cbe` отделяет отложенные эффекты каждого оператора. Условие цикла исполняется на каждой проверке, включая последнюю неуспешную; выполняется только выбранная ветвь if. Continue исполняет шаг for или условие do до следующей итерации. Break и return их обходят. Независимые ожидания опираются на C90 и дополнительно сверены с GCC.

Повтор в рабочей ветке: 2 130 native вызовов и 4 260 raw/final VM проверок в трёх режимах — PASS 0,317 с. Полный C89 — PASS 5,675 с, включая FatFS HIR verification и прежние switch-проверки. Все 25 payload файлов агентского манифеста проверены по SHA256 в Git и на шаре. Исходники, raw/final MIR, ASM/BIN и наблюдения повторного запуска сохранены в этом пакете.

Это исправление порядка операторов, а не всей семантики C89: отдельный пробел условных выражений &&/||/?: расследуется следующим шагом. Lexical shadowing при повторном lowering шага continue также передано на проверку. Не заявляется произвольная полнота frontend.

Полный MIR2 на checkpoint cc0165db после нулевых упрощений завершился PASS 81,675 с (exit 0); он предшествует этому C89 исправлению. Retained полный pipeline29df08bb всё ещё выполняется и не заменяется этими проверками.

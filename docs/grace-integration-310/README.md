# NC: полный main и независимая проверка памяти

На checkpoint `12a07168` совместные проверки raw/final VM и собранного Z80 прошли за **7,036 с**. Исходники FAT12 browser и импортированного модуля не менялись. Замороженная нагрузка содержит два файла и одну директорию; последовательность Down/Up/Esc даёт ровно **1453 события**, cursor=0, top=0, count=3 и высоту панели 4 во всех трёх режимах.

Ожидаемые байты всех глобальных переменных получены отдельной моделью исходного форматирования. Она учитывает оставшиеся хвосты namebuf, sizebuf и временного буфера, а также начальные значения неиспользованных переменных. На Z80 сравниваются все **65 536 байт RAM** с образом программы и ожидаемыми глобальными данными. Исключены только точные области compiler spill из листинга и фактически использованный стек. VM проверяет все глобальные данные по той же независимой модели; его результат не служит оракулом для Z80.

Тестовый диск разрешает чтение только секторов 0 и 2 в точный 512-байтовый буфер FAT12. Запись и неизвестные внешние вызовы запрещены. Терминальные callbacks читают аргументы по фактическому ABI и сохраняют остальные регистры. Возврат из main проверяется по PC=C003 и SP=F000.

| Режим | Байты BIN | Такты Z80 |
|---|---:|---:|
| Ordinary | 12 085 | 631 464 |
| Grace Size | 12 120 | 630 312 |
| Grace Speed | 12 128 | 628 188 |

Время host callbacks не включено в такты. Это наблюдения режимов сборки; они не доказывают выигрыш Grace selector. В частности, Size здесь увеличивает BIN. Конечная навигационная нагрузка не покрывает просмотр, удаление, меню, произвольные FAT12 образы или физический CP/M.

При подготовке найдены и отдельно исправлены три ошибки компиляции: усечение указателя локального массива в HIR, усечение spilled addr_of и неверное объединение load/BIT. Неудачные пробы сохранены в пакетах 303–309; ошибки настройки ROM и возврата тестового загрузчика описаны отдельно. Полный MIR2 после последнего исправления BIT прошёл за **84,903 с**.

Каталог сохраняет все 194 пути; **151** имеют независимое или ограниченное VM/Z80 покрытие. Обновлена только запись NC для указанной нагрузки. Экспорт каталога прошёл за **3,444 с**.

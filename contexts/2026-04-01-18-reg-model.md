## Key Decisions

### LocCost IXH = 1 (not 8, not 0)
- Cost=8 made Z3 NEVER use IX halves (penalty × liveness span)
- Cost=1 = slight preference for primary, but usable under pressure
- sha256: 20 IX half uses immediately after fix ✓

### Shadow Regs: EXX-Zone Model (not flat expansion)
- 18 locs flat: 18^6 = 34 billion — IMPOSSIBLE for GPU tables
- EXX-zone: separate 6-loc table (B'..L') + compose at zone boundary
- Same size as current tables! + 4T overhead per zone crossing
- Elegant: each EXX boundary = new allocation problem of SAME complexity

### HLH'L' > DEHL for u32 when DE needed as pointer
- Both 34T for ADD32
- HLH'L': frees DE for screen pointers (Che decoder critical path)
- DEHL: occupies ALL GPR pairs

### GPU Tables Expansion
- 11 locs: ~280M entries, ~20h overnight GPU run — FEASIBLE
- 18 locs flat: 350 GPU-days — IMPOSSIBLE
- EXX-zone: same size × 2 tables — FEASIBLE

### LIR→VIR Reintegration: Path A
- Interference graph already built in VIR
- Shape → enriched table lookup = plumbing only
- Covers 79% corpus at O(1)
- No Souffle/Datalog dependency needed

## Critical Insight: IXH/IXL = Zero-Cost Inter-Zone Bridges

EXX swaps B↔B' C↔C' D↔D' E↔E' H↔H' L↔L'.
**NOT swapped:** A, IXH, IXL, IYH, IYL.

IXH/IXL survive BOTH EXX and EX AF,AF' — they are a **universal register file**
accessible from both primary and shadow banks at zero zone-boundary cost.

Zone boundary bandwidth: A + IXH + IXL + IYH + IYL = 5 channels.
Cross-zone data movement via IX halves: 0T overhead (already there).
The 4T EXX cost dominates — data movement is NOT the bottleneck.

This upgrades IXH/IXL from "slow spill tier" to "universal inter-zone variables".
For the EXX-zone model: variables that need to survive zone boundary → allocate to IX halves.

### GPU Run: 11-loc tables
Launched overnight. Rate: ~15K shapes/sec. nv≤5 done in ~2h.
Move cost H/L↔IXH fixed to 16T (was 8T — DD/FD conflict route through A).

### Key: SP = universal tunnel
SP is never swapped by EXX or EX AF,AF'.
PUSH/POP = zone-invariant transfer. 21T per 16-bit value.
**Worst-case cross-zone cost is BOUNDED at 21T** — not unbounded.

### Practical ranking (cheapest first)
1. IX halves: 0T (just survive)
2. A register: 0T (EXX pass-through)
3. GPR regs: 0T (EX AF,AF' pass-through)
4. Stack tunnel: 21T (16-bit, unconstrained, escape hatch)

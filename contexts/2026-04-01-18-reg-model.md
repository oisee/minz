## Key Decisions

### LocCost IXH = 1 (not 8, not 0)
- Cost=8 made Z3 NEVER use IX halves (penalty × liveness span)
- Cost=1 = slight preference for primary, but usable under pressure
- sha256: 20 IX half uses immediately after fix ✓

### Shadow Regs: EXX-Zone Model (not flat expansion)
- 18 locs flat: 18^6 = 34 billion — IMPOSSIBLE for GPU tables
- EXX-zone: separate 6-loc table (B'..L') + compose at zone boundary
- Same size as current tables! + 4T overhead per zone crossing
- Elegant: each EXX boundary = new allocation problem of SAME complexity

### HLH'L' > DEHL for u32 when DE needed as pointer
- Both 34T for ADD32
- HLH'L': frees DE for screen pointers (Che decoder critical path)
- DEHL: occupies ALL GPR pairs

### GPU Tables Expansion
- 11 locs: ~280M entries, ~20h overnight GPU run — FEASIBLE
- 18 locs flat: 350 GPU-days — IMPOSSIBLE
- EXX-zone: same size × 2 tables — FEASIBLE

### LIR→VIR Reintegration: Path A
- Interference graph already built in VIR
- Shape → enriched table lookup = plumbing only
- Covers 79% corpus at O(1)
- No Souffle/Datalog dependency needed

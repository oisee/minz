### 3. Nanz Language Book v5 → v5.1 → v5.2 → v5.3
- v5.0: 19 chapters, 6 appendices
- v5.1: asm register contracts, implicit return, I/O patterns

### 4. MetaRuntime + Native Metafunctions
- Compile-time introspection + emit via Lanz + MIR2 VM
- Go-powered native metafunctions for code generation

### 5. Cross-Language Imports
- Nanz can import `.lanz`, `.lizp`, `.plm`, `.pas` modules
- Module resolution by extension priority
- Circular import detection across language boundaries
- Name mangling with `$` separator
- 11 import tests

### 6. `|>` Value Pipe Operator + Lambda Type Inference
- F#/Elixir-style `5 |> double |> inc` → constant-folded to `LD A, 11`
- Untyped lambdas: `|x| x + x` infers `u8` from chain context

### 7. ZX Spectrum Tetris
- 853 lines Nanz → 2176 lines Z80 asm (48 functions)
- SRS-lite wall kicks, hold piece, ghost piece, T-spin scoring
- Attribute-based rendering (no pixel redraw, color bytes only)
- Two versions: v1 (611 LOC basic), v2 (853 LOC full)

### 8. Asm Phase 1
- `(ret REG)` — explicit return register
- `(clob REG,...|auto|all)` — precise clobber specification
- `(in REG)` — register-style input (not variable name)
- Auto-clobber analysis: parse asm text, compute write-set

### 9. `ptr()` Cast
- `ptr(addr)^` read → `LD A, (HL)` (language-level peek)
- `ptr(addr)^ = val` write → `LD (HL), C` (language-level poke)
- No inline asm needed for memory-mapped I/O

### 10. Lizp Frontend (Lisp dialect)
- Scheme/Lisp syntax: `defun`/`defmacro`/`defglobal`, `cond`/`when`/`unless`
- Desugars to Lanz: macros, threading (`->`, `->>`), `1+`, `setq`, `progn`
- Cross-language import: `.lizp ↔ .nanz`
- Report #078

### 11. Pascal Frontend (Turbo Pascal subset)
- TP3.0 subset: `program`, `const`, `var`, `type`, `procedure`, `function`
- Records, arrays, `for`/`while`/`repeat`/`case`, `uses` clauses
- CP/M runtime: `WriteLn` → BDOS ConOut via inline asm
- `mz hello.pas -t cpm -o hello.com` works end-to-end
- Corpus analysis + feature matrix (report #079)

### 12. Universal Compile-Time Assert
- All 5 frontends produce `hir.Assert` → dual-VM verification
- 45 assertions across 5 languages, all verified
- Caught real bugs: Lizp `#x` hex desugaring, Pascal BDOS registers

### 13. Bug Fixes
